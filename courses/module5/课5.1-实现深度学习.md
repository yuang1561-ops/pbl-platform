## 📌 本课导读

"项目式学习不是动手型的，项目式学习是动脑型的。"——这是推进者课程 F_3 的第一句话，也是本课的题眼。很多老师把 PBL 做成"纸浆手工课"：学生离开座位、画点东西、涂点颜色，看起来热热闹闹，却没有发生真正的学习。深度学习的目标是把"做"和"知"融合在一起——**学习是有目的的，孩子们学到东西，然后用它去做有意义的事情**。

本课整合三套资料：**视频课 F_3/F_3.1** 讲"怎么想"（六项深度学习原则 + 学生需要的七项基本能力）、**《PBL项目制学习》第 3 章**讲"怎么设计"（学科大概念、布鲁姆高阶思维、智能时代素养）、**行动者手册"绘声绘色"项目**给真实参照。学完本课，你应该能拿自己的项目做一次"深度学习体检"。

## 📖 主线正文（整理自视频课 F_3 / F_3.1）

### 一、先破一个旧观念：PBL 不是动手活动

Tom Markham 在 F_3 开头直说，有件事一直困扰他：老师和教育者提到项目式学习，就把它说成是**动手活动**——这是旧式项目的遗留观念。旧式项目里，学生可能会离开座位、用纸浆做点什么、画点东西、涂点颜色。

- **旧观念**：项目 = 动手 = 手工作业（纸浆、海报、剪贴画）
- **新观念**：项目式学习是**动脑型**的，是一个更深层次的学习过程

深度学习与传统课堂目标的区别：传统课堂追求"知道"（知识），PBL 追求**在知识和技能方面真正把"做"和"知"融合在一起**。这就是 PBL 的目标：**学习是有目的的，孩子们学到东西，然后用它去做有意义的事情。**

### 二、深度学习的六项原则（F_3 核心）

深度学习是一个完整运动，和 PBL 密切相关（Tom 提供了深度学习网站和 PDF 资源）。六项原则每一条都需要体现在你的项目中，但它们**不会自己发生**——你需要计划和引导，让这些原则真正编织进项目的结构里，并给学生带来两难困境：每条原则的落实都需要你做出决策。

**1. 掌握核心学科内容**
- 这听起来当然好，但作为 PBL 老师，你必须**平衡教学和探究**：学生要自己学，有时候你也要做直接教学
- 残酷的现实：你不可能覆盖传统课堂能覆盖的所有材料，**有时候你不得不舍弃课程的一部分**
- 引导者的判断：你学科中的核心内容是什么？哪些是学生必须知道和掌握的关键内容？

**2. 批判性思考**
- "没人能真正定义它，它有太多太多的变体。"所以别纠结定义，问自己设计问题：
  - 我要向学生呈现什么样的问题？
  - 问题有多复杂？是只有一个解决方案，还是一个简单的答案？
  - 还是一个非常复杂的、我们称之为**"棘手问题"（wicked problem）**的东西？
  - 我是在教学生**发现问题**以及解决问题吗？——他们能自己识别问题吗？

**3. 协作工作**
- 团队不同于小组，也不同于合作学习（实践者课程和引导者课程花了大量时间讨论团队）
- **我们通常对学生团队合作的期望比较低**——不指望他们产出高质量作品，但这就是 PBL 的目标
- 引导者要提升团队效率，也要提升自己的引导技巧

**4. 有效沟通**
- 这是"四个 C"之一。它能教吗？怎么拆解沟通技巧？
- 光说"沟通"没用，你会发现里面有**倾听、表达、肢体语言**，沟通的方式五花八门
- 主要办法：**你自己就是沟通的好榜样**——你是个好听众，你能说清楚，能给出好反馈。以身作则是通过 PBL 教学的一个绝佳方式

**5. 学会怎么学**
- 这可不只是学习技巧那么简单：它意味着**成长心态、毅力、同理心、好奇心、坚持**，以及真正能攻克难题的能力
- 你怎么鼓励学生学会学习？怎么培养成长心态？随着课程深入你会发现"毅力"和"同理心"被反复提到——**这些是现在学习的核心要素**

**6. 学术心态（Academic Mindset）**
- 这不是四个 C 的一部分，但很有意思：它关乎在学术环境中前进的**能力和胜任力**
- 你能读懂深奥的文学作品吗？你掌握学术词汇吗？面对艰巨的学术任务你怎么应对？
- 这是**自主性、效能感**——让学生高中或中学毕业后能进入大学环境的东西

### 三、学生需要的七项基本能力（F_3.1 核心）

如果学生真的要通过项目进行深度学习，他们就必须具备相应的能力。**关键前提**：不是所有能力都要在项目开始前教完！很多老师会理解成"那我得在项目开始前把这些能力都教完"，真不是这样做的。要问自己：**哪些需要我在学年初期就教？哪些是学生在项目过程中能学到并提高的？**

**1. 探究的基本技能**：提问、找资源、解读信息、汇报发现。每堂课都会有，但在项目中至关重要——学生需要能把这些事情做得还不错，随着项目推进会学到更多方法。

**2. 背景知识**：这对 PBL 老师有点棘手——学生需要的所有背景知识，通常不会光靠项目过程就学到。你得做直接教学和指导，不断判断：**哪些需要我教，哪些学生自己能学会？**不管怎么决定，都要想他们怎么建立必要的背景知识，然后应用到项目解决方案上。

**3. 学术词汇**：可以融入每个项目——传统组织工具、笔记本、小组讨论（要求他们用特定词汇）、放进评分标准里、放在项目墙上。时刻留意词汇，构建学生的实用学术词汇。

**4. 高级搜索**：大多数学生其实不太会用搜索引擎，他们看到第一个答案就拿走了。教他们高级搜索：各种搜索引擎、特定关键词、简化搜索词。这是个很适合**提前花几天教**的内容，学生要做好的项目工作，就得知道怎么找到深度足够的信息。

**5. 整理内容（Curating）**：让学生看各种来源、各种媒介的信息，然后判断他们理解了什么——能分析吗？能评估吗？能批判性思考吗？教他们做判断：**知道什么有价值、什么没有**。这是 21 世纪的核心技能。

**6. 严谨（Rigor）**：要明确你说的严谨是什么意思。这有助于在学年开始时就把基调定好：学生怎么迁移知识？怎么综合知识？构建思维从简单到复杂、用对比观点。

**7. 协作**：如果他们过去没做过任何项目（PBL 新手），都需要学习如何团队合作。你可以从角色扮演开始、建议提供反馈的方式、让学生注意肢体语言、示范协作是什么样子的、让学生做同伴交流、列出他们过去用过的积极互动方式。

> **给引导者的提醒**：不是所有这些都需要在开始时教，但你应该在整学年中考虑这些能力，决定哪些需要教、哪些可以在项目进行中学习。

### 四、检验学习深度：布鲁姆高阶思维（深度阅读第 3 章精华）

《PBL项目制学习》第 3 章给出一个实用工具：**规划学习行为，使之与布鲁姆教育目标分类学中的高阶类别相联系**。从低阶（记忆、理解）到高阶（应用、分析、评估、创建），后三个与项目制学习尤其相关：

| 高阶类别 | 可用动词（设计活动时直接选用） |
|---------|------------------------------|
| **分析** | 考查、解释、调查、描述、分类、比较、推断、区分、辨别、说明、优先 |
| **评估** | 判断、挑选、决定、证明、证实、提高、维护、辩论、说服、建议、评定 |
| **创建** | 适应、预计、合并、组成、发明、设计、想象、效仿、提议、推理、规划 |

**经典改造例子（第 3 章原文）**：
- ❌ 传统传记写作任务：研究文艺复兴时期的一位著名人物，并撰写一篇描述他生平和成就的报告
- ✅ 重新斟酌后的任务：研究文艺复兴时期在同一领域表现出色的两到三位人物，制定"名人堂"标准，在 Padlet 上发布链接，比较成就，挑选最杰出的一位列入"文艺复兴名人堂"，说明理由，并为这位人物设计一份适当的奖品

同一个内容，从"汇报"变成"比较 + 判断 + 创建"，学习深度完全不同。

### 五、从高阶思维到学习素养

一个精心设计的项目能让学生脑洞大开，而传统学习活动可能无法做到。第 3 章强调两件事：

**1. 学习素养（思维习惯）**：设计项目时要想——项目如何帮助学生培养重要的技能、态度和学习素养？这与 F_3 的"学会怎么学"（毅力、同理心、好奇心、坚持）完全呼应。

**2. 智能时代的素养定义**：多个研究组织给出了定义——enGauge 强调智能时代素养、创造性思维、有效沟通、高生产率；联合国教科文组织把素养定义为"运用不同语境下的印刷和书面材料进行识别、理解、解释、创造、沟通和推断的能力"。**所有定义的重复之处：帮助学生准备应用所学知识。**ISTE 学生标准（2016）把学生描述为 7 个角色：主动学习者、数字化公民、知识构建者、创新设计者、有计算思维的人、有创造力的沟通者、全球合作者。加拿大教育者杰夫·惠普尔的顿悟最值得记住："我们希望我们的学生成为**信息艺术家**——他们是否能找到信息，评估信息的优劣，处理原始数据，并发表自己对数据的理解呢？"

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》第 3 章——建立项目的概念框架

**好项目直指学科大概念**：项目规划的第一步，是确认所教授学科的大概念——核心概念和进程。自问："如果你的学生只能理解或只能做两三件事，那这两三件事是什么？"（例：地球科学中"地球系统中的能量"是核心概念；代数老师会说"运用线性方程"；历史老师希望学生领会"历史如何塑造文化"。）

**已出版教科书 ≠ 深度学习**：用教科书教学，学习成果往往可预测、内容可能已过时。有驾驭能力的教师才能进行综合推理，去理解至关重要且具全局性的大概念。采用 PBL 的教师也可以使用教科书，但**教科书不再是课程的基础，而是一本带有丰富插图的参考书**。

**为什么这些概念重要？** 反思概念在现实生活中的应用：谁会在意这个概念？谁会接触它？谁会在工作或日常生活中与它有关系？（例：地球科学中的能量 → 地震学家、海岸线居民、社区委员会、保险公司、渔业都会关注——一个项目自然就跨学科了。）

**关键案例（第 3 章）**：美国马萨诸塞州布鲁克伍德学校的中学生开展"高效厨灶"研究——为发展中国家设计能挽救生命的炉灶。学生联系麻省理工学院的人道主义工程师，通过 Skype 向洪都拉斯的炉灶建设者学习，与卢旺达、印度、巴西的同伴交流测试数据。

## 🛠️ 落地工具：深度学习对照自查卡（本课自制工具）

把方法变成动作——设计或复盘项目时，对照这张卡自查（工具 2 PBL 目标体系是它的配套，见课 5.2）：

```
┌──────────────────────────────────────────────────────┐
│  深度学习对照自查卡（六原则 × 七能力）                   │
├──────────────────────────────────────────────────────┤
│ A. 六项原则体检（对每个原则打 ✓/✗，✗ 写改进动作）        │
│   □ 1. 掌握核心学科内容——我舍弃了哪些非核心内容？       │
│   □ 2. 批判性思考——问题只有一个答案吗？是棘手问题吗？    │
│   □ 3. 协作工作——是"团队"不是"小组"，期望设高了吗？    │
│   □ 4. 有效沟通——我有以身作则示范倾听与反馈吗？        │
│   □ 5. 学会怎么学——项目里哪里练毅力/同理心/好奇心？    │
│   □ 6. 学术心态——学术词汇、自主性与效能感落在哪？      │
│ B. 七项能力盘点（每项标：开学教 / 项目中教 / 已具备）     │
│   □ 探究基本技能  □ 背景知识  □ 学术词汇  □ 高级搜索    │
│   □ 整理内容      □ 严谨      □ 协作                   │
│ C. 布鲁姆检验：项目主要活动落在哪个层级？                │
│   记忆/理解/应用/分析/评估/创建（后三个才是项目主场）     │
└──────────────────────────────────────────────────────┘
```

**使用步骤**：
1. 拿一个正在设计（或已上完）的项目，先填 A 栏六原则，✗ 的条目写改进动作
2. 填 B 栏七项能力：逐项判断"开学教"还是"项目中教"，别指望项目前全教完
3. 用 C 栏布鲁姆动词表重写项目里 1-2 个学生任务（参考"名人堂"例子）
4. 把改进后的任务讲给同事听：学生是在"汇报"还是在"分析/评估/创建"？

> 💡 **研学场景示例**：
> - 主题"参观良渚博物院" → 把"听完讲解写感想"（记忆）改成"**为两件玉器制定'镇馆之宝'评选标准，比较证据后选出最杰出的一件并设计颁奖词**"（评估 + 创建）
> - 主题"西湖水质" → 把"查资料做海报"（理解）改成"**综合多来源水质数据，判断西湖水质能否支撑特定鱼类生存，向西湖管委会提交一份带证据的建议**"（分析 + 评估）
> - 主题"布达佩斯展" → 把"临摹名画"（应用）改成"**研究两位匈牙利艺术家的创作背景，建立'布达佩斯艺术名人堂'标准并说明选择理由**"（比较 + 判断）

## 📖 案例（行动者手册）

### "绘声绘色"艺术统整项目：让深度学习发生在音乐与美术的交界处

**背景**：北大附中天津东丽湖学校的崔甜甜老师，为了让五年级学生深入理解美术和音乐，设计了音乐与美术的统整课程，希望学生的视觉、听觉、触觉感受在项目中充分发挥。驱动性问题："**我们如何把听到音乐的感受在乐谱上表现出来实现可视化？**"项目时长 8 周，1 个班 21 人，美术 + 音乐两位老师。

**过程**：项目为学校公共空间设计作品——学生观看《幻想曲》和音乐可视化视频，音乐老师讲解基础乐理（节奏、旋律、力度符号、休止符、重音），依次播放 4 首选好的乐曲，学生用身体感官找节奏，再把脑海中的场景画下来，最终用画廊漫步和 7 分钟项目优化会议反复打磨作品，并综合分析经典作品的构图、配色、人物动态、情感表现。

**结果**：产出 4 张乐谱绘画作品、课程记录视频和学生绘制的小样图，在成果展上由学生讲解，后期在公共空间长期展示。核心能力清单里写着：**学生在小组合作中控制情绪、学会倾听、如何给他人提出友善的建议**，以及学会有效自评和小组互评。

**启示**：这个项目把"听音乐"（输入）变成了"可视化创作 + 评价标准 + 公开展示"（分析、评估、创建全占齐）——正是布鲁姆高阶思维和"做与知融合"的教科书式样本。同时它示范了深度学习的七项能力如何在项目过程中自然生长：学术词汇（乐理术语）进了项目墙，协作与反馈贯穿始终。

B. 学生研究西湖水质数据，比较不同湖区数据后判断鱼类生存风险，并向管委会提交带证据的建议

<details><summary>答案</summary>

B。A 是典型的"动手活动"（旧式项目观念，做与知分离）；B 让学生"用"知识做判断、出建议——符合 F_3"做与知融合"的定义，任务动词落在布鲁姆"分析/评估"层。
</details>

**题 3（判断）**：老师想让学生理解"良渚玉器的工艺"，设计了这样一个任务：*"上网搜索良渚玉器的资料，做一份 PPT 并在课上汇报"*。这个任务有什么问题？对照七项能力分析。

<details><summary>答案</summary>

两层问题：(1) 任务层级停留在"理解/应用"——学生只需要搜索 + 复述，没有分析、评估、创建，是"装饰过的研究报告"（第 4 章"科技重于传统实践"错误的翻版）；(2) 从七项能力看，它只练了"探究基本技能"里的"找资源"，却没有练"整理内容"（判断信息价值）、"严谨"（迁移与综合）和"协作"。改进方向：让学生像策展人一样——制定评选标准、比较不同来源的玉器工艺资料、评估其可信度、为展览创建自己的判断。
</details>

**题 4（自查·本课产出）**：拿你自己的一节课（或正在设计的课程），完成深度学习体检：
1. 用自查卡 A 栏六原则逐条打勾，写出至少 2 条改进动作
2. 用 B 栏盘点七项能力：哪些"开学教"、哪些"项目中教"？
3. 用 C 栏布鲁姆动词表，把项目里最弱的一个任务重写一遍

<details><summary>自查指引</summary>

这是本课最重要的产出。如果发现任务动词全是"了解/记住/汇报"→ 换用"比较/判断/设计/发明"；如果发现所有能力都想在项目前教完 → 回到 F_3.1 的原则：分清"学年初期教"和"项目过程中学"；如果六原则里"协作"和"有效沟通"没有落点 → 想想团队怎么组建、反馈怎么给（下一课 5.4 深度协作会展开）。
</details>
