## 📌 本课导读

"拥抱真实。"——这是 F_5 的标题。对优秀的项目式学习来说，黄金标准、最高标杆，就是**做真实的社区项目**：项目主题关于学生所在的社区和环境。但现实是：有学校、有系统、有考试、有各种限制和障碍，阻碍我们开展高质量、真实的项目式学习。这**真正考验你作为引导者的技能**：怎么为项目找到合适的定位，让它们尽可能真实，同时还能满足系统的要求？

本课整合三套资料：**视频课 F_5/F_5.1** 讲"怎么想"（黄金标准、限制与定位、甘地态度）、**巴克《教师指南》第 2 章**讲"真实性问题怎么设计"（4 条原则 + 精炼）、**工具 17 思维地图**给"怎么落地"。学完本课，你应该能为自己的项目做一次"真实性定位"。

## 📖 主线正文（整理自视频课 F_5 / F_5.1）

### 一、真实性是黄金标准，但别为此内疚

**黄金标准 = 真实的社区项目**：项目主题是关于学生所在的社区和环境——这是设定的高标杆。

但与此同时：有学校、有系统、有考试、有各种限制、有各种障碍。你的工作是**为项目找到合适的定位**，让它们尽可能真实，同时还能满足你所在系统的要求。

**Tom 的安慰（很重要）**："我只想说，别感到内疚。"我们生活在两个世界里：一个是正在展开的未来，另一个是旧式的工业教育。通常作为老师，**你一只脚踩在两边**。所以如果你做不到你想要的那么真实的项目，别自责。

- 这跟一年中的时间有关：**有时候在学年快结束时你能找到更多机会**，有时候不行
- 没有统一答案：因学生、时间、学校、考试要求而异
- 你作为引导者的工作就是**应对这些限制**：设计你能做到的最真实的项目，为你的学科、你的学生、你交付给他们的项目找到合适的定位

### 二、真实性的两种来源

F_5.1 开头点出我们喜欢什么样的项目：**更贴近社区、由学生需求驱动、真正面向目标和热情的项目**。结合巴克书，真实性通常来自两个方向：

1. **主题真实**：项目主题本身来自真实世界（社区问题、真实事件、现实需求）
2. **过程与产品真实**：学生做的是真实专业人士做的事，产出有真实用途、面对真实受众

### 三、找到合适定位：五个限制因素（F_5.1 核心）

作为引导者，你在平衡真实性和崇高目标时，会面临很多选择，还要考虑教学的环境、学校、课程和学生。典型的限制：

**1. 时间（大头）**
- 你有时间做一个三周的项目吗？
- 探究很好，但它花时间；把学生分组、让他们做研究很好，那也花时间
- 时间是个限制

**2. 学科**
- 你的学科是不是内容很重？你真的得教很多东西？
- 这意味着你可能要做更多**直接教学**，也许在项目背景下做更多直接教学

**3. 一年中的什么时间**
- 学生们准备好做这种项目了吗？是学年初期他们还没准备好？还是学年后期他们迫不及待想做项目？
- **通常学年初的项目更偏向标准和内容基础，学年后期的项目则更偏向兴趣或热情驱动**（不一定总是这样）
- 无论你从兴趣还是标准出发，你总得在里面找到设计的机会：**拿一个基于标准的项目，围绕它创造一个真正好的问题；或者拿一个基于兴趣的项目，注入更多标准**

**4. 学生声音（Voice）**
- 这是项目式学习的重要部分，但也不总是可行
- 有时候你得平衡教师主导和学生主导的项目——这是一个**连续体和平衡**：学生参与并推动项目，同时你确保按学科要求把内容教到位
- 这是个微妙的平衡，没有统一答案，你得边做边摸索

**5. 内容 vs 过程**
- 你需要教多少内容，又能允许多少过程？
- 如果你的课程中有某些元素必须教（也许是为了让学生准备考试），你可以在项目里做直接教学，但你总会面临这个平衡：多少内容自己教，多少交给学生自己去做

### 四、不必一直做项目（重要提醒）

"有时候你看着这个会说：'你知道吗，我在这部分课程里根本没法做项目。'那也没关系，**别做**。"

看看活动、看看课程、看看项目——不只是项目式学习，还有**更短的项目**，能让学生积极参与，但并不是完整的项目式学习项目。只要确保你带着那种能吸引学生的态度去做：**尊重、理解、接纳、欣赏**。

> 我称之为"**甘地态度**"，对学生非常管用。主要教训是：你不必一直做项目。这就是怎么找到合适的方式。

### 五、真实性问题：从"内容在现实世界中哪里找得到"出发

设计真实项目的核心一步，是把教学内容放进真实世界（巴克第 2 章）：**"我所要教的内容在现实世界中的什么地方能够找得到？"**

- 传统问题要求"回答"，驱动问题要求"做大量准备工作"
- 真实性来自：真实问题 + 真实过程（像专家一样做事）+ 真实产品 + 真实受众

## 📚 深度阅读（书籍精华）

### 巴克《项目学习教师指南》第 2 章——设计驱动问题（真实性视角）

**驱动问题应该反映出现实环境中的真实问题**——这是巴克对驱动问题的定义性要求之一：教师在设计驱动问题时应先问自己："**我所要教的内容在现实世界中的什么地方能够找得到？**"

**驱动问题设计四条原则（与真实性直接相关的两条）**：

| 原则 | 要点 | 示例 |
|------|------|------|
| 激发学生兴趣 | 使学生在项目过程中保持兴趣、深度投入 | "音乐电视是否精确地描绘了美国文化？" |
| 开放性问题 | 不是"是/否"能回答；要求高级思维、整理综合信息 | "美国在第二次世界大战时是否应该使用原子弹？" |
| 直指核心内容 | 指向科目核心内容，与课标紧密联系 | "我们的饮用水有多安全？"（需科学证据和生物、化学、生理学标准） |
| **反映真实问题** | **先问"内容在现实世界中哪里找得到"** | "我们要不要担心全球变暖对我们社区的影响？" |

**现实生活中的两难问题最激发兴趣**："如何在只能用本州自产的建筑材料的条件下，建造新的社区活动中心？"——佛蒙特州科学教师用它让学生理解岩石的形成：学生需要认识本地岩石的来源、属性、矿物质构成，还要评估材料的强度和耐久性，判断为什么页岩石材适合做屋顶而不适合铺地板。**一个真实约束（只能用本地材料）让整个项目立即真实起来。**

**小心陷阱**：
1. **可行性陷阱**：驱动问题要开放，但也要考虑可行性——学生能否在某一时间段完成？可用资源和技能水平够吗？"谁是 20 世纪最有影响的总统？"能激发思考但需要大量细致研究，作为项目主题不现实
2. **技术喧宾夺主**：项目中的所有活动都应是为解决驱动问题而设计的；评价应关注学生如何分析问题、查资料、整理论据、得出结论，**技术工具的使用是手段，不是评价焦点**（研究性项目却花大量精力让幻灯片更酷，就是反面例子）

**精炼驱动问题**（由粗到精的过程）：加强要求学生反复思考复杂问题；着力在项目主题上；学习课程标准规定的内容；动手实践与知识学习相结合。示例："在 20 世纪，机器人和自动化技术是如何改变了人类社会？"→ 精炼为"**在 21 世纪，机器人和自动化技术将会怎样改变我们的城市和这里的商业？**"——延展问题的广度能增加力度。

**真实性与社区需求（巴克"6A 法则"关联）**：根据社区的需要，很容易设计出具有真实性的项目（原书第 6A 法则强调真实性：项目是否具有真实的背景、真实的任务、真实的产品、真实的受众）。

> 🔗 延伸阅读：巴克《教师指南》第 2 章（第 44-53 页）→ 知识库检索"设计驱动问题"｜"真实性"

## 🛠️ 落地工具：思维地图（50工具 工具17）

把真实问题**结构化成探究方案**，用思维地图可视化——工具 17（美国哈佛大学教育学院大卫·海勒 1988 年开发）共有八种形式，比思维导图更利于辅助思维：

```
┌──────────────────────────────────────────────────────┐
│  思维地图八式（工具17）——选哪张取决于你要做什么        │
│  圆圈图：界定主题（主题圈 + 要素圈）                   │
│  气泡图：描述主题特征（中心主题 + 气泡特征）           │
│  双气泡图：比较两个主题的异同（中间 = 共同要素）       │
│  树形图：分类（主题 → 一层分解 → 二层分解）           │
│  括号图：整体与部分（中心主题 → 部件分解）            │
│  流程图：顺序/环节（环节一 → 环节二 → 环节三）        │
│  复流程图：原因-结果（左侧原因 → 中心主题 → 右侧结果） │
│  桥形图：类比（上下两行对应关系）                     │
└──────────────────────────────────────────────────────┘
```

**为何使用**：思维地图是用来构建知识、发散思维和提高学习能力的思维可视化工具。在真实性项目中，学生面对的是开放、杂乱的真实问题，八种地图帮他们把问题拆开、比较、找因果——**这正是真实探究需要的结构化思考**。

**使用步骤**：
1. 项目启动时用**圆圈图**界定主题范围（例："西湖水质"主题圈 → 污染源、生物、政策、游客行为等要素圈）
2. 研究真实问题时用**复流程图**梳理原因与结果（例：西湖水质变化的原因 → 影响 → 谁该做什么）
3. 比较方案时用**双气泡图**（例：对比"投放鱼苗"与"截污纳管"两种保护方案的异同）
4. 规划实施时用**流程图**（例：采样 → 检测 → 数据分析 → 撰写建议 → 提交管委会）
5. 把小组完成的思维地图贴在项目墙上，作为"真实问题探究地图"持续更新

> 💡 **研学场景示例**：
> - 主题"良渚博物院展陈设计" → 用**圆圈图**界定"什么样的展览能吸引同龄人"，再用**树形图**把展览要素分类（内容/互动/文创/导览），学生分组认领
> - 主题"西湖水质" → 用**复流程图**画出"水质变化的原因与结果"，再决定调研哪条因果链
> - 主题"布达佩斯展" → 用**双气泡图**比较"匈牙利艺术"与"中国艺术"的异同，为"跨文化导览"找到讲解切入点

## 📖 案例（《PBL项目制学习》第 3 章）

### 罗伯特·格里芬：判断真实性的标准是"这事在真实世界会不会发生"

**背景**：罗伯特·格里芬在加拿大大马南岛的渔业社区任教。社区里的人们常在饭桌上讨论许可证、配额问题——他发现这些话题天然就是真实的学习素材。

**过程**：为了让学生与写作的真实用途相关联，格里芬让学生**就许可证问题或配额问题给渔业部长写信**；在另一个写作项目中，让学生**给当地报纸撰写文章**。他判断项目是否具有真实性的主要标准就是："**这些活动是否会在真实世界中发生。比如，记者会不会向报社提交文章以求发表？答案是肯定的，那么我的学生也会照样去做。**"

**结果**：如果县报的编辑选择发表某位学生的文章，"那么，那位学生不仅会收到报社的酬金，也会从我这里得到该课程的成绩。他们的文章能在报纸上刊登就是**真实的评估**——这说明他们的文章已经好到可以被发表的程度了。"

**启示**：格里芬的标准把"真实性"从口号变成了可检验的判据——**问自己：这个任务在真实世界里有没有对应的专业人士在做？如果有，学生就照做**。写信给部长（真实受众 + 真实议题）、投稿报纸（真实产品 + 真实发表标准）都比"写一篇关于渔业的作文"真实得多。这正好呼应 F_5 的黄金标准：做真实的社区项目——主题关于学生所在的社区和环境。

**题 2（判断）**：学期中段（学生基础薄弱、考试压力大），以下哪个项目设计更符合 F_5.1 的"定位"思想？
A. 完全放手让学生自由选择任何感兴趣的课题，做 10 周长项目
B. 做一个 3 周短项目：围绕课本单元核心内容设计真实问题，教师做更多直接教学，保留学生部分选择权

<details><summary>答案</summary>

B。F_5.1 明确：学年初/压力大的时期，项目更偏向标准和内容基础，可以多做直接教学；时间、学生准备度都是限制因素。A 忽略了学生声音、时间、考试要求的平衡，容易导致项目失控（课 5.6 的"学生没准备好"是项目失败首因）。B 是"拿一个基于标准的项目，围绕它创造一个真正好的问题"。
</details>

**题 3（判断）**：一位老师设计"全球变暖"主题项目，驱动问题是"我们要不要担心全球变暖？"请找出问题，并对照巴克第 2 章给出修改方案。

<details><summary>答案</summary>

两层问题：(1) "要不要"是**"是/否"类问题**，学生可以只答"要"或"不要"而不用做深度探究，不符合"开放性"原则；(2) 不真实、不本地化——全球变暖离学生太远。巴克书的改进版是"我们要不要担心**全球变暖对我们社区的影响**？"——落到"我们社区"学生才有真实感；Tom Markham 的版本更进一步："气候变化会怎么影响**我们当地生态系统里的生物多样性**？"。另外可对照"内容在现实世界中哪里找得到"：把问题落到本地的海岸线、本地物种、本地产业。
</details>

**题 4（自查·本课产出）**：为你自己的一个课程做"真实性定位"：
1. 列出你面对的限制（时间/学科内容量/学年阶段/学生声音/考试要求）
2. 回答：这个项目能做多真实？（真实主题/真实过程/真实产品/真实受众，各打 ✓/✗）
3. 用思维地图中的一张（复流程图或圆圈图），画出项目真实问题的结构
4. 如果做不了完整 PBL，写一个"更短的项目"方案（带甘地态度：尊重、理解、接纳、欣赏）

<details><summary>自查指引</summary>

这是本课最重要的产出。如果限制列不全 → 回想 F_5.1 的五个因素；如果"真实受众"总是 ✗ → 想想谁会用学生的成果（景区、博物馆、社区、家长、同龄人，甚至一个真实的比赛）；如果思维地图画不出来 → 说明问题还没界定清楚，回到圆圈图先界定主题；如果决定不做完整项目 → 这是允许的（"不必一直做项目"），但要写出替代方案。
</details>
