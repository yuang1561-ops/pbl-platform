## 📌 本课导读

"跟着玩家走。"——这是 F_7 的标题。游戏难道不是在校外发生的事情吗？游戏不就是好玩，跟学习没关系吗？Tom 不这么认为。数据摆在那里：**美国 40% 的高中生在课堂上感到无聊**（澳大利亚数字也非常接近）；而有些孩子在课堂上五分钟都集中不了注意力，却能花八个小时盯着屏幕玩游戏。我们看到游戏中发生了各种深度合作，孩子们实际上在很多方面练习和磨练他们的 21 世纪技能。**游戏和 PBL 有很多重叠之处。**

本课整合四套资料：**视频课 F_7** 讲"玩家心态"（游戏原则引入 PBL）、**F_10/F_10.1** 讲"寻找天赋"（叛逆者与异类、呼吸与祝福、迷思与神经多样性）、**《PBL项目制学习》第 7 章**讲"激发好奇心"（差异性事件、角色扮演预测、K-W-L）。

## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、跟着玩家走：游戏告诉我们未来学习的样子（F_7）

**两组数据**：
- 40% 的高中生在课堂上感到无聊（美国报告，与澳大利亚接近）；很多报告说学生趴在桌上、对学习没兴趣、不参与、没有创造力
- 孩子玩游戏：课堂上五分钟都集中不了注意力，却能花八个小时盯着屏幕玩游戏；游戏中发生了各种**深度合作**，孩子们在交流，在很多方面练习和磨练 21 世纪技能

**好消息**：游戏和 PBL 有很多重叠之处。你可以把游戏的一些原则引入进来，这些原则主要涉及：
- **挑战**
- **目标**
- **有意义的掌握**
- **让孩子感觉自己在自主学习的方式**

**给老师的邀请**：如果你不是玩家，或者从未参与过游戏的乐趣，而且你对游戏持某种负面态度——请重新考虑一下。**游戏中有一些元素正在告诉我们未来的学习应该是什么样子**，你可以把它引入到你的项目中。

### 二、叛逆者、异类和不合群者：天赋往往溢出来（F_10）

F_10 的副标题叫"呼吸与祝福"。这个体验聊的是那些**不想参与项目式学习的学生**——Tom 称之为叛逆者、异类和不合群的人。他对这群人有些经验："我教书的头四年是在学校校园后面的一间移动教室里度过的，每天有五节课要应付那些叛逆者、异类和不合群的人。所有不想留在学校的孩子，他们宁愿去另类学校，或者干脆辍学。那是我学到很多教学经验的地方，也是我了解学生的地方，也是我稍微认识自己的地方。"

**关键发现**：和这些孩子打交道是个挑战，但也是发现他们是谁的机会——**他们很多人内心其实有天才**。不像那些需要培养创造力的孩子，这些孩子很多方面**创造力都溢出来了**——多到他们真的不想待在传统学校的框框里。

**完整案例（Tom 亲历，请完整保留）**：有个男孩，15 岁，经常在学校里打架或者惹事，口袋里总是装着两三百美元的现金。校长们说："他肯定在贩毒"——那是他们的结论。他的名声就是个麻烦精，可能还是个潜在罪犯。他在 Tom 的一门课上，他们聊了很多，开始建立信任的渠道，发展出纽带。随着这个发展，Tom 发现了这个年轻人身上很有趣的事情：**他不会读书，一个字都不认识**——他父母不知道，老师也不知道，这是他藏在自己心里的秘密。因为这个秘密折磨着他，所以很多表现出来的行为真的是愤怒式的。然后 Tom 问："好吧，那没问题。那 200 美元从哪儿来的？"他讲了一个非常有趣的故事：**他能修他邻居那边任何汽车引擎或摩托车引擎，他很抢手，人们一直付他现金。**他原来是个顶级的赛车机械师——能把引擎拆开再装回去，比任何人都快，而且从不看手册。Tom 问他："你怎么能不看手册就做到？"他说："**我就是脑子里能看到。**"惊人的天赋，那是一种天才。

**第一条规则**：**你总是要透过他们的行为去看，试图弄清楚背后的原因是什么。**有时候不只是天才，还有创伤、童年问题、家庭问题、家庭矛盾，但你的工作是试着深入下去帮他们——这需要不带评判、对体验开放，并且愿意倾听别人，而不急着对他们是谁下结论。

### 三、呼吸与祝福（F_10.1）

作为引导者，你做的很多事情其实并不在你的掌控之中。在项目式学习中，学生往往自己掌控自己——你会遇到一些"异类""抗拒者"和"不配合者"，他们看着你说："我不喜欢这个项目。"**不管你作为项目式学习规划者多出色，你总会定期遇到一些不想做项目的学生。**你如何处理他们非常重要——不仅关系到你自己的幸福感，也关系到他们的。

- **欢迎他们，感谢他们，让他们知道在这里没关系。你自己不要太沮丧**——他们是你在教室里会遇到的学生正常变化的一部分。不是每个人都能被照顾到，你也不可能让每个人都参与项目
- 如果你能避免评判，从一定距离外带着一些视角来看待，那真的会帮助孩子们——然后也许能扭转局面，他们真的开始表现
- **"看看那张图，花和杂草之间唯一的区别就是评判。"**这句话很有道理，尽量多运用它

**放下四个迷思**：
1. **没有所谓的固定智商**：智力不是一成不变的，它是动态的——智力分数每二十年大约上升 10 分；**基因不是命运**，一切都关乎文化和你的态度（你教室里的文化很重要）
2. **逆境越来越造成影响**：创伤阻碍了学习，随着时间推移你可能会遇到更多这样的情况
3. **没有所谓的非认知技能**：一切都与情绪和思维相关，这是一个过程
4. **理解神经多样性**：看"平均的终结"视频——平均是统计概念，年级水平也是。**没有所谓的年级水平达标或平均人**。统计变异让我们看不到每个学生都有隐藏的优势，也看不到创伤和贫困的存在——但可以通过工作和好的项目式学习来缓解

**你可以做的其他事情**：
- **提供充足的声音和选择**；**教专注和注意力，停止给所有事情计时**；给孩子们一个"数字安息日"（教室里把手机收起来两天）——关键：**通过自主性来教自我控制，而不是通过服从和说教**，那样永远不会取得进展。如果你有在教室里失控、很难处理的孩子，**给他们一些自主权和练习，而不是说教或把他们赶出房间**
- **定制学习（金发姑娘公式）**：试图找到**刚好适合**学生的项目和作业，在正确的时间满足他们的需求；可以做认真的覆盖，但别忘了那种玩乐的心态——定制它，让学习变得有趣

**天才的词根是喜悦**："人们没有意识到的一件事是，天才（genius）的词根是喜悦（joy）。喜悦和天才在一起，玩耍和学习在一起。记住你的项目应该有一个伟大的'为什么'，有理由做这件事，而不是'这会在考试里出现，你必须学'——那对你没用。"

**总的原则**：对学生要有同理心的态度。**"大脑可能接受建议，但心不会。"**孩子们会在你跟他们说话、建立关系时感受到你。当他们觉得你站在他们这边、你跟他们有连接、你相信他们、你不评判他们——那时候你的那些"问题学生"就会开始转变，不再是你的"问题学生"，他们会变成你的支持者。**这些年来 Tom 听过很多 PBL 老师的故事：以前的问题学生变成了项目式学习最大的支持者。**所以，如果你发现班里有问题学生、发现自己被惹恼了——深呼吸，祝福他们，放手让他们走，让他们找到自己的路。

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》第 7 章——项目启动：激发好奇心，让学生处于期盼状态

**项目启动的基调**：项目启动是一个深入并周密的学习周期的开始。请花些时间去**激发学生的兴趣**，了解学生已经掌握的内容和关注的事物，教授学生必要的概念或技能。在项目的开始阶段，应该让学生对接下来的学习**充满信心和好奇心**。

**激发好奇心的两种方式（第 7 章核心）**：我们要重组学生原有的知识框架，动摇他们对"已知"知识的看法。
1. **差异性事件（Discrepant Event）**：引人注目、发人深省的事件，教师故意用来挑战学生固有的观念。经典案例——5 年级密度与浮力课：教师展示两个看起来一模一样的玻璃杯，都装着看似水的液体。向第一个杯子扔冰块，冰块浮起；问学生第二个杯子会怎样，学生自信满满地说会浮起来——**但冰块沉到了杯底**。杯子里装的是什么？什么东西会在第二个杯子里浮起来？学生设计了微型调查现场调研。第二天，教师引导学生开展深入项目：研究和制作由不同材料制成的笛卡尔浮沉子。
2. **角色扮演预测**：让刚开始项目的学生在特定场景中扮演其他角色即兴发挥，学生根据对项目话题的初步理解进行预测，通过表演展现理解；录制并回放，让学生注意自己脱离角色的时刻，思考如何让表演更流畅精准。

**"殖民星球"案例（期盼状态）**：初中科学老师启动生物物理项目前一周，展示一幅 20 世纪 70 年代火星定居海报，说"长久以来人们都设想其他星球上有生命存在……下周我们将会迎来一位神秘嘉宾"。每天花几分钟重复话题，学生热情慢慢建立。一周后神秘嘉宾现身网络研讨会：**NASA 天文生物学研究所的科学家**讲述宇宙可居住性研究，鼓励学生像科学家一样探究。"此前的一系列活动几乎不需要学生花时间或做准备，只是让学生处于一种期盼的状态。项目正式启动时，学生变得迫不及待。"

**K-W-L 活动**：让学生重温已知、设想未知。注意：操之过急时学生只能学到事实性知识。在"已知"环节挑战学生（"你为什么这么说？"）；把"想知道"的事实性问题转变成"为什么/应不应该/怎样"开头的问题——不要满足于学生能问"地球距离月球多远"，要引导成"人们最开始是怎么得出月球与地球间的距离的"。把"需要知道"清单放在显眼位置时时更新。

**问题引导词（乔伊斯·瓦伦扎提供）**："哪一个"类型（收集信息做明智决定）；"如何"类型（理解问题、权衡选择、提出解决方案）；"如果……会怎样"类型（假设性问题）；"是否应该"类型（基于证据做道德伦理决定）；"为什么"类型（理解原因与后果）。

## 🛠️ 落地工具：好奇心启动设计卡（本课自制工具）

把"玩家心态 + 好奇心"变成项目启动的动作——结合 F_7 的游戏原则与第 7 章的启动策略：

```
┌──────────────────────────────────────────────────────┐
│  好奇心启动设计卡（本课自制）                          │
│  ① 挑一个"差异性事件"：打破学生固有认知的现象/物品/    │
│     数据/新闻（例：冰块在"水"里沉下去）               │
│  ② 设计悬念：提前 3-7 天埋线索（海报/神秘嘉宾预告/     │
│     项目墙谜题），让学生处于"期盼状态"                 │
│  ③ 加入"角色扮演预测"：让学生扮演角色即兴预测，        │
│     录制回放，讨论哪里不像                         │
│  ④ 游戏化三件套：挑战（难度分级）/ 目标（可见的进度条）/ │
│     有意义的掌握（技能徽章或里程碑）                   │
│  ⑤ 用 K-W-L 收尾：已知/想知道/学会了，把"想知道"       │
│     改造成"为什么/怎样/是否应该"式问题                  │
│  ⑥ 玩家心态自检：项目有"伟大的为什么"吗？学生是      │
│     被要求学还是自己选择玩？                         │
└──────────────────────────────────────────────────────┘
```

**使用步骤**：
1. 项目启动前一周：设计并埋下差异性事件或悬念线索
2. 启动当天：用角色扮演预测让学生"动起来"，录制回放
3. 把游戏化三件套（挑战/目标/有意义的掌握）写进项目墙
4. 用 K-W-L 收集学生的"想知道"，逐条改造成开放式问题
5. 对照第 ⑥ 步自检：如果学生说不出"为什么做这个项目"，回到课 5.6 的"为什么"检查

> 💡 **研学场景示例**：
> - 良渚博物院研学 → **差异性事件**：展示一块"普通石头"与一块良渚玉琮的对比，问"同样来自地下，为什么它被当成宝贝？"（打破"文物=好看"的固有认知）
> - 西湖水质 → **悬念启动**：提前一周贴出"西湖里到底有什么？"海报和神秘水样照片，神秘嘉宾（水质监测员）预告；启动日角色扮演预测："如果你是西湖的一条鱼，你愿意住在这里吗？"
> - 布达佩斯展 → **游戏化**：设"观展挑战"分级（初级：找到 3 幅最特别的画；进阶：为一幅画写'身份档案'；大师：设计一条'隐藏线索'导览路线），完成挑战得"策展人徽章"

## 📖 案例（《PBL项目制学习》第 3 章）

### 从"电脑游戏"到"我的天赋"：两个关于兴趣与天赋的故事

**案例一：维克托·埃尔南德斯的电脑游戏项目（玩家心态入课）**：在科学领导力学院，入门计算机科学的学生探究"什么是电脑游戏？"——先阅读有关"玩家门"争议的内容（涉及对游戏文化中性别歧视的指控）建立背景知识，然后**设计和编程自己的游戏，并将游戏在 SLA 游戏中心上线，供玩家来玩**——让作品跟真实受众联系起来。高级课上学生要解决的问题是"科技有何用处？"，通过采访了解企业或机构的需求，设计实施软件解决方案，**使用与专业程序开发员同样的方法：创建功能列表和实施时间表，从客户那里获得实时反馈**。

**案例二：纳塔莉·汉普顿与"与我同坐"（被忽视的天赋）**：南加利福尼亚州的初中生汉普顿因为不合群，午餐时间是最不舒服的时间："我被所有的同学排斥，所以每天都只能一个人吃午餐。"转学后她反思："如果我只是在新学校里开心快乐地成长，而不为那些每天都跟我有着相同处境的人做些什么的话，那我跟那些冷眼看我一个人吃饭的人又有何区别。"11 年级时她开始思考数字化解决方案，**与一位软件开发员合作**，把想法变成产品——"与我同坐"（Sit With Us）免费手机应用程序：任何想加入餐桌的人都可以查看应用，找到开放的邀请。应用自 2016 年问世以来，**在 8 个国家拥有了超过 100,000 名学生用户**。

**启示**：两个案例从不同方向诠释本课——埃尔南德斯把"学生本来就在玩的游戏"变成学习入口（F_7：跟着玩家走）；汉普顿则是一个"异类"找到天赋与使命的故事（F_10：透过行为看原因，她的孤独感背后是对同伴的共情天赋，加上解决问题的能力）。共同点：**真实受众让作品有力量，个人兴趣让学习有热情——这正是"天才的词根是喜悦"。**

B. 找他聊聊，了解他喜欢游戏的哪些部分，问他愿不愿意在项目里负责"游戏化设计"或"数字展示"的部分

<details><summary>答案</summary>

B。F_7 邀请老师重新审视游戏（"游戏中有一些元素正在告诉我们未来的学习应该是什么样子"）；F_10/F_10.1 强调不带评判、透过行为找原因、提供声音和选择、通过自主性教自我控制。A 是说教和威胁——"通过服从和说教永远不会取得进展"。
</details>

**题 3（判断）**：老师们私下说某个学生"脑子笨，学不会，还总捣乱"。请分析这个判断的问题（至少两层）。

<details><summary>答案</summary>

两层问题：(1) **迷思层面**——F_10.1 说没有固定的智商、基因不是命运、没有所谓的"年级水平达标或平均人"；给一个孩子贴"笨"的标签等于用统计变异遮蔽了他的隐藏优势；(2) **行为解读层面**——F_10 的第一条规则是"透过行为看原因"：捣乱可能是创伤、家庭问题、学习障碍（如案例中的男孩不识字），也可能是天赋被压抑的愤怒。正确做法：不带评判地倾听、观察、建立信任渠道，寻找行为背后的原因和隐藏的天赋——"花和杂草之间唯一的区别就是评判"。
</details>

**题 4（自查·本课产出）**：结合你自己的学生/学员，完成"天赋发现"练习：
1. 回想一个你曾觉得"难搞"的学生，写下他/她让你头疼的 2 个行为
2. 透过行为问"为什么"：背后可能是什么？（创伤/被忽视/学习障碍/未被看见的天赋/对权威的对抗？）
3. 设计 1 个"连接动作"：你下周可以做的具体一件事（单独谈话？给他一个能发挥所长的角色？提供一个选择？）
4. 用好奇心启动设计卡，为你下一个项目写 1 个差异性事件

<details><summary>自查指引</summary>

这是本课最重要的产出（也是 F_10 的落地练习）。如果写不出行为背后的原因 → 别急，先安排一次不带评判的谈话（F_10 说"这需要你成为一个好的观察者"）；如果连接动作是"找他谈话"但没想好谈什么 → 参考案例：从兴趣入手（游戏、修车、任何他擅长的事），先建立信任渠道；差异性事件想不出 → 用第 7 章的例子启发：找一个"看起来 A 但其实是 B"的现象（冰块、玉琮、神秘水样）。
</details>
