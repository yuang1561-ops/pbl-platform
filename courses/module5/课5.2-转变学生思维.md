## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、为什么学生"不催不动"：因为他们在适应环境

"我遇到过很多 PBL 老师，很多普通老师，还有很多现在做远程或在线教学的老师。他们告诉我：除非我告诉学生该做什么，否则他们不会干活。"

为什么这么真实？**我们在训练他们听话方面做得太好了**——让他们相信只有我们在教的时候他们才算在学习。这种心态需要你去解开。

**关键认知：文化塑造大脑。** 我们知道大脑会对环境做出反应：如果一个学生坐在教室里四年、八年、十二年，他（她）真的已经适应了那个环境——大脑已经把自己调整到在那个环境中表现最佳。所以当你说要训练学生或转变学生心态时，你实际上是在说**解除训练（untraining）**。这需要下功夫，不容易。

除非你开始进行非常透明、真诚的对话，跟学生谈谈**为什么他们需要转变思维、成为不同类型的学习者**，否则你会在 PBL 中感到沮丧——因为如果有太多学生坐在后面说"直接教我就行，给我书，告诉我该做什么，告诉我作业什么时候交"，他们不会开心地做 PBL，你也不会开心地和他们一起做 PBL。

**转变的方向**：让学生把学习看作一种**创业式的努力**——这是他们自己在做的事情：不是在接收知识，而是在创造知识，并用它去做重要的事情。

### 二、项目思维（Project Mindset）：21 世纪的学习指标

Tom 提醒所有 PBL 老师即将面对的东西——项目思维：**我们真正在关注学生的行为和优势，把它们作为本世纪学习的一些关键指标**。

- 学生就是需要去**表现**
- 光有一张证书是不够的，光有大学或学院学位也不够
- **你必须能做事**——这需要我们在寻找的优势和行为

### 三、转变的五个方向（F_4.1）

改变思维模式不容易——"这需要一辈子，可能需要一年，当然不可能在学校的短短一周内就实现"。但作为引导者，要在学年开始时思考：如何转变学生的思维模式，让他们**为自己做到最好，同时为未来做好准备**。思维需要这些转变：

1. **从学习到完成**：提升自己，改善你的世界，有能力采取积极行动
2. **从热情到应用热情**：对某件事充满热情，然后围绕这份热情采取行动、做出改变
3. **不要那么关注高分和排名，更专注于把事情做成**
4. **不仅仅是学术视角，而是在现实世界中思考和行动**
5. **最重要：我们准备好应对一切**——教学生灵活思考、敏捷应对、有韧性，这是他们最需要的东西

### 四、项目思维模式的定义与九个指标

> **项目思维模式 = 项目式学习 + 良好的问题解决能力 + 关键优势（创造力、同理心、设计技能和幸福感）的整合**

愿景：帮助学生成为全面发展的、在校外也非常有能力的人——**他们准备好面对世界了**。这也意味着：**你首先要教学生，然后才是教标准和内容**；你必须关注每一个个体。

Tom 给出的**九个指标**（"我不认为这是一个完整的清单，但肯定是可以供你思考的东西"）——你要找的是那些：

| # | 指标 | 通俗理解 |
|---|------|---------|
| 1 | 独立、自我管理、有创业精神 | 不用催就能开工 |
| 2 | 用热情和目的去追求学习 | 知道为什么学 |
| 3 | 具备良好的问题和项目式学习技能 | 会提问、会做项目 |
| 4 | 持续学习 | 你不在旁边督促或推动，他也在学 |
| 5 | 善于合作 | 能协作 |
| 6 | 能联系导师和全球资源 | 知道怎么找到人帮忙 |
| 7 | 注重幸福感 | 关心自己的状态 |
| 8 | 重视服务和贡献 | 想为他人做点什么 |
| 9 | 能反思自己的学习 | 会复盘 |

**关键结论**：如果你仔细看这九个指标，**它们都可以通过项目式学习来教授**——你可以通过和学生一起做高质量的项目来实现这一切。

### 五、学年开局的三个抓手

**1. 天才一小时（Genius Hour）**
- 字面意思：一小时的、由热情和目的驱动的练习
- 学生找出一个感兴趣的话题 → 快速头脑风暴 → 会有什么解决方案？他们会怎么解决？
- 它不是深入的，但能**激发创造性思维**，让学生习惯快速、灵活、敏捷的思考方式——这对项目式学习非常有用
- 在课堂上**定下新基调**时效果很好

**2. 设计冲刺（Design Sprint）**
- 更像一个五天的练习，思路和天才一小时差不多，只是时间长一些
- 学生确定一个问题 → 尝试画出解决方案 → 判断是否可行 → 提出原型 → 得到反馈 → 决定是否可行
- 非常快速的思考，鼓励敏捷性
- **别忘了：设计思维始终是项目式学习的一部分**——你总是要把设计解决过程融入项目中，这样学生就不断被挑战去检验他们的想法，提出更好的解决方案，这对改变思维模式大有帮助

**3. 你的语言和你的态度：成长型思维模式**
- 你是否一直在鼓励这种转变：从"我做不到"到"我能行"？
- "是的，我能行。我有能力，我能找到策略，我能找到方法去克服这些挑战和问题，取得成功。"
- 这不会立刻见效，但这是你全年做项目时的**总体目标**：想想你的愿景是什么？我这一年要怎么调整这个？

### 六、本课产出

作为引导者，问自己：**我的愿景是什么？** 转变思维是全年持续的工作——用 F_4.1 的话说，"改变一种思维模式并不容易……但作为引导者，我希望你们在学年开始时思考这个问题，想想如何转变学生的思维模式，让他们为我做到最好，同时为未来做好准备。"

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》第 1 章——项目制学习，颠覆传统课堂

**老师的角色变了**：老师不再是内容专家，只会把知识一点点教给学生；学生的行为也变了——不再一味地被老师牵着鼻子走，而是**提出自己的问题，并为之创造意义**；教室的界限也变了——学生拥有更多的自主权，最终利用科技获取和分析来自世界各地的信息。

**为什么必须变**：现在的雇主寻找的候选人，是知道如何开展团队工作、懂得变通、能够获取和分析信息、创造性地思考和解决问题的人。**知识内容再也不是稀缺的资源，学生不需要我们提供信息；但他们比以往任何时候都更需要我们——帮助他们学会思考、学会如何钻研、学会如何应用知识。**

**运用项目制学习的 8 大思考（教师自我转变清单）**：

1. **你的学习目标**——准备好重新思考你对学生的期望
2. **你和学生互动的方式**——走下讲台，让学生更加自主，不一定要所有人都同时做同一件事情，适应"更混乱的学习"
3. **你的课堂管理风格**——帮助学生更好地管理他们自己的学习
4. **你对教学环境的布置**——重新配置课桌、电脑等，以促进团队合作
5. **你对评估的看法**——重新评估你在学习过程中需要注意的事项
6. **你对社区资源的看法**——将学生与课堂外的专家和其他资源联系起来
7. **你要收集什么样的学习成果**——重新思考哪些成果值得评估、值得用来触发复盘
8. **你如何与家长和同事沟通**——解释你采取项目制学习的理由，让家长和社区成员找到支持项目的方法

**高质量项目制学习框架（2018）的 6 项准则**：智力挑战与成就（学生深入学习、批判性思考、追求卓越）；真实性；公开产品（作品被公开展示、讨论和评论）；协作（面对面或通过网络，接受导师和专家指导）；项目管理；复盘。

**巴克"黄金标准"的 7 个基本项目设计元素**：挑战性难题或问题；持续性探究；真实性；学生的话语权和选择；复盘；评论和修正；公开产品。

**"重建"课堂的关键点**：项目是课程的核心，而不是附加单元；学生参与真实世界活动，实践演练学科策略；科技是探索、合作、创造和沟通的工具；教师相互合作设计项目；好项目产生的能量会带来螺旋式效应。

## 🛠️ 落地工具：PBL 目标体系（50工具 《50个工具》工具2）

转变思维不是喊口号，要靠"目标看得见"来支撑——工具 2 把项目目标拆成三层，让学生知道自己在做什么、为什么做、做到什么程度：

```
┌──────────────────────────────────────────────────────┐
│  PBL 目标体系（《50个工具》工具2）                                 │
│  项目目标：解决核心驱动问题 = 项目的终点                │
│    例：如何设计既防病毒又防雾霾且兼顾舒适的口罩？        │
│        → 项目目标：设计出这样一款口罩                   │
│  课程目标：学科知识怎么在项目中落地（查教材+查课标）     │
│    例：数学"包装的学问"→ 立体图形表面积、体积计算       │
│  核心素养目标：BESMART 七维能力中选，不超过 3 项         │
│    例：创新思维 + 协作能力 + 批判性思考                 │
└──────────────────────────────────────────────────────┘
```

**为何三层**：项目式学习有两个关键词——"项目"和"学习"。到达目的地（完成项目）只是基本要求，更重要的是帮助学生习得知识、提升素养（学习目标）。目标体系也是**项目评价的依据**：教师以各项指标的达成情况衡量项目的质量和成效。一切教学活动均需围绕目标的达成而设计，**避免开展过多与目标体系无关的教学活动**（否则费事、费力但无效）。

**使用步骤**：
1. **确定项目目标**：把核心驱动问题翻译成可交付的成果。例："有爱的包装盒"项目 → "为我爱的人选择礼物，并用最少的材料制作包装盒"
2. **确定课程目标（查教材）**：跳出单个知识点，从大单元视角看知识联系——锁定新知识、旧知识、拓展性知识。例：五年级"包装盒"项目，画平面图用到四年级"三视图"（旧知识），长方体表面积体积是五年级内容（新知识），圆柱体表面积体积是六年级内容（拓展知识，可做微课自学）
3. **确定课程目标（查课标）**：最简便的方法就是研读国家课程标准，**引用课标原话描述**，而不是按自己的理解写——既不准确，又增加工作量
4. **确定核心素养目标**：从 BESMART 七项能力中选择与本项目最相关的，**原则上不超过三项**（维度太多会增加后续评价的复杂性）
5. **公示给学生**：把三层目标做成项目墙，让学生随时能回答"我们在做什么、为什么做"

> 💡 **研学场景示例**：
> - 主题"西湖水质探究" → 项目目标："产出一份西湖水质分析报告及保护建议"；课程目标：科学（水质检测指标、pH 值）、数学（数据统计与图表）；素养目标：批判性思考 + 协作（≤3 项）
> - 主题"良渚文化策展" → 项目目标："为良渚博物院设计一场面向同龄人的微展览"；课程目标：语文（解说词）、历史/道法（良渚文明）、美术（展陈设计）；素养目标：沟通表达 + 创新思维
> - 主题"布达佩斯展导览" → 项目目标："制作一份可扫码收听的双语导览"；课程目标：外语（导览词）、美术（作品赏析）、信息科技（音频制作）；素养目标：沟通 + 信息素养

## 📖 案例（行动者手册）

### 深圳光明中学《设计思维》校本课程：从"被动听课"到"主动创造"

**背景**：深圳市光明区光明中学的方庆老师参加设计思维培训后，在高中开设《设计思维》校本课程（每周一课时，13 周），驱动性问题："做一个创新作品，参加区市创客节比赛"。**第一期不太成功，第二期比较成功**——转变的关键之一，就是先转变学生的思维和文化。

**过程**：课程成员来自高一高二不同班级，相互不熟悉，且"公立学校学生实践机会少，协作机会少，平等分享和接纳意识不强"。老师设计了团建活动营造设计思维文化："确认彼此眼神，发现对的人"（根据特征表找同伴，10 分钟破冰）；"吸管船"挑战（每人先画至少 4 个设计图 → 交流选定方案 → 实施 → 调整再实践，40 分钟完成并复盘）。随后用"同理—定义—创想—原型—测试"五步法推进：以"同学手臂受伤"为例讲解五步——感同身受是同理，做安全防护是定义需求，想几个方案是创想，做防护网是原型，让他试一下是测试；测试后可迭代，也可能要重新定义。**5 位懂编程、电路、3D 打印、激光雕刻的学生提前接受工作坊培训，在正式课程中担任助教**，为 29 人、8 个小组（每组 2-4 人）提供即时支持。

**结果**：学生产出了设计草图、创客作品、小发明等个人成果，团队携一系列发明作品参加光明区创客节、深圳市创客节。学生从"等老师教"变成"自己定义问题、动手解决"。

**启示**：这个案例示范了 F_4 的两个要点——转变思维要**从建立关系和文化开始**（团建、破冰、接纳），而不是直接布置任务；同时"学生助教"机制让有专长的学生从被动学习者变成主动贡献者，正是"从学习到完成、从热情到应用热情"的缩影。它也提醒我们：**转变不是一蹴而就，第一期不成功、第二期成功，是常态**。

**题 2（判断）**：学年开学第一周，以下哪种做法更有利于转变学生思维？
A. 直接宣布项目任务和评分标准，强调作业截止日期
B. 先做一次"天才一小时"：让学生找一个感兴趣的话题，快速头脑风暴解决方案

<details><summary>答案</summary>

</details>

**题 3（判断）**：你发现班上一个学生总是说"我做不到""这个太难了""反正我学不会"。请分析这个问题，并给出应对。

<details><summary>答案</summary>

两层分析：(1) 表面是能力问题，实质是**思维模式问题**——固定型思维把"现在做不到"等同于"永远做不到"，这在长期"训练听话"的环境里很常见；(2) 老师的语言和态度是塑造因素——F_4.1 说"你的语言和你的态度"是转变思维的抓手，要持续鼓励从"我做不到"到"我能行，我能找到策略，我能找到方法去克服"。应对：用成长型语言回应（"你还没做到，我们可以一起找策略"）；设计一个低门槛成功任务让他体验"完成"；把项目拆小让他获得效能感。
</details>
