## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、团队中一定会出现的两种现象

当人们在团队或小组中工作时，会出现某些特定的现象，Tom 点名了两种：

**1. 社会惰化（social loafing）**："当一群人在一起时，有些人会干活，而有些人会躲在干活的人后面偷懒。"这在成人的小组和团队中会发生，在孩子身上也会发生——14 岁的、小学生，任何年龄段都一样。**你得靠教练技巧来应对**，光靠工具不行。

**2. "异类"**："不可避免地会有所谓的'异类'——有行为问题的孩子、不想参与团队的孩子、不想干活的孩子、会捣乱的孩子。"你不仅要用团队工具，还得有方法来处理团队中的"教练部分"。

关键心态："某种程度上，你会看到，并不指望你会有个一帆风顺的体验，因为你在教练和教授一项困难的技能——与人相处并让他们高效工作的技能。这是人生中的一件大事，培养这些技能需要时间。"Tom 的忠告：**别指望完美，给它时间**。"学年开始时你会看到一套完全不同的技能，而学年结束时孩子们能做到的又是另一回事。"把它看作一个过程，在几个项目中给学生时间发展能力、反思方向、纠正行为。

### 二、教练的角色：人员管理，不是课堂管理

P_12.1 的第一条原则："教练的角色对你有什么要求？首先，是**人员管理技能，不是课堂管理**。你在 PBL 项目里管理的是人，不是课堂。"

这意味着你自己得有良好的沟通能力，一种**能激发而非激怒的教学风格**——"你怎么激发人们最好的一面，而不是惹出最坏的一面？"部分通过关注**成长心态**：重视成长的过程而不是最终结果。

### 三、教练技能组合：四个原则（P_12.1 核心）

1. **全神贯注**：老师被训练得会说，不太会听——"你得做个好听众。"
2. **接受局限**："你只能教练某些情况，其他事情你改变不了，就得放手。"
3. **用协议**：让学生指出他们的问题，从积极面出发，给他们正面反馈，并给他们**行动的方法**——"真正用你给他们的反馈去做点什么，并给它一个积极的调调。"
4. **定期沟通**：经常和你的团队沟通，别让他们太久不跟你聊。稍微探探："他们有没有什么问题？有没有什么困难？问问他们。"**仔细听团队在告诉你什么**——如果他们告诉你有些问题，停下来，和他们深入讨论怎么解决，"因为这些问题肯定会冒出来"。

### 四、在教练与直接教学之间切换

"你在教练团队走向精通和成功，所以你始终关注成长和过程，但也让他们按截止日期交活。里程碑、期望他们按时完成工作——因为在校外世界里，截止日期很重要。"通过执行截止日期为学生准备好面对那个世界。

**但"不是所有时候都教练"**："有时候你在项目里就得直接教。如果你需要把直接教学放进去，就教内容，准备考试。有时候你会发现团队迷失了，因为他们没有正确的信息——给他们一个及时的课程。"所以：该教内容时直接教，该辅导时辅导。

### 五、用评分标准持续训练"职业道德"

"职业道德，用评分标准持续训练学生。记住，你想让他们准备好面对生活，用职业道德评分标准来评估。"Tom 展示的职业道德评分标准"包含了所有不同的技能，底部还有同理心"——"因为除非你尊重彼此、对彼此有点善意，否则你不可能成为好团队成员。如果不这样，你的团队就会争吵、争论，不会产出他们该产出的东西。"

即使是 K-2 的小孩子也可以用评分标准："他们可以圈这些项目，能感受到在团队里好好合作是什么意思。"填完后他们就能了解自己的团队合作技能怎么样、怎么在培养这些技能。

### 六、"爱那些异类"：把问题行为变成指导机会

"你不可避免地会遇到一些真的不想在团队里干活的学生，或者不擅长团队合作的学生，或者有各种问题阻碍他们参与团队工作的学生。那些'异类'，我建议你去**爱那些异类**，想办法绕过去，而不是让他们把你逼疯。"

项目式学习在团队中的一个巨大优势：**学生会在我所说的他们熟悉的环境中工作，所以他们真实的行为会显现出来**。那时你有一个选择："你可以说他们妨碍了我的教学，或者现在我有机会去指导他们。"——喜欢那些特立独行的学生，抓住机会去指导他们，帮助他们在学校表现得更好。

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》第 8 章——签署团队合同，管理团队冲突

**团队合同"改变了一切"**：许多隶属于新科技系统的学校把"团队合同"的理念结合在团队合作中。项目开始时，团队成员对自己的角色和职责达成一致，签署一份合同，**写明成员忽视这些职责的后果，比如被团队"解雇"**。保罗·柯蒂斯（新科技学校网络）解释："现在，进行团队合作就有了来自团队成员的压力。团队成员的压力不会允许'懒虫'的存在。这与传统课堂大不一样，因为传统课堂会宽容懒惰的人。他们会降低学习曲线和期望值。但是，当学生开始在团队中工作时，懒惰的人就会成为整个团队的真正麻烦。他们有压力了。"

**把团队合作作为正式评估的重点**：一些教师要求学生根据团队合作评分准则评价团队中的同伴；不太正式的形式是让学生在项目日志中对团队合作进行复盘；项目结束时，让学生思考将来如何选择队友，并描述自己为团队提供的技能（自我评估）。

**数字握手（digital handshake）**：当项目把来自不同文化的学生联系起来时，维基·戴维斯和朱莉·林赛建议用"数字握手"启动全球项目——通过视频、电子邮件、Skype 或 VoiceThread 交流，打破僵局，开启共同学习。

**提问是冲突预防的前哨**：研究人员发现教师提出的问题中约 60% 是低阶问题（重述事实），20% 是高阶问题（评估分析），20% 是程序性问题。PBL 课堂需要高阶问题成为常规——"你是怎么知道的？你注意到什么了？多告诉我一点……"。教师提问后平均等待时间只有 1 秒甚至更少，而"教师愿意等待答案的时间越长，学生的参与度和表现就越好"。

**四类常规检查问题**（对应你要关注什么）：
| 类型 | 问题示例 |
|------|---------|
| 程序性问题 | 我们是否在按计划的时间进行？有现成材料吗？ |
| 团队合作性问题 | 成员相处得如何？一个学生是否为整个团队承担了太多？学生自己能处理冲突吗？ |
| 理解性问题 | 学生是否偏离了任务、根据错误信息做了决定？ |
| 自我评价性问题 | 学生对项目的看法如何？（项目日志/博客提供安全空间） |

## 🛠️ 落地工具：托马斯-基尔曼冲突决策模型（《50个工具》工具49）

### 工具卡

```
            关心自我 →
           坚持            不坚持
  合作   │  合作（双赢）  │  迁就（自我牺牲）
  ↑      │                │
 关心他人│                │
  不合作 │  竞争（强迫）  │  回避（忽视）
```

五种冲突处理方式：**竞争**（坚持，不合作——争取对自我或团队更有利的方案，迫使对方放弃）；**回避**（不坚持，不合作——事情解决与否影响不大，选择忽视）；**合作**（坚持，合作——既维护自身利益又兼顾对方，双赢）；**迁就**（不坚持，合作——自我牺牲满足对方）；**妥协**（中间——双方各让一步，暂时缓解）。

**冲突并不等于吵架**：冲突有多种来源——时间冲突（会议时间重叠）、资源冲突（两个小组抢设备/预算）、观点冲突（小组讨论出现不同观点）、利益冲突（顾了这组那组受损）。"能够有效地处理冲突是项目管理中的重要能力。妥善解决每一个小冲突，就不会产生更大的冲突。"

**使用步骤**：
1. **识别冲突类型**：时间/资源/观点/利益——先别急，说清楚冲突是什么
2. **结合"要事第一"分析双方需求**：这个需求是"重要且紧急"还是"重要但不紧急"？（例：实验室被占——我方实验结果是下节课依据 = 重要且紧急；对方数据下周才用 = 重要但不紧急 → 可竞争）
3. **分析各策略的结果**：好 / 不好不坏 / 不好（例：原定去 A 地考察，有人提议改 B 地——B 明显更好则迁就；不好不坏则按双方意愿竞争/回避/妥协；B 弊端很多则竞争坚持原计划）
4. **决策并复盘**：把选择过程讲给团队听，让冲突处理本身成为学习机会

> 💡 **研学场景示例**：
> - **西湖研学**：两个小组都想在"苏堤春晓"点位拍摄（资源冲突）——A 组方案依赖早晨光线（重要且紧急），B 组可调整；按模型 A 组竞争优先，B 组迁就换点位，事后 B 组在分享会上说"我们学到了取舍"
> - **布达佩斯展**：导览内容中"重点讲文物历史"还是"重点讲中匈文化对比"争执不下（观点冲突）——用"合作"策略：主展线讲历史、互动区做文化对比，双方利益都满足
> - **良渚博物院**：有学生觉得"画玉器纹样太麻烦，想直接打印"（与团队质量标准冲突）——教师引导团队按"结果好不好"分析：打印图与手绘纹样对观众的感染力差异，最后团队用"妥协"：手绘核心纹样 + 打印补充资料

## 📖 案例（行动者手册）

### 写作项目危机：当学生不敢把自己的作品发上网

《PBL项目制学习》第 8 章记录的安妮·戴维斯案例，是"教练 + 团队干预"处理危机的完整示范。

- **背景**：佐治亚州教育工作者安妮·戴维斯是"把博客引入小学课堂的先驱"。她在提高学生写作能力的项目中，把 4、5 年级学生与另一个州的高中生配对，让高中生当小学生导师。
- **过程**：起初学生很开心有人会看自己写的东西。但当把文章发布在网上时，她的学生却愣住了——"教室里完全静止了。我看出有些不对劲。"通过询问，她发现学生都很惶恐："他们担心自己写得不够好，高中生不想看。"另外，高年级学生写的故事似乎都太长，低年级学生不想参加比赛。
- **结果**：戴维斯的反应是"我的情绪瞬间高涨！我的学生希望能写出好东西。这是他们第一次真正在意自己的写作。"她与合作教师威尔·理查森交流，高中生们集思广益，通过网络为小学生消除焦虑，还创建了微型课程，把写作项目分解成小块任务，让学生不那么胆怯。项目成功推进。
- **启示**：① 学生"愣住"不是捣乱，而是真实的恐惧信号——教练的第一动作是**问**（"出什么事了？"）而不是惩罚；② 问题不一定靠教师解决——让更有经验的同伴（高中生导师）介入，比教师单方面鼓励更有力；③ 把大任务拆小（微型课程、小块任务），是化解"不敢做"的通用药方。戴维斯的总结正是本课主题："课堂讨论必须是一个重要组成部分。你不能只是告诉你的学生，'进实验室，然后开始写吧。'你必须建立学习者共同体，也必须在开展的过程中跟他们谈谈正在发生的事情。"

## ✅ 自测（自我检查，做完即看答案）

**题 1（改写）**：你的"西湖水质守护者"研学团队中，小组成员小 W 连续两次缺席采样（先称生病、后称作业多），其余成员开始互相埋怨。请设计一个干预方案：写出你会（a）用的协议句式（从积极面出发）和（b）依据托马斯-基尔曼模型做的冲突类型判断与策略选择。

<details><summary>参考示例（先自己写再看）</summary>

(a) 协议句式：先一对一沟通——"我们注意到你缺席了两次采样（事实），是遇到什么困难了吗？"（倾听）→ 从积极面出发："你上次记录水质数据很认真，我们很需要你的观察力"（正面反馈）→ 给行动方法："这周六补采一组数据，或者负责整理本周数据报告，你选哪个？"（让他自己选择行动）。如果团队已经怨气很大，用小组会议："我们怎样才能让大家再次积极行动起来？"（巴克第 7 章句式）。(b) 冲突类型：这是"责任/利益冲突"（个人事务与团队任务争夺时间）；策略：先回避（不在群里公开批评）→ 迁就一次（允许补做）→ 若再犯，按小组公约或团队合同的"解雇条款"处理。判断标准：先倾听再给选择、先私下再公开、有升级阶梯。
</details>

**题 2（判断）**：团队讨论方案时，以下哪种教师介入更好？为什么？
A. 直接告诉学生"按 B 方案做，别争了"
B. 问"你们各自的方案分别能解决什么问题？我们怎么把两者结合？"

<details><summary>答案</summary>

B。P_12.1 教练原则："仔细听你的团队在告诉你什么……停下来，和他们深入讨论怎么解决。"直接拍板（A）是在做"课堂管理"而不是"人员管理"，学生没有学会解决冲突；B 是教练式提问：让学生自己指出问题、从积极面出发、寻找行动方法。这也符合第 8 章的高阶问题标准——"多告诉我一点"式提问推动高阶思维。注意：B 的前提是问题在可教练范围内；如果团队因缺少关键信息而卡住，则应切换为直接教学（"不是所有时候都教练"）。
</details>

**题 3（判断）**：一位老师发现小组里有学生"搭便车"，于是在全班批评了该学生，并说"再这样你就别做了"。请找出这个问题的问题（两层以上）。

<details><summary>答案</summary>

第一层（表面）：当众批评羞辱了学生，违背"能激发而非激怒"的原则，只会让"异类"更抗拒、更孤立。第二层（机制）：教师直接解决 = 剥夺了团队自己的压力机制——团队合同的作用就是让"团队成员的压力不允许懒虫存在"，教师介入太早太猛，团队永远学不会自我管理（巴克第 7 章："学生应该知道，只有当他们整个团队一起还协调不好的时候，他们才该找教师介入"）。第三层（归因）：没有先弄清楚"为什么"——是故意偷懒，还是不会做、没资源、不敢说？（参考戴维斯案例：学生"愣住"背后是恐惧）正确顺序：先私下倾听找原因 → 用协议从积极面出发 → 给行动方法 → 仍无效则升级到合同条款（解雇/同伴压力法）→ 最后才考虑家长与评分系统。
</details>

**题 4（自查·本课产出）**：为你的研学团队写一份"危机预案"：
1. 预判 3 个可能出现的团队问题（如：社会惰化、角色冲突、外部干扰）
2. 为每个问题写出你的第一反应（对照"先倾听-再协议-后升级"顺序）
3. 检查：你的团队有合同/公约吗？有"解雇条款"或替代机制吗？

<details><summary>自查指引</summary>

- 第一反应是不是"问"而不是"骂"？P_12.1 的协议是：让学生指出问题 → 正面反馈 → 给行动方法
- 你的预案里有"升级阶梯"吗？（私下沟通 → 小组会议 → 合同条款 → 家长/评分）不要第一步就跳到最强手段
- "异类"条款：你打算怎么"爱那些异类"？有没有安排一个能发挥他特长的角色？
- 记住 Tom 的话：别指望完美，给它时间——学年开始和学年结束，学生的团队技能会完全不同
</details>
