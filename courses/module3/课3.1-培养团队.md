## 📌 本课导读

项目式学习到了实施阶段，第一个拦路虎往往不是内容，而是"人"——学生不会自动变成一支高效团队。Tom Markham 说得直接：教育里最常用的词是"群体"和"小组作业"，但你要用"团队"来思考，因为**团队意味着群体所没有的责任感和绩效水平**。本课整合三套资料：**视频课 P_11/P_11.1** 讲"怎么想"（从群体到团队 + 谷歌研究的软技能清单）、**巴克《教师指南》第 5 章**讲"教师作为项目经理"的角色与检查点设计、**《50个工具》工具 4 和工具 16** 给"落地卡"（角色设定表 + 小组公约）。学完本课，你应该能拿出自己团队的组建方案。

## 📖 主线正文（整理自视频课 P_11 / P_11.1）

### 一、为什么必须从"群体"走向"团队"

这个体验的标题是"训练你的团队"，也可以叫"如何从群体走向团队"。Tom 承认："我知道'群体'和'小组作业'是我们教育中最常用的术语，大多数 PBL 老师自己也用这些词，甚至我自己偶尔也会这么说。"但关键区别在于：

- **群体**：一组人凑在一起，各干各的
- **团队**：有共同目标、有责任感和绩效水平，成员彼此依赖

**现实世界的证据**：在工业和职场中，第一技能就是协作和在团队中工作的能力。工业界每年花费数百万美元培训新毕业生如何在团队中工作。"从某种程度上说，到 18 岁真的没必要这样。"学生没有理由不能在离开学校时，就已经有了丰富的团队工作经验、良好的反馈和培训——他们知道良好协作的原则，并且有机会在项目中实践。

Tom 也理解老师的恐惧："你真的不需要担心或害怕团队合作，因为有时候老师确实觉得让学生团队合作是个问题——很难控制，会出现各种捣乱行为。是的，会有。但你现在有一些工具。"

### 二、谷歌研究：软技能驱动良好团队合作

P_11.1 的开场是一张幻灯片——谷歌研究团队成功靠什么的数据：

> **软技能、平等、慷慨、好奇心、同理心、情商，还有不欺负人。**

"换句话说，软技能驱动了良好的团队合作。这对我们来说是个很好的启示。"我们不只是在通过团队教解决问题、教学术卓越——那些是目标——**我们还在教软技能，教学生真正变得更高效**。在整体社交学习方面，我们在教他们更深层次的协作：怎么真正和睦相处，怎么互相尊重。

Tom 特别关注**同理心**，这是当今教育界的大话题。学生在团队中学到这些：轮流发言、在多元化团队中工作、练习良好的社交技能、实践谷歌发现的那些品质——谦逊、尊重。一旦他们掌握了这些软技能，就能真正实践**深度协作**：

> 争论、设计、讨论、研究、一起反思——列表里没有的还要加一条：**一起解决冲突，冲突化解**。

### 三、组建团队的操作清单（P_11.1 核心）

1. **团队规模 3-5 人，不要两人一组**——为什么两人一组不够？"因为产生不了足够的冲突。"你真的希望学生互相合作，有很多东西可以讨论。
2. **可以用角色分配**，但你可能得在进入团队合作之前教他们基本技能：倾听、反馈、眼神交流、肢体语言、怎么协商、怎么贡献、怎么负责、怎么解决冲突——把团队合作拆解成各种技能来教。
3. **让他们知道为什么**：一旦组好了，确保他们知道团队合作在当今世界至关重要。
4. **为抗拒的学生做好准备**，尽量让所有学生都留在团队里，别让他们单独干活。
5. **给充足的结构和目标**：规则、指导方针、行为规范——"我们怎么对待彼此？我们怎么互相尊重？我们要对彼此友善吗？"
6. **项目开始时介绍团队合作评分标准**，锚定期望——他们知道具体期望是什么、团队表现怎么评分，"你非常重视这件事，他们也清楚"。这份评分标准可以按自己的目的修改，它只是一个模板。
7. **签契约**：学生在开始时坐下来，在团队里说，"这是我们打算做的，这是我们怎么表现的，如果我们不表现，就会发生什么。"有时候团队喜欢加入**"解雇条款"**——如果团队里的学生没有履行义务、不负责任，其他团队成员可以真的解雇他们。"它确实管用，效果很好。"
8. **用项目墙**（尤其六年级以下）给团队焦点，确保他们知道日程安排和里程碑。
9. **复杂任务需要时间**："你不能光分配任务就以为他们能马上搞定，你不能真的催他们。"可以用设计思维，或某种解决问题的办法，给团队时间去工作。
10. **总是给每个团队成员一个个人成果**：如果有团队成果当然好，但一定要有个人成果来捕捉个人表现——"否则如果只有团队负责他们的成绩，学生会很焦虑。"
11. **把沟通作为任务的一部分**：他们有没有互相分享草稿想法？有没有用协议交流？推荐一个简单协议——**"我喜欢，我好奇，我建议"**（一个团队向另一个展示，或一个成员向另外两个人展示），"用起来效果很好，对团队特别管用"。
12. **辅导**：你必须是一个有效的教练——这是下一课（避免团队危机）的主题。

### 四、两个易错点：个人成果与沟通协议

- **个人成果不能省**：P_11.1 特别强调"一定要有个人成果来捕捉团队中的个人表现"。理由很实际：如果只有团队分，学生焦虑；如果个人贡献不被看见，混日子的人没有压力。给每个成员一个"必须交"的个人产出（如个人反思日志、个人负责的调研板块）。
- **"我喜欢，我好奇，我建议"协议**：展示方陈述 → 反馈方每人一句"我喜欢……（具体）"、一句"我好奇……（提问）"、一句"我建议……（可操作）"。它让反馈结构化、不伤人、可执行，是团队沟通的入门协议。

### 五、给老师的心态：这是行业标准

"从群体到团队，我们强调责任感和凝聚力，我称之为**行业标准**——教学生朝着共同目标努力。'团队'这个词比'群体'更有分量。"把团队合作当作**要教的课程内容**，而不是默认学生天生就会。你在训练学生为职场做准备——18 岁离开学校时，他们已经知道良好协作的原则，并有大量机会实践。

## 📚 深度阅读（书籍精华）

### 巴克《项目学习教师指南》第 5 章——管理项目过程

**教师在项目中的角色**：教师作为项目管理者，将扮演各种不同角色——要预见这一点，并在项目开始时和学生讨论清楚职责。关键管理任务清单：

| 任务 | 要点 |
|------|------|
| 引导学生聚焦目标 | 定期用驱动问题强化目标；时间跨度长的项目定期提醒进展；提醒"深入的学习需要时间和耐心" |
| 适当分组 | 可小组、可大集体、可先独立后合作；分组状况可随进展改变 |
| 组织每天的活动 | 帮助确定探究范围、发现解决途径；设定任务期限；收集过程文件；给予反馈 |
| 信息澄清 | 学生常问"下一步做什么""哪些必须知道"，教师要有准备、给清晰指导 |
| 监控和管理行为 | 教学生"在没有监管的情况下有效工作"；时间期限概念、做事要求和标准、时间管理方法 |
| 管理工作流程 | 及时收作业、关注进展、判断是否在通往成功的路上；必要时停下来即时指导（小讲座、讲义） |
| 评估项目成功 | 帮助学生认识到从项目中有哪些收获、还有哪些没学到 |

**关键步骤**：① 尽早分享项目目标（研究表明即使目标不是学生自己设定的，他们也会很投入）；② 和学生一起完善项目设计——可用**调谐规程（Tuning Protocol，又称关键朋友规程）**：两组各 4-5 人，A 组陈述 7 分钟 → B 组澄清提问 4 分钟 → B 组思考"暖问题"（积极角度）和"冷问题"（批判但不刻薄）→ 分别给反馈 → A 组回应，开放交流；③ 使用解决问题的工具（知道/需要知道清单、学习日志、项目简报）；④ 设计检查点和里程碑；⑤ 为评估与反思制订计划。

**设计检查点和里程碑的 10 种监控方法**：小组长非正式简要报告；快速书面评论；随机/选择会谈；调查统计；每周例会反思；检查已完成工作清单；检查项目日志；教师写自己的项目日志；参与小组监督进度；活动/作品完成时组织简要汇报。

**项目最终评估四方法**：全班情况通报会、鱼缸式讨论法（内圈讨论外圈围观）、问卷调查、自我评价。别忘了**庆祝会**——"当学生为了成功完成项目而投入了很多时间和精力，庆祝会能让学生拥有和体验成就感"，可邀请家长、社区成员、其他教师。

## 🛠️ 落地工具：小组角色设定表（工具4）+ 小组公约（工具16）

### 工具卡 1：小组角色设定表（工具4）

```
┌────────────────────────────────────────────────┐
│ 小组角色设定表                                  │
│ 第一角色 │ 主要职责 │ 成员姓名 │ 特长/爱好 │ 希望发展的技能 │ 第二角色 │
├────────────────────────────────────────────────┤
│ （示例：访谈策划 │ 统筹整个访谈计划 │ 小C │ 领导能力强 │ 写作 │ 记者）│
└────────────────────────────────────────────────┘
```

**为什么必须用**：项目式学习分组按角色进行，有五个特点——① 每个项目有不同的角色设定（戏剧项目要导演/编剧/演员/服装师/道具师/场务；出书项目要主编/文编/美编/宣传发行员）；② 每个团队有清晰的角色划分；③ 每个成员有明确职责；④ **有第二/第三角色**——避免"长板恒长"（会画画的永远画画，没有机会锻炼其他技能）；⑤ 分组方式不是一成不变的，可随项目阶段调整；班级内可用平行小组（各组装同样角色、公平竞赛）或并行小组（各组件不同职能、汇总成班级成果）。

**使用步骤**（三阶段）：
1. **角色定义**：根据项目成果类型定义团队角色（成果是人物访谈 → 访谈策划/记者/录音师/撰稿人/音视频编辑），填表格第一列
2. **角色阐释**：学生受生活经验所限不了解职业，用讲解、视频、现身说法帮他们理解职责，完成"主要职责"列
3. **角色认领**：让学生按兴趣选择角色，而不是强行分配——"因为选择，所以专注"（蒙台梭利）；抢手角色用"角色竞选"或多志愿填报，避免落选打击

### 工具卡 2：小组公约（工具16）

```
┌────────────────────────────────────────────────┐
│ 问题区（小组合作中可能遇到的问题）                │
│ ·团队成员无法达成一致 ·团队成员互相埋怨          │
│ 公约区（小组公约的常用语）                       │
│ ·小组成员应…… ·讨论时应…… ·赞同观点时可以……   │
│ ·小组合作时，鼓励…… ·反驳观点时可以……          │
└────────────────────────────────────────────────┘
```

**为什么学生自己定的公约才有效**："没有规矩，不成方圆"，但"要实现纪律，必须通过自由"（蒙台梭利）。公约不是教师单方面宣布的冷冰冰条例，而是学生自主制定、共同遵守的约定。**关键洞察**："学生其实什么道理都懂，只是不愿意遵守——因为他们总是被要求、被强迫、被惩罚，而很少有人告诉他们为什么要遵守。"让学生先发现问题、再用公约解决问题，他们就知道为什么遵守，也愿意遵守自己主动制定的规则，还会相互监督。

**使用步骤**（四步）：
1. 先达成一致：约定一旦确立，所有学生必须遵守
2. 带领学生预测：团队合作中可能遇到什么问题？（把能靠约定解决的问题筛选出来）
3. 提供常用语/样例，让学生自己拟订条款，再筛选归类、投票保留
4. 全体宣读、签字承诺，项目结束前共同遵守；出现问题时可修订

> 💡 **研学场景示例**：
> - **良渚博物院研学**：成果是"玉器讲解剧"，角色设定为编剧、导演、演员、服装道具师、音效师；平时不爱发言但动手强的学生认领道具师，第二角色填"讲解员"（希望发展表达能力）→ 用小组公约解决"排练时有人迟到、台词背不熟互相埋怨"的问题
> - **西湖水质调查**：团队 4 人 = 采样员、实验记录员、数据分析员、报告撰写人，每人再加一个第二角色（如"摄影记录"）；公约条款示例："采样时鼓励分工合作，不鼓励单独行动""反驳观点时可以陈述理由，不可以用情绪"
> - **布达佩斯展双语导览**：5 人团队按导览流程设"展厅讲解员（中/英）""动线设计师""文物资料研究员""互动活动策划"，签约时加入"解雇条款"——连续两次缺席排练的成员，经全组投票可被"解雇"并转做独立任务

## 📖 案例（行动者手册）

### "故宫十二时辰"戏剧项目：角色设定如何撑起一台大戏

《50个工具》记录的"故宫十二时辰"项目，最终产品是一出戏剧——这是工具 4 角色设定思路的完整示范。

- **背景**：项目成果是戏剧，团队必须按戏剧生产的真实职业来配置角色：导演、编剧、演员、服装师、道具师、场务。除了戏剧组，还有信息收集组和模型组。
- **过程**：信息收集组内再分信息搜集员、报告撰写者、演示文档制作者；模型组内分绘图师、材料收集者、模型搭建者。每个成员都有明确的第一职责——小 B 担任导演就统领整个项目安排，小 C 担任道具师就对道具的选择、制作、使用全环节负责。同时每个人都登记"希望发展的技能"，获得第二角色，让"长板"之外也有"短板练习"。
- **结果**：戏剧的每一个环节都有人负责、有人补位，学生既体验了真实剧组的分工，又没有困在单一技能里；角色随项目阶段调整——剧本编撰阶段按写作需求划分，排练阶段按演出需求重新划分。
- **启示**：角色设定表不是"排座位"，而是把真实职业世界的分工逻辑搬进课堂；第二角色解决"长板恒长"，角色竞选解决"抢手岗位"，多志愿解决"落选失落"——育人功能优先于效率。

**题 3（判断）**：一位老师只给小组打分，没有给个人成果。请找出这个问题的问题（两层以上）。

<details><summary>答案</summary>

第一层（表层问题）：学生焦虑——P_11.1 说"如果只有团队负责他们的成绩，学生会很焦虑"，因为个人努力无法被看见和承认。第二层（深层问题）："社会惰化"被制度性鼓励——没有个人成果，混日子的学生没有压力，努力的学生觉得不公平，团队责任感瓦解。第三层（结构问题）：评估无法区分个人表现，教师后续的辅导和反馈（下一课 P_12 的核心）失去了依据——你都不知道谁在贡献、谁在偷懒，就无法"评估团队中每个人的职业道德"。改进：团队成果之外，必须给每个成员一个个人成果（个人负责的板块、个人反思、个人展示环节）。
</details>

**题 4（自查·本课产出）**：为你自己的研学/课程团队完成组建方案：
1. 用小组角色设定表定义角色（第一 + 第二角色），并写出认领方式（竞选/志愿）
2. 和学生一起制定 5 条小组公约（含问题区）
3. 检查：是否给了每个成员个人成果？是否在项目开始时介绍了团队合作评分标准？

<details><summary>自查指引</summary>

这是本课最重要的落地产出。对照清单：
- 角色覆盖了项目的全部关键任务吗？（缺角色 = 项目环节没人负责）
- 第二角色填的是"希望发展的技能"而不是"随便补位"吗？
- 公约是学生自己发现问题、自己拟订的吗？（如果是老师写好让学生签字，就失去了工具 16 的意义）
- 个人成果是什么？能不能在项目中途"看见"每个人的贡献？
- 评分标准有没有在项目开始时锚定期望？（没有 = 学生不知道"团队表现怎么评分"）
</details>
