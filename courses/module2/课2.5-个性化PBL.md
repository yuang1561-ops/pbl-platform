## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、教育领域的三大趋势

**趋势一：项目式学习**——以及所有相关活动：创客空间、设计思维、基于地点的学习、基于挑战的学习等等。

**趋势二：社交情感学习和幸福感**——我们渴望帮助年轻人发现**自身内在的优势**，那些能帮助他们在未来生活和工作中取得成功的个人资源。

**趋势三：个性化**——帮助每个学生找到自己的学习路径。这在当今世界是不可避免的：**有太多不同的选择、太多不同的可能性、太多人们学习的方式**——这些只会不断增加，所以我们需要准备好个性化我们的教学、个性化我们的教育体系。

### 二、好消息：PBL 和个性化完美契合

产品和学生自主性的**灵活性**、**学生的声音**、**学生的选择**、**辅导**——所有这些术语都和项目式学习以及个性化相关。所以：

> **当你做项目时，你已经在个性化教学了，你已经在融入很多个性化的原则**——这些在未来会变得至关重要。

### 三、四个做法：让个性化在项目里真正发生（P_8 核心）

**做法一：超越标准来教学（teach above the standards）**
- 如果你过于担心教授课程中的每一个标准，你就没有时间让人们做好项目式学习，也无法实现个性化
- **超越标准教学，这是第一步**

**做法二：尽可能从主题转向概念**
- 如果你熟悉基于概念的教育，你会知道它和项目式学习非常契合
- 例子：**光合作用**是一个主题；"**光合作用如何影响森林砍伐**"是一个概念；**工业化**是一个主题；"**工业化如何融入现代生活**"是一个概念
- 转向概念非常有帮助——概念是开放的理解框架，不同学生可以在不同深度和方向上探索

**做法三：为第二语言学生进行个性化**
- 几乎每个地方的每位老师都有第二语言学生，所以我们需要个性化
- Tom 自己受过英语作为第二语言教师的培训："我对此略知一二"
- 他不打算把这一课变成"如何在 PBL 中使用第二语言技巧"的课，但提醒：**进入这次体验中的资源时好好看看**——有很多人在这个领域做了很好的思考，资源都已包含进去。如果你课堂上有大量第二语言学生并且他们参与了项目式学习，请阅读这些资源并仔细看看

**做法四：做一个人类学家，而不是考古学家**
- 这听起来有点奇怪，但意思是：当你进行个性化时，**你必须是一个善于观察人类行为的人**——这就是人类学家的工作：观察人类，观察人类行为
- **不要只关注学生创造的产品、事物、测试或材料，而是专注于观察他们、注视他们**——这会帮助个性化教学

### 四、本课小结

"这些是你在课堂上实现个性化的方法。"——Tom 还提到"我还有一些其他想法，请看下一部分"（后续课程会继续展开）。记住四个关键词：**超越标准、主题转概念、关照第二语言学生、做人类学家**。

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》第 4 章——设计灵活，为不同的学习路径创造可能

**芬兰奥卢市的启示**：一支跨年级教师团队希望拓展探究在学习中的使用——他们设计了一个利用**照相手机、GPS 和网络学习环境**支持探究学习的项目：学生团队收集并分析垃圾回收数据，观察家庭和社区的回收习惯，然后对学校的垃圾回收提出建议。教师帕斯·马蒂拉称结果是"有意义且有动力的学习"。这个案例说明：**项目规划需要批判性思维**——你可以调整他人设计并测试过的项目计划，也可以从头设计自己的项目，但都需要同样的批判性思考。

**审查他人项目的警示：项目设计中易犯的 6 大错误**：

| # | 错误 | 表现与对策 |
|---|------|-----------|
| 1 | 活动时间长，学习成果少 | 任务繁重却只达到低阶目标。**项目的繁简程度应该"刚好适合"任务**；如果学生通过简短讲座就能学会，就不适合做项目 |
| 2 | 科技重于传统实践 | "互联网上研究主题 + 幻灯片呈现"只是**经过装饰的研究报告**。科技要用来辅助真实学习目标（连接真实受众、连接第一手资料） |
| 3 | 单薄的主题单元 | 3 年级"海洋主题"——写报告、画海洋生物、数学课用贝壳学分数……这些任务**并非跨学科、非合作、非高水准**。同样是海洋：可以研究超市海鲜来自哪里、如何用可持续性记分牌计分 |
| 4 | 学习步骤过于详尽 | **最好的项目是让学生在学习中做决定**。警惕步骤过于详尽且衔接不自然的计划——学习成果会可预见且局限 |
| 5 | 对形成性评估关注不足 | **尽早并经常评估**，检查理解程度、调整教学计划 |
| 6 | 评估不够真实 | 真实项目应该用**类似真实世界衡量质量的方法**来评估——确保有真实观众和评委 |

**构建高质量项目的 9 个方式**：比较与对照（研究"破窗"警务并给市政厅提建议）、预测（饼干品牌口味测试预测市场占有率）、理解因果关系（分析交通事故数据库确定事故关键因素）、确定局部与整体关系（用 STELLA 建模行星生物圈）、着眼于随时间的变化（2 年级研究几十年前的市中心照片并对城市未来提建议）、辨别模式或趋势（4 年级测量一周被丢弃食物重量并用电子表格制图）、研究不同视角并变换观点（在新闻报道中区分事实与观点并写专栏文章）、做出合理判断或明智决策（食物偏好问卷→建议食堂改变餐食）、推陈出新（研究健康营养后担任"私人健身教练"定制健康方案）。

**设计灵活：船只项目（The Boat Project）的故事**——加拿大埃德蒙顿明洲小学教师谢里尔·韦希尔原本和团队规划了"海洋"主题单元。但一个特别活动改变了方向：孩子们被要求在学校穿沙滩服，活动中心提供了很多海滩相关的东西探索——**许多学生都被积木船模吸引**。韦希尔说："将海洋作为一个项目去研究实在太过宽泛了，因为这并不是这些孩子所见所闻的真实世界或真实体验。因此我们放弃了'海洋'……由于许多孩子已经在积木区搭船，通过讨论、提问、对话表现出浓厚兴趣，'船只'就被选作项目主题。"一个孩子大声宣布："**我们应该建造一艘船，一艘真正的船！**"——项目就此诞生。最终项目持续 7 周，涉及浮力、船只和设计（科学）、语言艺术目标，学生学会决策、团队合作并证明学习成果。

**阿瑟·戴安·麦格拉斯教授（退休教育学教授）的忠告**："要真正吸引学习者，你必须建立一种情境。在这种情境中学生想要提问，想要学到更多，想要知道他们未知的事物，并且相信这一切对他们来说很重要，对更大的群体来说，找到答案也很重要。你的项目不是让学生复制前人做过的实验。相反，**一个好项目是在前人所做的基础上的一种更深入的探究**，在这个探究过程中，学生会自己设计各种子问题，并且试图寻找如何解决这些问题的方法。"她建议中学科学教师设计受安德鲁·波斯特曼启发的"节能"项目："**我家如何才能减少 5% 的能耗？这样做需要付出的成本是多少？**"

**#MyParty12 / #MyParty16 项目**：两位对政治充满热情的教师（迈克尔·凯歇乐、乔·尤索）不教教科书上的政党知识，而是**向学生发起挑战去制定自己的党派纲领**，把立场观点以视频形式发布在 YouTube，用 #MyParty12 话题标签在 Twitter 推动势头，通过谷歌环聊与全美学生辩论。2016 年版本：学生制定纲领、制作竞选广告、在校园进行初选，每校获胜者参加全州选举。学生不仅了解民主制度，还积极参与、批判性思考、文明沟通。

## 🛠️ 落地工具：小组角色设定表（50工具 《50个工具》工具4）

```
┌───────────────────────────────────────────────┐
│  小组角色设定表（《50个工具》工具4）                         │
├───────────────────────────────────────────────┤
│  第一角色  │ 主要职责 │ 成员姓名 │ 特长/爱好 │ 希望发展的技能 │ 第二角色 │
├───────────────────────────────────────────────┤
│  导演      │ 统领项目安排 │ 小B   │          │              │ 道具师   │
│  编剧      │            │      │          │              │          │
│  ……       │            │      │          │              │          │
└───────────────────────────────────────────────┘
```

**为什么用角色分组**（项目式学习分组策略的核心）：

1. **每个项目有不同的角色设定**——"故宫十二时辰"项目最终产品是戏剧，就按戏剧要求设置角色：导演、编剧、演员、服装师、道具师、场务；"酥油花"项目最终产品是书，就按出版要求设置：主编、文编、美编、宣传发行员
2. **每个团队有清晰的角色划分**——戏剧组之外还有信息收集组（信息搜集员、报告撰写者、演示文档制作者）、模型组（绘图师、材料收集者、模型搭建者）
3. **每个成员有明确的角色职责**——小B 担任导演就统领整个项目安排；小C 担任道具师就对道具的选择、制作和使用全环节负责
4. **项目成员有第二/第三角色**——防止"长板恒长"：一个孩子擅长画画，每次画画任务都给他，他就没机会锻炼其他技能。理想方法：项目开始前收集学生的特长爱好（确定第一角色依据），同时收集"希望发展的技能"（给第二角色）。例如有领导力的导演，希望多参与手工制作，道具师就是他的第二角色——**每个任务多人参与，一个人也可扮演多角色，组织架构是立体的**
5. **分组方式不是一成不变的**——戏剧项目剧本编撰阶段按写作需求划分角色，排练阶段按演出需求重新划分；深度阅读项目中学生可三次重新分组
6. **平行小组或并行小组交替使用**——空间改造方案项目用平行小组（每组角色相同、进度一致、各自出方案班级遴选）；调研报告项目用并行小组（数据组、图片组、文字组、美工组各管一块，成果汇总成班级共同成果）

**使用步骤（三阶段）**：
1. **阶段一 项目角色的定义**：根据项目成果类型定义团队角色（成果=人物访谈 → 访谈策划、记者、录音师、撰稿人、音视频编辑），填写表格第一列
2. **阶段二 项目角色的阐释**：学生受生活经验所限对职业认知不足，教师用讲解、视频、现身说法帮助学生了解各角色职责（记者做什么？录音师做什么？），完成后填写"主要职责"列
3. **阶段三 项目角色的认领**：教师定义和阐释后，**学生根据兴趣和爱好选择希望担任的角色，而不是由教师强行分配**——这是个性化最直接的落点

**何时使用**：第二模块"招兵买马、组建团队"。

> 💡 **研学场景示例**（把 PBL 方法落到你的业务）：
> - **博物馆研学"策展小分队"**：成果=班级 mini 展览。角色：策展人（统筹主题）、内容研究员（文物资料）、空间设计师（展位布局）、讲解员（现场导览）、宣传官（海报与邀请函）。第二角色：让擅长画画的策展人同时认领"文创设计"，让内向的讲解员第一角色做"资料整理"、第二角色做"展签撰写"（先书面表达再口头表达）
> - **良渚研学"考古工作坊"**：角色=考古队长、绘图师（文物线描）、记录员（档案卡）、修复师（陶片拼合）。根据特长/爱好收集表分配第一角色，"希望发展的技能"决定第二角色——想练表达的孩子在结营汇报时做"考古成果发布会"主讲
> - **西湖水质研学**：成果=水质调研报告。角色=采样员、检测员（pH/溶解氧）、数据分析师、报告主笔、发布演讲人。平行小组模式：每组同构角色各自完成一份区域报告，班级遴选最优方案提交水域管理部门

## 📖 案例（行动者手册）

### "教室改造家"：让 50 个学生都找到自己的位置

**背景**：成都市实验小学五年级。因学年初换教室，教室环境遭到同学诟病——学生群自发讨论：教室空间如何吸引人？如何照顾教室里的每一个人？班主任联合美术、思品、数学、科学、语文五个学科老师和校方，开启长达 8 周的项目式学习（每周 6 课时 + 零散学科课时）。

**过程（个性化的层层递进）**：驱动性问题——"**我们如何改造教室空间，让我们的教室变得更吸引人？**"项目分七个阶段：教授设计思维（设计师讲授 5 阶段）→ 用户调查（KWL 表格、5W1H 采访、APOEM 观察工具）→ **设计方案答辩会**（每组答辩不超过 7 分钟，民主选出最佳设计小组）→ **重组核心设计团队**（向全班招募，集结有特色的同学完成第二轮优化设计，全班形成"设计师与用户"的真实场景）→ 招募施工团队完成改造（12 课时，每周 2 次复盘）→ 1 周适用测试、迭代优化（设计"教室迭代箱"收集意见）→ 教室开放日发布"原生班级"论。

**结果**：一间改造后的教室 + 教室开放日发布会。学生通过项目获得的不只是空间，还有"原生班级"的身份认同——他们还提出"教室如何持续成长"的建议，号召更多班级加入。

**启示**：这是个性化 PBL 的教科书案例——**学生的声音**（自发讨论成为项目起点）、**学生的选择**（答辩会民主投票、核心团队招募单、施工团队自愿报名）、**灵活的路径**（不同小组有不同设计方向，有特色的同学进入核心团队，其他人作为"用户"参与反馈与施工）、**真实受众**（专业设计师智库 + 开放日观众）。《50个工具》工具4 的角色设定在其中贯穿始终：每个阶段按任务需求重新组队、认领角色，让 50 个学生都找到自己的位置。对应 P_8 的"人类学家"比喻：老师始终在观察学生——观察谁有领导力、谁想练表达、谁的手工强，再据此设计角色与任务。

B. 老师先收集学生的特长爱好和"希望发展的技能"，第一角色匹配特长、第二角色指向成长，并在项目阶段转换时重新分组

<details><summary>答案</summary>

B。判断依据有三层：《50个工具》工具4 的"长板恒长"警示——A 会让擅长者永远做同一件事；角色认领原则——学生按兴趣选择角色而不是被强行分配（教室改造家的答辩会/招募单就是例子）；分组动态原则——项目不同阶段按任务需求重组（故宫项目剧本阶段与排练阶段角色不同）。A 是静态的、老师主导的，与"学生的声音和选择"相悖。
</details>

**题 3（判断）**：一位老师说："我的项目很个性化——每个学生自己选一个主题做海报，做完贴墙上，大家互相看看。"这个项目离"个性化 PBL"还差什么？

<details><summary>答案</summary>

两层问题：(1) **只有"个人选择"没有"共同探究"**——epub 第4章批评的"单薄的主题单元"就是这种：任务非跨学科、非合作、非高水准，学生各做各的，没有团队协作与真实问题；(2) **只有"产品"没有"路径设计"**——P_8 的个性化是"帮助每个学生找到自己的学习路径"，涉及产品灵活性、学生声音、学生选择、辅导四个维度；海报墙缺少真实观众与真实评估（epub 第6 大错误"评估不够真实"）。修正方向：让海报服务于一个真实项目（如"为西湖设计护水宣传海报，向游客征集反馈并迭代"），加上角色分工、团队协作、真实评委。
</details>

**题 4（自查·本课产出）**：为你自己的课程/研学产品完成个性化设计：
1. 用 P_8 四做法自查：是否超越标准教学？是否从主题转向概念？是否关照第二语言/特殊需要学生？你是否在"做人类学家"（观察学生）？
2. 用工具 4 表格，为你的项目设定 4-6 个角色（含主要职责、第二角色）
3. 写出你的项目里"学生的声音和选择"出现在哪三个环节

<details><summary>自查指引</summary>

这是本课最重要的练习（P_8 + 《50个工具》工具4 的产出要求）。如果卡住：
- 角色定不出 → 先想项目最终成果是什么，再按成果反推"真实职业需要哪些角色"（书→出版角色；戏剧→剧组角色；展览→策展角色）
- 第二角色不会填 → 逐个问学生/学员："你最想在这段时间里学会什么？"把答案填进"希望发展的技能"
- "学生的声音"找不到 → 参照教室改造家：从学生自发讨论出发、答辩会投票、招募核心团队、意见箱迭代——至少要有 2-3 个真实的选择点
- 自检：有没有任何环节是"老师强行分配"的？如果有，改成"认领+协商"
</details>
