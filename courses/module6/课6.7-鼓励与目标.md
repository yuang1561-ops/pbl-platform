## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、机会所在：在线学习可以解放想象力

"这次体验的主题是激发热情和目标。就像我在课程开始时说的，在线项目式学习给了你一个机会，真正挖掘学生的热情和目标，为他们找到更真实的主题去探索和参与项目式体验。这就是机会所在。"

- **标准课程的局限**："这意味着我们不会限制他们的想象力，而是会找到各种方法来激发他们的思维和创造力。现在，如果你想想，这在教育中是非常必要的，甚至至关重要。我们作为教育者都在谈论，希望看到更多的创造力、好奇心和学习的热情。然而，我们大多数人都知道，标准课程并没有提供足够的机会让这个过程发生。它确实限制了想象力，并且在很大程度上迫使学生走上一条不一定有创造性或由热情驱动的思维路径。"
- **在线学习可以做到**："在线学习，你可以做到这一点。这就是机会所在。"
- **帮助学生克服恐惧**："想想他们，解放他们，让他们思考，让他们接触自己的创造力——因为他们确实有恐惧，而且通常被灌输认为自己不那么有创造力的观念。所以，你要帮助他们克服害怕自己不够聪明、不够有创造力、害怕同伴看法等任何阻碍他们的障碍，这样你就能得到更好的项目成果。让他们真正把自己看作有创造力的个体。"
- **在线生态消除了障碍**："在线生态系统消除了我们在这方面的一些障碍。所以，你现在的机会是抓住这个突破口，帮助学生真正变得更有创造力，更受自己好奇心的驱动。"
- **承诺**："我将介绍十种方法来解放思维，如何不限制想象力，如何在某种意义上释放学生，让他们成为优秀的创造性表现者。"

### 二、解放思想：老师也需要解放

"解放思维，找到灵感，开启一个项目。听起来不错。但我要用稍微不同的方式来讲解这组幻灯片。**不只是学生需要解放思维，老师作为教育者也需要。**我们都习惯了某些思维和做事的方式，我们需要做一些改变。"

**项目思维**："我用'项目思维'这个词，用这个图表来描述我们想达成的目标。这真的是对学生的整体视角——想想我们想鼓励学生达成的各种成果，我们想看到的成长类型，我们想看到的行为表现。所以不再只是一个成果、一次考试、一个结果，真的是一个全面的成果。"

**项目思维关注的成果**：
- "价值、服务导向、幸福感、合作协作、持续学习的能力——这些是通向成长的成果，而不仅仅是关注标准。所以我们真的在朝着成长迈进，而不是那么注重标准。"
- "我们也在开始强调设计和问题解决。这是项目式学习的核心。这真的是我们想留给学生的能力，让他们能灵活地、以设计为导向地思考。"
- "他们将来会通过与他人合作来做这件事。没有什么比数字和远程网络更重要的了，学生们会互相合作。我们假设有良好的集体智慧，而且我们也会奖励那些重视服务、有贡献的项目。解决善良的问题，就像我之前说的。我们想要有意义的项目，而不仅仅是覆盖内容的项目。"

### 三、十种解放思维的方法（C_4.1 核心）

**1. 帮助学生找到他们的故事**："帮助学生找到他们的故事，论证写作。"
**2. 目标墙、选择板、个人陈述**："目标墙、选择板、个人陈述。我在体验的生态系统部分放了一些选择板的例子，你可以看看那些是什么样的。我也有一些目标墙的例子。"
**3. 把世界当作课程**："看看你社区周围有什么。使用可持续发展目标，如果这对你来说是一套好的标准，那就绘制你的社区地图。我在社区地图绘制方面放了一些资源，让学生们看看他们的社区。就像我常说的：**在学校一英里范围内，有 100 个项目等着发生。**"
**4. 提供选择和挑战**："跨学科选项、主题、这个发现如何影响、问题有多关键、主题、冲突如何影响？换句话说，深入思考这些跨学科的问题，而不仅仅是狭隘的问题。这就是你解放的方式。"
**5. 有目的的工作、高度参与、有意义且真实的项目式工作**："把模板变成激情项目，换句话说，确保项目想法能变成实际项目，所以提供大量资源让学生思考想法。"
**6. 教学生使用资源**："我在图书馆里有一些很好的例子你可以用，在'成长你的生态系统'里，你可以教学生如何使用这些资源。"
**7. 对年幼的孩子来说就是玩**："基于游戏的学习真的是伟大项目式学习的基础。学生们在幼儿园和一年级做了一些很棒的项目，他们在发明游乐设施、新玩具。"
**8-10. 升级你自己的思维**："你打算怎么升级你的思维？你打算怎么跟上那些幼儿园的孩子？这就是我们想思考的。你如何解放学生的好奇心、创造力、激情和目的？当他们开始设计项目时，这就是问题所在。"

> 说明：汤姆在原文中列出这串方法时未编号，本课按讲述顺序整理为十条；核心精神是"提供选择、连接真实世界、把想法变成项目"。

### 四、协商、指导和交谈：在线引导者的新角色

"这次体验，辅导教练和对话，真的是之前关于以同情心和社区为核心的领导力体验的延伸。但我想多聚焦一点在线环境中引导者的新角色，以及你在引导在线项目时需要具备的各种技能。这和基于课堂的引导过程有点不一样，有两个原因。"

**原因一：有很多未知数（未知的剧本）**："就像你在遵循一个未知的剧本，因为有人是远程的，他们离得很远，他们在做自己的事，他们在某种程度上独自工作。所以你在不断引导我所说的未知剧本，并试图跟踪学习者的进展。"

**原因二：学生和你有一段距离**："因为学生是远程的，因为他们在线上，他们实际上和你有一段距离。那么，当旅程真正属于他们，而不是像在课堂上那样属于你时，你的角色是什么？"

**放手一层控制**："当我们让学生自由，或者更自由地去探索他们的热情、目标和创造力时，这意味着我们又放弃了一层控制。这对你的角色来说结果是什么？你怎么处理这个？"

**教师需要做出的转变**："一些教师发现他们需要做出的转变，以便成功引导在线项目，特别是他们需要为自己的教学风格带来的那种灵活性和开放性，以使这些项目成功。所以让我们看看一些技巧，看看教师们在成功做什么，来引导在线项目。"

### 五、给你的行动清单（把三段课变成动作）

1. 每个学生/每个项目问："你对什么充满热情？你想解决什么问题？"
2. 帮助学生克服"我不够有创造力"的恐惧——先解放老师自己
3. 用"项目思维"的成果清单（价值、服务导向、幸福感、合作协作、持续学习）代替"只关注标准"
4. 十种解放思维方法挑 3 个用起来：找到他们的故事 / 目标墙选择板 / 把世界当课程（"学校一英里范围内有 100 个项目等着发生"）
5. 接受"未知剧本"：灵活、开放，跟踪学习者进展，放弃一层控制
6. 用积极反馈表给出"正向、具体、有帮助"的反馈

### 《PBL项目制学习》第 3 章——如何激发学生的热情

"站在学生的角度，对破壳而出的项目构想进行复盘：**他们为什么要在意这个？**"

- **基于激情的学习**：加州帕洛阿尔托研究中心前任首席科学家约翰·西利·布朗建议想象"基于激情的学习"——"用'激情'替换'项目'后，再思考一下你的项目构想。什么才能激发学生的好奇心，并让他们感到当下所学是有趣且重要的？如何设计交互方式，让参与者感到自己也是重大项目的一分子？哪些活动、经历和工具能让他们兴奋起来？"
- **热情促进深度**："当你激发起学生的热情时，你就增加了他们开展深入探究的可能性，并让他们获得更深的理解。充满激情的项目有助于将学习经历的社交要素和情感要素联系起来。"
- **显性教授学习素养**：有些教师把学习素养作为明确目标——"在学年开始时，教师可能会把学生的自我管理，如高效利用时间、管理学习材料、回应反馈等作为最重要的学习素养来加强"；年初项目多安排独立任务培养自我管理，下一个项目强调毅力并配合团队问题解决策略；"从一个项目到下一个项目，不断强化积极的素养，让其成为学生的第二天性。"

## 🛠️ 落地工具：积极反馈表（《50个工具》工具15）

### 反馈三原则：正向、具体、有帮助

```
┌────────────────────────────────────────────────────────┐
│ 积极反馈表（《50个工具》工具15）——三原则 × 句式支架                 │
├──────────────┬─────────────────────────────────────────┤
│ 正向          │ "我非常喜欢你……的方式。"               │
│ （建立交流基  │ "活动中你一直非常棒地……"               │
│   础，肯定与  │ "这个活动中你做得最好的是……"           │
│   情感支持）  │ "我认为你写得/画得/做得非常棒，因为…"   │
├──────────────┼─────────────────────────────────────────┤
│ 具体          │ "当你……的时候，你特别棒！"             │
│ （指出哪里好、│ "在第一段/第一个环节/第一次小组活动中，  │
│   为什么好、  │  你……"                                │
│   怎样更好）  │ "我觉得你在……中，可以更好地……"       │
├──────────────┼─────────────────────────────────────────┤
│ 有帮助        │ "你可以给你的……增加一些细节。"         │
│ （对改进产品  │ "你想过调整这一段/这个部分……会怎样吗？" │
│   和能力切实  │ "关于改进的方式，你想想是不是可以……"   │
│   有帮助）    │ "别忘了……"                            │
└──────────────┴─────────────────────────────────────────┘
```

**为何使用**："积极反馈表可以赋予观众/学生/教师评价者的角色，并将他们的注意力引导到项目活动中值得关注的方面。在给学生提供反馈时，评价者还能及时地提出问题，促使学生在解答问题时深入思考和理解学习内容。教师也可以让学生参与反馈表的制定，强化学生对阶段性产品和最终产品展示的预期认知。展示结束后，学生可以使用这些反馈表来反思他们在项目活动中的表现或继续修改产品。"

**三原则详解**：
1. **正向**："正向反馈是评价者和学生建立交流的基础。让学生感受到评价者的肯定和情感支持在项目式学习中非常重要。在自主探究过程中，结果常常具有不确定性，学生也总是心怀忐忑。项目式学习的目标并不是要让学生获得好的结果和创作出无懈可击的产品，而是培养学生主动思考、积极合作的能力，提高各项素养。评价者如果执着于学生所完成产品的不完美……给出大量负面的反馈和评价，就会影响学生主动探究和自主学习的积极性。如果评价者能够在项目活动中发现学生的闪光点和优势，并及时给予学生鼓励和正向反馈，那么学生会变得更自信，更愿意进行持续探究。"
2. **具体**："具体的反馈是指，在正向鼓励的基础上，评价者真诚地给学生提出详细、确切的评价和建议。对于学生做得好的部分，指出哪里好，为什么好，怎样可以更好；而对于尚有欠缺的部分，指出问题出在哪里，探讨为什么会出现这样的问题，可以怎样改进。评价者的具体意见会给学生改进产品、调整心态提供方法和精神上的支持，使学生感受到自己所做工作被看见并被认真对待。"
3. **有帮助**："积极反馈要对学生改进产品和提高能力有切实的帮助。一方面，反馈者对具体问题给出有针对性的建议或对没有考虑到的因素和问题进行适当的提示和点拨，帮助学生进行反思、改进；另一方面，反馈者通过启发式、引导式的提问，让学生对问题进行横向和纵向的联系和思考，跳出固有思维，以新的视角审视出现的问题，从而提高认知能力，形成高阶思维。"

**使用步骤**：
1. 在项目活动过程中及时观察并记录学生遇到的问题、解决方式、小组协作情况（为反馈积累素材）
2. 在第六模块"解决问题、产出成果"阶段（或对作业/阶段性产品反馈、同伴互评时）使用
3. 按"正向→具体→有帮助"的顺序组织反馈语言：先肯定闪光点（正向），再指出哪里好为什么好、欠缺处问题在哪（具体），最后给改进建议+启发式提问（有帮助）
4. 展示结束后，让学生用反馈表反思表现或继续修改产品
5. 可以让学生参与反馈表的制定，强化对产品展示的预期认知

> 💡 **研学场景示例**：
> - 线上"云端策展"作品互评：学生用积极反馈表给同伴的文物导览视频反馈——"你的开头用'如果文物会说话'特别吸引我（正向）；你在 1 分 20 秒讲玉琮纹样时语速有点快（具体）；你想过在关键纹样处加一个放大镜头吗？（有帮助）"
> - 西湖研学线上日记点评：老师用三原则批改学生"西湖观鸟记录"——先夸观察细节（正向），再指出记录结构可改进（具体），最后用问题引导"如果把鸟的行为和天气联系起来，你会怎么补充？"（有帮助，形成高阶思维）
> - 良渚研学小组互评：组员反馈"你整理的玉器资料特别全（正向），但分类可以更清楚（具体），要不要试试按'礼器/兵器/工具'分组？（有帮助）"——把"打分"变成"思想与情感的交流"

## 📖 案例（《PBL项目制学习》）

### 莎拉的故事：一个被"看见"的学习者如何找到目标

背景：小学教师埃莉斯·米勒通过一位患有诵读困难症的学生莎拉，确认了"学生具有主导自己学习路径的潜能"。米勒经常阅读教育博客，读到杰夫·乌特希特（Jeff Utecht，国际学校教师、思维棒博客作者）的一篇博文——"他写的是自己讨厌写作，但是爱写博客。"

过程：
- 米勒把博文转给莎拉，莎拉说："他跟我有一样的感受！"莎拉说："因为有学习障碍，所以阅读和写作对我来说就像一块氪星石。"
- 米勒鼓励莎拉给乌特希特的博客写评论，一场国际性的对话就此展开——"他们你来我往地分享着克服诵读困难症的策略。杰夫·乌特希特对诵读困难症的了解远远超过我。就这样，他和莎拉以一种有意义的方式联系在了一起。忽然间，整个世界都打开了合作之门。合作不一定要在一个学校或者一个社区内进行，从上海一直到贝灵汉都有可能发生。"
- 故事没有就此结束："莎拉决定要为和她一样患有诵读困难症的孩子们创造资源。她想要把自己的学习策略都分享给他们。莎拉就这一话题创建了维基，那是她的写作项目，也是她的学习路径——她正在解决自己生命中存在的一个问题。"

结果：莎拉从"讨厌写作、害怕学习"变成主动为同伴创建学习资源的创造者。"作为教师，我不必非是那个为全班所有学生设计一个超级项目的人。我可以问问学生：你对什么充满热情？我也不必对每一个项目都进行微观管理。他们可以自己开展学习，而我则可以给他们提供支持。"

启示：这个案例把本课三段课串成一条线——**C_4（鼓励）**：米勒看见莎拉的恐惧（"被灌输认为自己不那么有创造力"），用一篇博文点亮她；**C_4.1（解放思想）**：莎拉找到了"自己的故事"，把障碍变成目标；**C_7（放手）**：老师"又放弃了一层控制"，让学生自己开展学习、自己提供支持——这正是"当旅程真正属于他们时"的教师角色。
