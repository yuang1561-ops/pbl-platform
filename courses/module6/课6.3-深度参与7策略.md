## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、先立目标：培养专家型学习者

- "我的目标是培养专家型学习者——自主、有知识、目标明确、有方向感。有动力的学习者，能掌控自己的学习并独立完成任务。"
- "这不仅是良好的学术技能，更是当今职场上让你具备就业竞争力的关键。当你成为专家型学习者时，你正是雇主所寻找的——主动进取、终身学习、有创业精神的年轻人，能够在没有老师指导的情况下工作，并能自主学习。"
- "当他们体验到选择和挑战时，学习会变得更有趣，也更容易实现。"

**你的角色**："你的角色转变为共同学习者。你在帮助学生寻找意义，你在项目中帮助他们发出声音、做出选择。实际上，你是作为引导者和促进者一起构建项目，而在这个过程中，你在与学生建立一种促进成长的关系——正如我们所了解的，这是在线工作成功的关键。"

### 二、策略 1：明确对在线工作的期望

"你也要明确对在线工作的期望。深度学习目标在这里完美契合。"

- **能力**：学生如何展示这些能力？他们如何掌握这些能力？他们如何向你提供这些能力的证据？
- **成功是什么样子**："学生如何知道自己是否掌握了技能或内容？"
- **重要提醒**："记住，分数在这里不太管用。你要把它转化为项目中少数几个关键学习成果，这样学生就能专注于他们想要完成并接受你评估的少数深度学习目标。"
- "而要衡量这些，你需要超越分数的评估方式——分数在在线环境中被证明非常低效。"

### 三、策略 2：用单点量规替代分数

"这里有一个单点量规的好例子。我在课程的生态系统部分放了更多内容。你可以去看看单点量规是什么样的，但本质上，学生是在你的帮助下设定目标，他们反思自己的表现，然后根据设定的学习目标制定新目标。"

> 单点量规（Single-Point Rubric）：在"目标"这一列之下，学生看到的是"目标达成后的样子"，而不是一堆扣分项——它的重点是**"下一步怎么走"**，而不是"你差多少分"。

**使用要点**：
- 学生在教师帮助下设定目标（而不是教师单方面定标准）
- 学生反思自己的表现
- 根据学习目标制定新目标（形成"目标—反思—新目标"的循环）

### 四、策略 3：建立常规流程

"对于项目，我们还要建立常规流程。我们需要常规来帮助学生保持进度，这对成年人也同样适用。"

- "所以确保你有退出票（exit ticket）、里程碑、在线进度报告。"
- 为什么需要："记住，他们正在经历一个过程，而且由于异步工作，他们经常独自工作，所以他们需要一种支持系统，帮助他们按时完成任务、赶上截止日期、建立里程碑，并按时提交项目。"

> 核心信息：异步工作 = 学生经常独自工作。常规（退出票、里程碑、进度报告）就是他们的"虚拟同桌"。

### 五、策略 4：磨练你的反馈技巧

"这也是一个机会，让我所说的'磨练你的反馈技巧'得以实现。在线学生需要大量高质量的反馈。"

- 反馈要回答的问题："成功的下一步是什么？"
- 检查理解程度，保持远程在线办公时间（office hours）
- "让你的反馈保持规律、持续、一致和可信，并把反馈规划到项目时间线和设计中"
- "我想说的是，要善于观察，留意他们表现中的差距"

> 核心信息：反馈不是"批改作业"，而是"规划到项目时间线里的设计元素"——规律、持续、一致、可信。

### 六、策略 5-7：深入探究过程（四五个步骤）

"现在，让我们谈谈可以采取的四个或五个步骤，我称之为'深入探究过程'。"

**第 1 步：持续的个人和小组反思**："首先，始终进行个人和小组反思——随着在线过程的进行，学生在告诉你他们的感受和表现，你要在个人和小组层面持续反思。"

**第 2 步：给困难留出充足时间**："给过程中出现的困难留出充足时间。深度学习不是快速或迅速的，它需要坚持和时间。这在面对面的课堂项目中如此，在远程环境中可能更是如此。老师们发现，在数字环境中完成任务需要更多时间，而不是更少。"

**第 3 步：灵活、个性化的路径**："让学生以不同方式完成工作，并展示他们如何掌握所学内容。尽可能给他们空间、自由和灵活性，让他们展示自己的学习成果。学生有很多方式可以向你展示他们学到了材料。所以，让他们选择，你来审查和批准，但在评估过程中给他们充分的发言权和选择权。"

**第 4 步：问学生"你觉得会掌握什么"**："一定要问问他们：你觉得在这个项目里会掌握什么？很多时候，在线学习过程中获得的技能、学到的知识或展现出的优势，可能并不是我们预想的那样，所以给学生一些选择，让他们表达自己的看法。他们学到了什么？他们认为什么重要？对有些人来说，可能只是能坐在屏幕前两小时把活儿干完的能力。不管是什么，让他们告诉你。"

**第 5 步：以"下一步"收尾**："最后，确保在项目结束时，留出时间让他们表达：这是我学到的，这是我下一步要做的——总是朝着未来的愿景前进。总是帮学生真正设想他们自己迈向成功的下一步。在任何环境下，项目没做完复盘就不算结束，这在在线环境中特别重要。"

**给你的行动清单**：
1. 把你的项目目标压缩成"少数几个关键学习成果"
2. 用单点量规做一次形成性评估（目标—反思—新目标）
3. 为项目设置退出票、里程碑、在线进度报告三个常规
4. 把反馈写进项目时间线（何时、由谁、以什么形式）
5. 评估环节给学生发言权和选择权（"你觉得你会掌握什么？"）
6. 项目结束必须做复盘：学到了什么 + 下一步做什么

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》第 7 章——启动项目，激发好奇心

第 7 章讲"项目启动阶段如何让学生进入状态"，和 C_8.1"深度参与"互为表里——**参与从启动那一刻就开始了**。

- **场景导入，让学生处于期盼状态**："此前的一系列活动几乎不需要学生花时间或做准备，只是简单地让学生处于一种期盼的状态。项目正式启动时，学生变得迫不及待，已经开始自己思考，并且为这场丰富和有意义的探索做好了准备。"
- **激发好奇心的两种方式**：
  - **差异性事件**："引人注目、发人深省的事件，教师故意用这些事件来挑战学生固有的观念。"案例：5 年级教师展示两个看起来一模一样的玻璃杯，都装着看似水的液体。冰块放进第一个杯子浮了起来；放进第二个杯子却沉到了杯底——"杯子里装的是什么？这些真的是冰块吗？什么东西会在第二个杯子里浮起来呢？"学生设计了微型调查，现场调研。第二天，教师引导学生开展深入的学习项目，研究和制作由不同材料制成的笛卡尔浮沉子。
  - **角色扮演预测**：让刚开始项目的学生在特定场景中扮演其他角色，即兴发挥，根据初步理解预测并表演出来；录制回放，让学生注意自己开始脱离角色的时候，"引导他们思考如何才能使表演更加流畅和精准"。
- **科技让启动更有吸引力**：5 年级"丝绸之路"项目——教师在谷歌地球社群里发现一位葡萄牙建筑系学生发布的丝绸之路地理标记和注释，让学生沿着丝绸之路从一个地方"飞到"另一个地方，并通过电子邮件与那位正在研究丝绸之路沿线地标性历史建筑修复的大学生交流。"学生不仅结交了新朋友和专家，对这些地标性建筑的命运也越来越感兴趣，这意味着他们已经为项目做好了准备。"
- **先传授基础知识**：高中科学老师为 9 年级学生计划"停车场废油生物修复项目"，先上一系列微生物课程，再提出"减少学校停车场废油的最佳生物修复方法是什么？"——"她希望学生能在不跳过核心知识内容的前提下，快速进入探究式学习的环节。"
- **给教师的开车比喻**："首先，你学着绕着一个街区开；然后开始绕着小镇开；接着可以开去邻近的地区；最后，就可以准备好开往市中心了。你不会让一个新手直接开车上高速公路。他们需要循序渐进。"

## 🛠️ 落地工具：世界咖啡流程（《50个工具》工具23，线上版）

### 线下原版

```
┌────────────────────────────────────────────────────────┐
│ 世界咖啡（World Café）流程                             │
├────────────────────────────────────────────────────────┤
│ ① 每桌选一个主持人，每轮讨论一个问题                   │
│ ② 讨论结束，组员重新选桌，主持人留在原桌               │
│ ③ 主持人向新一轮组员介绍上一轮观点，并组织选出新主持人 │
│ ④ 新主持人组织组员开展下一轮讨论（3 轮以上）           │
└────────────────────────────────────────────────────────┘
```

**为何使用**：世界咖啡"让学生在项目活动中自然、有效地提升个人领导力，促进社交影响力"。主持人的任务（组织讨论、记录观点、向新组员讲解要点、组织选出新主持人）锻炼组织能力、控场能力、总结归纳和表达能力；而作为组员参与又体验协作参与——"这两种身份的交替，让学生能同时体验主持人的领导职责和组员的协作参与"，有机会进行不同视角和思考方式的转换。它还能"连接多元视角、鼓励每个人的贡献、一起听取见解分享集体发现"。

**何时使用**：用于第五模块"知识准备、能力准备"和第六模块"解决问题、产出成果"；当学生有三个以上讨论主题、且每一轮需讨论一个主题时使用。

**线下使用步骤**：
1. 把主持人职责和工作流程写出来（含每个步骤的活动内容和执行时间），让学生提前了解
2. 用投票、自荐、轮流等方式选主持人，确保每名组员都有机会做主持人
3. 每桌讨论一个主题；结束讨论后主持人留下，组员重新选桌；新主持人介绍上轮观点并组织选出新主持人
4. 三轮以上讨论后，主持人总结观点，组员写反思（各 100 字，可用画廊漫步互相观摩）
5. 讨论中可使用思维地图（《50个工具》工具17）、概念组织表（《50个工具》工具20）等工具，使用文本、视频、图片等多种素材

### 线上版改造（结合 C_8.1）

线上世界咖啡的"桌子"变成"讨论房间/分组会议室"，主持人职责不变：

```
┌────────────────────────────────────────────────────────┐
│ 线上世界咖啡（Zoom/腾讯会议版）                         │
├────────────────────────────────────────────────────────┤
│ ① 主会议室说明规则，用投票/自荐选出各组主持人           │
│ ② 按主题分入讨论房间，每组一个房间，主持人组织讨论      │
│    （用共享文档/白板记录观点，替代纸笔）                 │
│ ③ 讨论结束，组员重新选房，主持人留在原房间；            │
│    新主持人向新一轮组员介绍上一轮观点，选出新主持人     │
│ ④ 三轮后回到主会议室，主持人分享要点，组员写反思       │
└────────────────────────────────────────────────────────┘
```

**线上要点**：共享文档（腾讯文档/石墨）代替纸笔记录；"退出票"（策略 3）可以做成"讨论结束前每人填一句话观点"；主持人的"控场"在线上尤其考验表达能力——提前给主持人打印职责清单；每轮时间要略短于线下（线上注意力更易疲劳），并在轮间安排 1-2 分钟休息。

> 💡 **研学场景示例**：
> - 布达佩斯展线上研学：三个讨论主题（"匈牙利文物为什么用金器？""游牧民族如何影响欧洲？""如果让你策展，选哪三件？"）分成三个线上房间，每轮 8 分钟，学生轮转体验主持与参与
> - 西湖文化线上读书会：围绕"西湖十景"的成因、变迁、保护三个主题走世界咖啡，主持人用共享白板记录各组观点，最后合成一张"西湖十景全景知识图"
> - 良渚研学线上策划会：学生以"云上策展人"身份，用世界咖啡讨论"展什么、怎么展、讲给谁听"三问，每轮换房换角色，产出展览方案雏形

## 📖 案例（《PBL项目制学习》）

### 丝绸之路项目：一个"差异性事件"级别的线上启动

背景：一位 5 年级教师准备一个结合地理、历史和贸易知识的"丝绸之路"项目。传统启动方式是老师放课件讲路线——学生多半听完就忘。

过程：
- 教师在谷歌地球社群里发现了一位葡萄牙建筑系学生发布的一系列丝绸之路的地理标记和注释
- 她让学生沿着丝绸之路从一个地方"飞到"另一个地方（谷歌地球漫游）
- 学生通过电子邮件，跟这位正在研究丝绸之路沿线地标性历史建筑修复的大学生交流
- 学生在线上认识了"新朋友和专家"，对这些地标性建筑的命运越来越感兴趣

结果：项目还没正式开讲，学生已经"迫不及待"，开始自己思考——"这意味着他们已经为项目做好了准备"。学生带着期盼进入项目，后续探究的动力和深度都不同了。

启示：这个案例同时示范了本课多个策略：**角色扮演/情境启动**（把自己当成丝绸之路上的旅行者，替代被动听讲）、**连接真实专家**（那位建筑系学生就是"你能学习的专家"）、**把启动做成参与**（不是"讲给你听"，而是"带你飞过去"）。对线上教师：启动即参与，参与即深度。

**题 3（判断）**：线上项目进行到一半，老师发现好几个学生"进度落后"。请用本课策略诊断：可能的原因有哪些？对应的策略是什么？

<details><summary>答案</summary>

可能原因与对策（至少两层）：(1) **缺乏常规**（策略 3）——异步工作常让学生独自迷失，检查是否有退出票、里程碑、在线进度报告；(2) **反馈不够**（策略 4）——学生不知道"成功的下一步是什么"，反馈要规律、持续、一致、可信并写进项目时间线；(3) **时间假设错误**（深入探究第 2 步）——"在数字环境中完成任务需要更多时间，而不是更少"，要给困难留出充足时间；(4) **路径不灵活**（第 3 步）——是否给了学生不同的完成任务方式？"让他们选择，你来审查和批准"。更深一层：还要先诊断是"意愿问题还是技能问题"（衔接课 6.2 原则 3）。
</details>

**题 4（自查·本课产出）**：为你正在设计的一个线上项目写"深度参与方案"：
1. 写出 3 个"关键学习成果"（取代分数清单）
2. 设计 3 个常规：退出票 / 里程碑 / 在线进度报告各是什么形式
3. 写一条"反馈日历"：第几周、谁、以什么形式给反馈
4. 设计一个"深入探究过程"的 5 步时间表

<details><summary>自查指引</summary>

- 关键学习成果要"少而精"，每个能用单点量规描述"达成后是什么样子"
- 退出票可以是"一句话收获+一个疑问"；里程碑要对应真实任务节点；进度报告让学生自己填（自评而非汇报）
- 反馈日历要具体到"周次+形式"：如"第 3 周：小组反馈会（世界咖啡）""第 5 周：教师一对一 office hours"
- 5 步时间表应包含：个人/小组反思（持续）、困难缓冲期、灵活路径、'你觉得会掌握什么'对话、'学到了什么+下一步'复盘
</details>
