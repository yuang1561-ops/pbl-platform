## 📌 本课导读

## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、以同情心和社群引领：关系是线上学习的起点

"我相信在线学习暴露了我们学习和教育体系中的一个致命缺陷，那就是我们和学生之间的关系不够深入、不够牢固。"

- **学生只为"有联系"的人学习**："我们知道，学生只有在感到有联系的时候，才会为老师工作、和老师一起工作。如果他们在教室里没有这种感觉，他们就不会做太多功课。如果他们在网上没有这种感觉，他们做的功课就更少了。联系、社区，这些都很重要。"
- **在线 PBL 讲师的第一要务**："作为在线 PBL 讲师，你真的必须从联系、同情心和社区开始，在开展项目之前，先和学生建立那种关系。"
- **目标状态**："你怎么设置这一切，才能让学生积极参与、渴望学习、愿意投入项目，进入那种开放的心态，说'我准备好干活了'。这就是你想达到的效果。"
- **共同学习者进入学生的情感空间**："作为共同学习者、作为老师，你实际上在某种程度上进入了学生的情感空间。因为他们正在经历各种奇怪的情绪——和教室隔离、和朋友同学隔离、在家，在各种环境里，有些很支持，有些不太支持……你的工作就是去理解这些，安抚他们，和他们建立联系，给他们一种安全感和目标感。"
- **金句**："这就是我说的'以联系、同情心引领'，把自己当作他们的**情感向导**。这很关键，如果你不这么做，你很可能做不出什么好项目。"

**出勤率的差别就是关系的差别**："有时候我和一些老师聊天，他们的在线出勤率只有 50%。其他时候，我和一些老师聊，他们能拿到 100% 的出勤率。区别在哪里？**同情心、善意、联系。**"

### 二、教会学生积极地协作：善良是协作的底色

汤姆在 C_6 里"再次强调"团队合作，但用了不同的方式——谈"积极协作"。

- **社交智能**："我想谈谈一个叫社交智能的东西。有大量证据表明，当学生们一起合作时，他们实际上开始体验到一种群体感、成长心态。在我们这个高度互联的世界里，我们开始影响彼此的思维方式。"
- **世界是课程**："有些人说，世界现在真的成了课程，学生们可以出去连接他们想连接的任何地方……他们建立这么多不同联系的可能性，跨越全球，以某种方式互动，这种方式我们可能会在某个时候发现正在改变他们的大脑。这就是社交智能背后的概念。"
- **积极协作 vs 普通团队合作**："这是我所说的积极协作的一种形式，它要求学生比过去更深入地分享，还要求他们做一些非常有趣的事情：**培养同理心和彼此开放的态度**。"
- **善良的力量**："在最初的体验中，我谈到善良是我们在这个世界上寻找的转变之一。这就是学生们有机会体验和促进彼此善良的地方。如果我是做在线项目的 PBL 老师，我会和学生们讨论善良的力量，以及这如何等同于更深层次和更积极的协作。"
- **汤姆的坦白**："我在这里要透露我的偏见：我希望整个世界变得更善良。我认为我们可以教学生，并给他们机会去体验彼此之间善良积极的协作。"
- **怎么加一个元素**："他们仍然会组建团队，会组建虚拟团队，会彼此合作，很多时候这确实很像典型的团队工作。但我现在要求你在这个过程、这个体验中加入另一个元素：**彼此之间善良积极的协作、同理心、好好倾听、尊重、对彼此往好处想**。所有那些可能阻碍深度协作的事情，那些真正由个性驱动的行为，在在线环境中是可以克服的。这就是目的所在。"

### 三、促进社会智能：生态协作模式

"社会智能的理念，即我们可能在一起学习，成长型思维可能是一种集体努力。这对教育来说是新的，对世界来说也确实很新。但我们可以看到，随着互联网拉近我们的距离，随着我们成为一个联系更便捷的全球社会，世界变成了课程。"

- **生态协作模式**："这就是为什么我使用这种生态协作模式，其中你有这么多不同的接触点——互联网、同伴、资源、成年人、社交媒体，这么多东西都在为你的学习做贡献。你真正在思考的是：这个项目的关键联系是什么？"
- **更有意地选择协作对象**："他们仍然需要组建一个虚拟团队、一个小组，但他们也可以问为什么——你为什么选择那些伙伴？你为什么觉得他们会对你最有帮助？所以，你实际上是在要求更深层次的协作，而且真的是更有意地选择协作对象。"
- **用生态视角看待互联网**："你确定了哪些网站或资源能帮助你的项目？你是在面对这个真正无限的资源集，试图决定什么对你的项目最有帮助。这当然需要学生有更多的选择和更好的研究技能。"
- **把成年人当导师**："他们还可以比过去更多地纳入成年人。一旦他们在教室外进行远程学习，他们可以联系成年人，看看成年人在做什么，把成年人当作导师。这真的是年轻人接触成年人并在课堂外向他们学习的强大机会。"
- **小学生的父母资源**："对于更小的学生，你会怎么利用你的父母？我们知道，如今父母更贴近学习过程，尤其是对更小的学生来说。他们真的就在许多学生身边。他们有时需要接受培训来了解怎么做，但孩子们真的也能学会把父母当作很好的资源。"

### 四、可教授的沟通技能清单（C_6.1 核心）

"你还可以教授学生可能需要的技能，比如批判。"（此处"批判"指批判性倾听——原文紧接着就是一系列自问）

**1. 有联系的倾听（批判性倾听）**：
- "我真的能听到你吗？我在听吗？"
- "**我是在听以求学习，还是在听以求回应？**这总是一个好问题。"
- "我能给你怀疑的好处吗？"——"换句话说，彼此善意相待，这大大有助于增强有联系的沟通。"

**2. 认可（肯定）**："也包括认可：哇，我喜欢你做的。做得很好。"

**3. 找到共同点和解决冲突（冲突解决）**："当然，找到共同点和解决冲突的能力，也就是冲突解决，这成为如今任何在线工作的人技能组合的一部分。"

**4. 民主沟通**："还有我称之为民主沟通的东西，即你真正愿意深入参与对话。现在，显然，这可能更适合年龄较大的学生。"

**5. 大脑是社会器官**："但我们知道，群体思维正在发挥作用。如今在发展和头脑风暴想法时，很可能这种对话会改变大脑。大脑是一个社会器官，它会在真实对话、真诚和关怀中成长和回应。这些技能对如今的在线协作至关重要。"

**如何教这些技能**："如果你愿意，你也可以教授其中一些技能。你可以引入某种情景，问学生他们会如何提供积极反馈，问他们的肢体语言和眼神接触是什么样的。你可以示范和角色扮演积极互动，分享观察结果并反思，让每个人设定一个成为更好在线沟通者的目标。"

**给你的行动清单**：
1. 项目开始前，先做"联系优先"：一对一连接、情感向导式倾听，再谈项目
2. 在团队里引入"积极协作"元素：善良、同理心、好好倾听、尊重、往好处想
3. 让学生"有意地选择协作对象"，并说出理由
4. 把成年人/家长/导师纳入项目资源生态
5. 教授 4 项沟通技能：有联系的倾听、认可、冲突解决、民主沟通（示范+角色扮演+反思）

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》第 9 章——利用在线合作，拓展学习空间

"当学习圈不断扩大，不再局限在一间教室或一所学校内，而是包括了来自遥远国家或其他大洲的参与者时，会发生什么？"

**案例一：杰夫·惠普尔（加拿大）——跨文化插画项目**
- 惠普尔通过交换视频、博客和其他沟通方式，把加拿大新不伦瑞克的学生与远在其他地方的同龄人和成年人联系起来
- 他邀请一位加拿大冒险作家参与项目，学生通过博客讨论作家的书。"该项目的精妙之处在于作者是真实的，学生可以接触到他。"作家每周花 3-5 小时回复学生的帖子；项目最后一天，作家访问其中一所学校朗读最后一章，另一所学校的学生通过视频会议加入并提出问题
- 后来他抓住机会连接韩国国际学校，让学生"跨越距离和时区，共同创作插画作品——这是一个需要对目的和创造性进行深入交流的任务"；更多学生加入扮演审稿人角色，最终**来自世界各地的 40 所学校的学生都参与了进来，既是作者也是审稿人**。"学生开始理解他们有机会、有可能与生活在世界其他地方的人们一起合作。唯一的阻碍是时间，而非空间。"
- 他还推动法语二外学校与新不伦瑞克双语学生建立联系，使用 Skype、谷歌云盘或维基共同写作或制作视频；项目强调版权保护——"他们使用的图像必须是自己创作的，或是得到许可能再次使用的素材。这是一个教授保护知识产权并实现知识共享的机会。"

**案例二：莉萨·帕里希（美国纽约）——自然灾害项目**
- 帕里希与远方的教师（伊利诺伊州的唐娜·罗曼）合作，用 Skype、谷歌文档等工具组织跨校合作
- **开局的教训**："我们还以为我们可以立马开始，所以就没有花时间让学生互相熟悉。开局有点不利。"——她复盘后认识到，团队合作中"共同进行项目规划和教学是一个必然组成部分"
- **项目真正开始于互相关心**：帕里希的学生所在的长岛被飓风桑迪袭击，之后又遭暴风雪，学校停课数周。"罗曼班上的学生真的很为我们担忧，实际上他们还为我们的学校进行了募捐。"帕里希的学生成了报道快速变化事件的记者
- 春末两边再合作共享故事写作项目，学生通过 Skype 和谷歌文档会面。"罗曼和我彻底被折服了。我简直不敢相信，他们把我们之前教授的所有关于团队合作的技能统统用上了。"

**给教师的启示**："对于很多教师来说，第一个项目'是他们真正需要的，是可以让他们今后能自主开展项目的开端'。"——"与学生一样，教师也能在帮助学生学习的过程中有所收获。这一切都是为了让教师更上一层楼，让他们进入一个可以独立的阶段。"

## 🛠️ 落地工具：有效沟通大纲（《50个工具》工具21）

线上协作最常见的翻车点：各说各话、互相埋怨、无法达成一致。"人们经常把'沟通'和'说话'画上等号，仿佛说起话来滔滔不绝就是沟通，其实不然。……沟通在本质上是一种信息的互换，双方基于收到的信息，在各自理解基础上达成目标，这样的沟通就是有效的。"

```
┌────────────────────────────────────────────────────────┐
│ 有效沟通大纲（《50个工具》工具21）                                 │
├────────────────────────────────────────────────────────┤
│ 沟通的对象是谁：____________（他需要做出的决策）        │
│ 第一步：目标（写给自己的）                             │
│   通过沟通，我希望对方做出的决策：1.____ 2.____ 3.____ │
│ 第二步：关联性（用同理心想对方在乎什么）               │
│   他在乎的原因有：1.____ 2.____ 3.____                │
│   如何让他在乎：1.____ 2.____ 3.____                  │
│ 第三步：要点（围绕沟通内容组织语言）                   │
│   关键信息：____________                              │
│   谈话结束时，他将决定…/同意…/开始：____________       │
│ 倾听反馈（沟通是双向的，不是"洗脑"）                  │
│   从反馈中你决定：1.____ 2.____ 3.____                │
└────────────────────────────────────────────────────────┘
```

**为何使用**："沟通是在个人或群体间相互传递信息、思想和情感，因此沟通是双向交互的过程，而不是单向传递的过程。"从字面上看，沟通由"沟"和"通"组成——沟通者和对象之间有"沟"存在，可能窄可能宽、可能浅可能深；"沟通的目的就是要架起跨越这个鸿沟的桥梁"。PBL 让交互变成网状，但"教师管理经验的不足，以及学生沟通经验的不足，常常导致沟通的场面变为争吵、互相埋怨、各说各话、无法达成一致"。"没有人天生就是沟通的高手。任何一种能力的培养，都需要科学的方法、持续的指导，再加上刻意练习。……看起来有些呆板的沟通结构，正是帮助我们进行刻意练习的工具。沟通高手都是在刻意练习中才慢慢走向自如的。"

**使用步骤**：
1. 明确沟通者（"我"）和沟通对象（要沟通的人）——如学生跟团队成员沟通一个想法，对象就是团队成员
2. 第一步定目标：沟通的目标是写给自己的——"通过沟通，我希望沟通对象可以做出哪些决策"（如：校长批复足额经费→目标 1 校长很支持这个项目、目标 2 校长批复了足额经费）
3. 第二步建关联：用同理心思考对方的立场和需求——"想要与他人真正地沟通，你必须认真思考他们需要什么样的体验"（如校长在乎：学生是否真正受益/预算是否宽裕/是否必须花钱）
4. 第三步备要点：围绕沟通内容组织语言，把观点、信息、证据提炼成清晰要点（如：如何衡量对学生的益处/有经费无经费的对比/项目关键信息/所需预算）
5. 预判反馈、灵活调整："沟通不是'洗脑'。沟通的乐趣在于双向互动的过程。"如果对方点头继续，冷漠就调整策略；"千万不要一股脑地把准备好的信息说完，这样只会事倍功半"

> 💡 **研学场景示例**：
> - 线上研学团队向学校申请"布达佩斯展云端策展"经费：学生用大纲三步准备——目标（申请到直播设备经费）、关联（校领导在乎学生受益与预算）、要点（数据+预算表），并在模拟沟通中练习"观察反馈再调整"
> - 良渚研学小组线上分工谈判：队员想当"讲解组"却担心没人做"资料组"——用大纲明确目标（达成公平分工）、站在队友角度想（谁擅长什么、谁想锻炼什么），把争吵变成协商
> - 西湖水质探究营向社区机构求助：学生用大纲起草一封正式邮件，练习"对象分析"（机构在乎什么：公益形象/数据价值/时间成本），线上协作的第一次"真实沟通"

## 📖 案例（《PBL项目制学习》）

### 饼干面团项目：从教室到 100 万美元的线上社群力量

背景：美国马萨诸塞州伊普斯威奇中学，凯西·西姆斯老师设计了一个数学项目——"给学生提供一些在真实生活中使用分数和测量知识的体验"：学生计算制作批量饼干面团混合配料所需的干料比例，罐装并设计市场促销活动，支持他们关心的事业。学生们选择支持一位患罕见神经系统疾病的同学——该家庭发起的基金会目标是为基因疗法研究筹集 100 万美元，项目开始时才完成一半。

过程：
- 项目第一部分如预期展开，学生进行大量讨论，奋起接受涉及分数知识的开放式问题
- 一位科学老师建议学生创建营养成分标签并提供医学研究需求信息，项目升级；语文老师又以其他方式提供帮助
- 一位学生计算出全部卖出只能筹集 3,600 美元——"那简直就是杯水车薪！"西姆斯跟同事说，"我们需要做得更大一点！"
- 6 年级学生制作了关于筹款活动的视频，开始通过社交媒体宣传；高中生加入，学区的其他人用 Facebook、Twitter 等社交媒体传播消息；"这才开始快速发展"——不久全国新闻工作者开始拍摄课堂过程

结果：**项目启动一个月后，基金会完成了募集 100 万美元的捐款目标**。"对于学生来说，这是个难忘的成就，他们通过这个项目发现了数学和媒体的力量，把学习延展到了课堂之外。"

启示：这个案例把本课三节课连成一条线——**C_3（社群）**：项目源于对同学的同情与关怀，社群（同学、家庭、学区、网络）是项目燃料；**C_6（积极协作）**：科学老师、语文老师、高中生、学区伙伴的善意协作让项目不断升级；**C_6.1（生态协作）**：互联网、同伴、资源、社交媒体都是"接触点"，学生学会了"这个项目的关键联系是什么"。对线上 PBL 来说：社群不是背景板，而是项目能走多远的决定性力量。
