## 📖 主线正文（整理自视频课 C_5 / C_5.1 / C_10）

### 一、共同设计：主导学习者的关键时刻

"现在，这就是你作为主导学习者的技能受到考验的时候了，因为你现在的任务是通过共同设计的过程，帮他们把那个提议塑造成一个良好的项目设计。"

这意味着要做几件 PBL 里传统上会做的事情：
- **使用设计指南**："你要使用在线设计指南。我附上了一个简化版的其他设计指南，因为在线设计比基于课堂的设计过程要简单一些。但你应该用设计指南来规划项目的步骤。"
- **塑造驱动性问题**："要解决的问题是什么？这永远是优秀项目成功的关键，也永远是个挑战。你要帮助学生真正提出并清晰地表达那个挑战性的问题。"
- **设定里程碑、截止日期和时间表**："然后随着他们推进，他们要设定里程碑、截止日期和时间表。他们需要帮助来按时完成项目。"
- **塑造最终成果**："他们要展示给谁看？成果会是什么？他们怎么让它公开？"
- **处理标准与内容**："在线激情驱动、目的驱动的项目中，总是会涉及标准和内容的问题。你得弄清楚内容在哪里、标准是什么、它们怎么融入项目。"

### 二、流程颠倒：从激情出发，把内容"放进去"

"这很有意思，因为它有点颠倒了你的常规工作流程。通常，你可能会从内容成果和标准开始，然后围绕这些设计项目。在这种情况下，**你从目的和激情出发，从学生的兴趣出发**。当他们提出这个项目点子时，你的任务就是弄清楚那些内容标准和成果该放在哪里。"

- "你可能得把它们作为项目的直接教学部分。如果你在做在线教学，你可以进行同步项目教学、直接教学，就像在普通科目中那样，或者你当然也可以让他们自己做探究和调查。"
- "不管你怎么做，挑战在于怎么把内容放进去。"
- "内容会因科目、学生、一年中的时间、测试环境等因素而变化。有时候你得做更多的直接教学，得有更重的标准和学习内容的清单，可能还要配一些练习题……或者在某些科目中，你可以减少标准和成果，让学生专注于项目中真实的激情驱动部分。"
- "这真的取决于你作为在线项目式学习老师的判断，不总是容易的，但这就是你在和学生一起进行共同设计过程中必须做的。"

### 三、设计线上 PBL：目标驱动 vs 兴趣驱动

"让我们看看这组幻灯片，了解一些实际步骤，你需要采取这些步骤来成功帮助学生设计和参与在线项目。"

- **记住 PBL 全球工具箱**："看一下，我已经把所有关于远程和在线 PBL 的工具都加进去了，这样你就知道有一套完整的工具可以用于在线工作。"
- **高质量项目设计的原则不变**："注意高质量的项目设计。你仍然要使用挑战、原因、驱动问题和好的评估。你真的是以终为始。你在设计、在解决问题，最后达到精通。所以你是在运用所有高质量的原则。"

**两类项目的设计工具不同**：
- **目标驱动的项目**（更多由教师主导和指导）→ 用**在线项目设计指南**："你得注意那个'为什么'——项目背后的原因是什么？要解决的问题是什么？那就是驱动问题。核心标准，解决方案会如何影响世界？学习成果会怎么分享？协作会怎么进行？"
- **兴趣项目**（学生自己设计项目）→ 用**项目提案表**："项目提案表会问学生一系列问题。它会从'为什么'开始：这个项目为什么重要？它会带来什么？"

### 四、项目提案表：从"为什么"到"可衡量的正面影响"

**记住同理心**："记住在整个过程中同理心的作用。你在开始一个设计过程。你让学生去观察世界、社区和问题，他们试图弄清楚：我能做什么、为什么重要、我想学什么。这真的是一个同理心的过程，这总是设计过程中的第一步。"

项目提案表引导学生回答的系列问题：
1. **为什么**：这个项目为什么重要？它会带来什么？
2. **要解决的具体问题**："他们通常需要一些帮助，但他们会尝试确定：我到底在解决什么问题？什么让我感到挑战？"（= 驱动问题）
3. **怎么协作**："我会有团队吗？我会用一些同伴吗？我会用父母吗？我会用老师吗？协作是 PBL 的关键部分。"
4. **计划、草稿和设计循环**："他们怎么创建产品、怎么改进？重新设计，这样在项目结束时能拿出最好的作品。他们是在用那个设计和草稿过程。"
5. **可衡量的正面影响**："我喜欢每个项目都有可衡量的正面影响这个想法。影响——你做这个项目的原因是什么，它怎么能真正为世界做贡献？"
6. **时间线里程碑和工作流程**："你会帮他们设定一些时间线里程碑和工作流程，搭建和结构化项目，确保按时完成并赶上截止日期。这在在线项目中很关键，因为有些工作可能会失控，让他们建立日历。"
7. **分享计划**："他们怎么分享项目？他们的分享计划是什么？他们会通过某种媒体展示吗？他们会展示给同学看吗？——我们在 PBL 中努力实现公开分享。"

### 五、打磨与批准：草稿、时间、以人为中心的设计

- **强调草稿和设计步骤**："当他们经历整个过程时，记住强调草稿和设计步骤。这是获得最好作品的关键，你能从学生那里得到的。所以给他们充足的时间做这个项目。不要赶，不要太多，不要压缩，给他们时间去探索、创造，做出最好的作品。"
- **以人为中心的设计方法**："有时候你也可以通过加入一些以人为中心的设计方法来帮他们做出最好的作品。这真的是让他们调查问题、访谈、图像板、画出对问题的想法的一个好方法。换句话说，用他们的想象力和资源。"
- **最后：审查、修改并批准**："在学生开始前审查计划。修改或批准，跟他们设定截止日期，定期检查，并确保他们理解要解决的问题。你可以用这个协议：他们真的在探索驱动性问题吗？花点时间让他们真正理解问题的含义。"
- **分享**："总是对你做的事情感兴趣。任何你觉得有效的想法，能真正提高在线工作质量和参与度的，告诉我们吧。"

### 六、C_10：现在轮到你了——如何为世界作出贡献

"在上一次经历中，我们问过学生如何为世界做贡献。现在，我要稍微转变一下，**问你**如何为世界做贡献？你将如何成为专家？你将如何为在线教育中不断发展的专业知识做出贡献？特别是在线项目式学习？"

- **没有专家**："因为正如我之前所说，现在没有专家。我们所有人都在共同学习，共同创造，共同合作，试图弄清楚未来十年、二十年、三十年的教育会是什么样子。我们并不确切知道。我们只知道它可能会涉及大量的在线工作。"
- **贡献什么**："你能制定一个教案吗？你能分享一个实践吗？你能告诉我们你一直在做什么有效的事情吗？我真的很想听听你的想法。"
- **建立最佳实践**："所有这些工作累积起来，我们开始创造新的工作成果，并建立一套可以向前推进的最佳实践。"
- **重新发明教育**："我们实际上不得不抛弃过去一百年来用于课堂教学的许多最佳实践。我们得清理一些仓库，做些回收利用。因为很多那些材料不再适用了。我们正在重新发明和重塑教育。所以加入这个努力吧。这是一个成为创造性教育者的绝佳机会。"

**给你的行动清单**：
1. 区分你的项目：目标驱动（用在线项目设计指南）还是兴趣驱动（用项目提案表）？
2. 与学生共同设计：驱动问题、里程碑、最终成果、内容如何融入
3. 项目提案表走一遍：为什么→问题→协作→草稿循环→可衡量的正面影响→时间线→分享
4. 强调草稿与迭代，给足时间，不压缩
5. 学生开始前审查-修改-批准；定期检查
6. 把你的实践分享出去，成为线上 PBL 的"专家"之一

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》结语——关于项目制学习未来的 7 大预测

> 本书结语由苏西·博斯与简·克劳斯写下，对未来项目制学习作出 7 大预测——与"变革者"课程"教育正在被重新发明"的判断完全同频。

| # | 预测 | 核心内容 |
|---|------|---------|
| 1 | 项目制学习促进深度学习 | 《地平线报告》自 2012 年起每年强调"深度学习和真实的学习体验"两种趋势；休利特基金会定义深度学习为"掌握知识内容，使学生参与批判性思考、解决问题、协同合作和自主学习"；2018 年《高质量项目制学习框架》把"真实的学习"描述为"学生开展与他们的文化、生活和未来相关的项目方面的学习"——"真实的学习不是趋势，而是必要" |
| 2 | 项目制学习实现规模化发展 | 教师需要"善于设计、能促进以学生为中心的学习、指导学生应对挑战、培养数字化素养"；开创性学区实施课堂学习走访、招募教师领导、成立项目制学习顾问团；"我们见证了一个又一个项目制学习改变整个学校文化的例子" |
| 3 | 普及计算思维 | "没有什么比研发一项新科技更以项目为基础的了。发明者经历的过程跟学生在参与项目制学习时所经历的过程是一模一样的：确定和仔细研究问题，设计并建立雏形，完善解决方案，最终将产品推向世界。"美国劳工部估计到 2024 年美国将有 110 万与计算机数据处理相关的工作岗位，2/3 以上会空缺 |
| 4 | 项目制学习与全球性的目标相结合 | 鼓励学生成为全球公民；#TeachSDGs 教育者网络致力于帮助实现联合国可持续发展目标；"通过全球化的视野和本土化的行动，可以促使学生在解决他们所在社区中存在的问题时，去思考他们的决策会有什么样的全球性影响" |
| 5 | 培养项目制学习思维 | 卡罗尔·德韦克的"成长型思维模式"：努力和坚持的价值，把挫折视为学习机会；安杰拉·达克沃思的"坚毅"：长远坚持挑战性任务；科斯塔和卡利克的 16 种思维习惯（坚持不懈、灵活思考、对不断学习保持开放）；"复盘需要贯穿于项目制学习的整个过程"，建议让学生停下来思考"我现在能做的最明智的事情是什么？" |
| 6 | 重新思考学生学习的时间和方式 | 翻转教室与在线课程普及；"20% 的时间"或"天才一小时"（源自谷歌的 20% 时间实践）；"当学生更多地指导自己的学习时，教师的角色必须改变"；EDUCAUSE 提醒翻转课堂"是一个让人很容易就误入歧途的模式"，精心准备和周全的计划至关重要 |
| 7 | 寻找更多方式共同学习 | 教师继续从互联网学习中受益并更积极地建设社交网络：Twitter 社群 #pblchat、#EdChats，非传统会议和 EdCamp；"任何老师都用不着感到孤立，即使你是你们学校里唯一一个准备推进项目制学习的人" |

**结语中的故事**：挪威奥斯陆山特维卡高中（Sandvika High School）的安·迈克尔森（Ann Michaelsen）想为教育工作者写一本"从学习者角度看问题"的书——于是她邀请 9 年级学生与她共同合著《联合学习者：创建全球课堂的分步指南》，一本 219 页的电子书。"这不是一本教师或教育专家用来告诉你学生想要什么的书。这是一本由学生和他们的老师在一个合作项目中撰写的书，其中的每个声音都很重要。"28 名学生中只有 1 名选择独立研究；项目启动后不到 6 个月完成研究、编写、修改和出版准备。她让 4 名学生担任项目负责人，还有章节编辑的角色——"一个女生告诉我，她一直梦想成为一名编辑……现在，她就有机会成为第 1 章的编辑。在这样的项目中，你会对学生有新的了解。"

## 🛠️ 落地工具：视频创作构思表（工具31）

"项目式学习的阶段性成果、最终成果都可以使用视频的方式进行输出和展示。"——视频是线上 PBL 最自然的成果形态，构思表为"准备、组织和实施各项工作提供框架性的方向和参考"。

```
┌────────────────────────────────────────────────────────┐
│ 视频创作构思表（工具31）                               │
├────────────────────────────────────────────────────────┤
│ ① 前期准备                                            │
│   · 视频脚本创作（选类型：解说型/纪录片型/街头采访/     │
│     创意剪辑/技能分享/情景短剧）                       │
│   · 确定拍摄地点和时间 · 组织拍摄人员及分工            │
│ ② 拍摄与调度                                          │
│   · 现场设备与调度 · 人物、场景、故事情节              │
│   · 镜头运用（远、中、近、特写等）· 回看补拍镜头       │
│ ③ 后期剪辑                                            │
│   · 剪辑软件使用（学生不会→专门安排教学课时）· 剪辑技巧 │
│ ④ 视频效果                                            │
│   · 片头片尾、音效、背景音乐、字幕、字体等             │
│   · 专业特效制作                                       │
└────────────────────────────────────────────────────────┘
```

**解说型视频构思框架**：介绍问题 →（现状）→ 反应（人们对问题的反应/现有对策）→ 解决办法（设想、试验或模型搭建，提供解决办法的建议）→ 结尾展望未来。（书中示例：海洋环境问题——海水质量差→现有对策→污水过滤器/垃圾分拣设备→展望。）

**纪录片型视频构思框架**：找到值得记录的创意 → 调查、准备 → 搭建视频故事结构 → 提前和被拍摄者沟通、熟悉 → 拍摄和剪辑。（"在采访聊天中抓住其主要情绪，挖掘情绪背后的故事。"）

**为何使用**："要创作出高质量的视频作品，在短短几分钟内讲述事实、突出观点，对学生来说是一个'大项目'。"视频展示可能出现在里程碑事件或是最终成果的展示活动中——"在正式开始制作视频之前，教师和学生可使用视频创作构思表来进行规划和安排"。

**使用步骤**（以"让世界看到湖湘漆器之美"项目为例）：
1. **前期准备**：明确故事蓝本和表达方式——该项目选择以湖湘漆器的起源作为故事蓝本，创编有趣故事情节；师生共同决定用**定格动画**（有趣、观赏性强、制作难度比连续动画低，适合该年龄段）；按工作内容为团队成员分配文案、美工、摄影、剪辑等角色
2. **拍摄与调度**：提前计划场地及设备，确保资源到位，"以此倒推项目进度和时间安排"
3. **后期剪辑**：确定剪辑软件；学生从未用过 → 教师安排专门教学课时指导
4. **视频效果**：引导发挥创造力，设计转场效果、选择背景音乐——"学生不仅加深了对湖湘漆器的了解，还综合运用了音乐、美术等表现形式，提高了艺术素养"

> 💡 **研学场景示例**：
> - 布达佩斯展线上研学：学生产出"云端看展"解说型视频——按"介绍匈牙利文物→观众对文物的反应→文物流转与保护的建议→展望'如果文物会说话'"框架构思（呼应解说型框架）
> - 良渚研学：学生做"良渚的一天"纪录片型视频——先找值得记录的创意（考古工作者的一天），再调查准备、搭建故事结构、提前与采访对象沟通建立信任、拍摄剪辑

## 📖 案例（《PBL项目制学习》）

### 快闪自然历史博物馆：学生当"策展人"的创造者项目

背景：学校有位教师知道"很多孩子对动物感兴趣"，于是想到"这是一个好机会，可以让学生有机会成为博物馆的'负责人'"。整个年级的学生相互协作，共同规划了一个项目：**创立他们自己的快闪自然历史博物馆**，展示可供学生观察和研究的小动物（昆虫、小型哺乳动物、爬行动物）。

过程：
- 共享式规划帮助教师识别课程中的关联内容，并预测项目关键阶段的具体学习活动；在项目日历上布局安排，"计划什么时候把重点从前期研究转向头脑风暴，或从产品制作转向展示成果"
- 早期研究阶段，学生在 4 个教室轮流探讨问题，"找了不同的老师做不同方面的研究"，包括书本、图片、精选网站和视频资源
- 项目后期，学生设计自己的展品时，可以选择去哪个教室参加研讨会；每位教师提供使用不同材料的方法（纸胶混合物、科技手段结合展品设计）
- 快闪博物馆在展出 3 小时后拆除，所有展品都进行了系统分类
- 一个学生在参观一个有音频录音的博物馆后，决心在蝴蝶展品中加入声效——教师帮他找到了成百上千只蝴蝶拍动翅膀的录音，参观者可在 iPad 上按按钮听到声音

结果：教师复盘时一致认为，同侪反馈文化在项目期间带来好处；学生的听说能力、文本组织能力、专业词汇运用都显著进步（"拥有语言的所有权让他们充满了学习的力量"）。教师说："孩子们对项目制学习很买账，这就让我们都能继续下去。""这个项目的成功说明了项目制学习是可行的。"

启示：这是"让学生成为创造者"的完整样本——**学生是策展人（角色）、有选择权（去哪个教室参加研讨会）、产出真实产品（博物馆展览）、面向真实观众（参观者）**。教师用共享式规划+项目日历"搭脚手架"（C_5 的里程碑/时间表），却把创造的决定权交给学生（C_5.1 的兴趣驱动项目），学生甚至主动提出加声效的迭代（草稿与设计循环）。对线上 PBL：创造者的舞台可以从"快闪博物馆"平移为"云端博物馆/线上展览"。

**题 3（判断）**：一个线上项目"什么都好，就是学生最后只交了个半成品"。请用本课至少两层原因分析，并给出对策。

<details><summary>答案</summary>

(1) **时间被压缩**（C_5.1）——"给他们充足的时间做这个项目。不要赶，不要太多，不要压缩，给他们时间去探索、创造，做出最好的作品"；线上完成需要比预期更多时间（呼应课 6.3"数字环境中完成任务需要更多时间"）。(2) **缺少草稿与设计循环**——"强调草稿和设计步骤，这是获得最好作品的关键"；项目应内置"创建产品→改进→重新设计"的循环。(3) **里程碑与定期检查缺失**——"你会帮他们设定时间线里程碑和工作流程……这在在线项目中很关键，因为有些工作可能会失控"；还要"定期检查，并确保他们理解要解决的问题"。对策：加宽时间轴、内置草稿评审节点、建立定期检查协议。
</details>
