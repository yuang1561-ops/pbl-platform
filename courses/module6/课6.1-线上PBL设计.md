## 📌 本课导读

线上 PBL 是整套课程里"最未被充分探索的领域"——变革者课程开篇就说：**"这里没有真正的专家。"** 汤姆·马卡姆（PBL Global 创始人）邀请每一位老师"来帮忙当专家"，因为"有一些巨大的转变正在向我们袭来，我们作为教育者必须去应对这些"。线上做项目式学习，不管是完全在线还是混合环境，已经是趋势，往后我们可能都需要这类技能。

本课整合四段视频课：**C_1**（你准备好重构学习了吗）讲大趋势与两个核心转变，**C_1.1**（八个转变）把教育面临的全球性挑战逐条展开，**C_2**（建立新的学习生态）对比新旧生态并给出"不要补救，要加速"的立场，**C_2.1**（开展线上PBL）给出教师角色、团队协作、结果导向、规则制定四个实操变化。配套工具是**《50个工具》工具18 KWL表格**和**《50个工具》工具19 STW三步提问法**——两件"探路"神器，正好用于线上项目启动期的摸底与提问。

## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、变革者的邀请：线上 PBL 是一片新大陆

汤姆开场就定调："我们要用项目式学习来探讨一些不一样的东西——怎么在线上做项目式学习，不管是完全在线环境还是混合环境。我们知道这趋势来了，我们会看到更多这样的情况。"

- **技能必要性**："作为项目式学习老师，你掌握线上工作的技能很重要。不管我们面对什么样的危机，往后我们可能都需要这类技能。"
- **没有专家**："当我谈到线上项目式学习，我指的是一个还没被充分探索的领域。这里没有真正的专家。所以我希望通过这个课程，请你来帮忙当专家。"
- **邀请共创**："我希望你在课程里评论，分享你的创新，我真的希望你能成为变革者……告诉我们你在做什么，什么对你有效，你面临什么挑战，因为我们现在一起在创造未来几十年的教育。"
- **这是好时代**："这是教育中一个了不起的时代，实际上是一个当老师的好时机……让我们弄清楚未来的教育会是什么样子，让我们真正重新发明——这真的是这个课程的目的。"

> 提醒：变革者课程建立在实践者课程、引导者课程的基础之上——设计指南、工具箱、PBL 的基础和基本原理都要先掌握，"你必须掌握这些，才能把在线工作做好"。这门课是在这些基础上"展望未来"，有时被称作 **PBL 2.0**。

### 二、教育转型的大方向：两个先发生的转变

"我们做越多线上工作，第一个转变，第一件必须发生的事就是学生得更加自主。"

**转变一：学生更自主**——学生要"站出来，更自我管理，更能设计自己的项目，更能挖掘自己的热情和使命感"；老师帮助学生"真正设计出对世界有意义的项目"，"在线环境真的增加了做个性化真实项目的机会"。

**转变二：老师的角色变了**——"当我们做线上项目式学习时，我们真的转向一个真正的引导者角色"。汤姆称之为"**共同学习者或主导学习者**"："关键是你和学生一起工作，帮他们设计项目，而不是你主导整个项目。"

**背后的深层转变**："我们真的从更应试驱动、课程导向的学习形式，转向更个性化、真实的学习形式。项目式学习完美契合这个转变，而且这个转变不会停止。"——"如果你关注新闻和教育，你会看到有人在质疑标准化考试……所以这个机会现在向我们所有人敞开了。"

### 三、八个转变：未来几十年教育者要扛起的挑战

汤姆说"我脑子里至少有八个转变，是我们作为教育者在未来几十年要面对的。学习会有大变化，学生会有大变化，老师也会有大变化。"

**1. 世界变得混乱了（VUCA）**：多变、不确定、复杂、模糊（V-U-C-A）就是我们生活的世界，要转向"愿景、理解、清晰、敏捷"。"这是观念上的大转变，要想成功，这是必须的。"

**2. 课程体系淡出，走向个性化学习**："我们正走向更个性化的学习形式：真实性、连接、社会情感学习、优势——这些是人们在当今世界真正需要成功的东西。所以，不只是考试。"

**3. 学生站出来，掌控自己的学习**："少点老师主导，多点学生主导。他们在学怎么有创意、怎么当设计师、怎么管好自己。对我们老师来说是大挑战：怎么训练学生成为更好的自我管理学习者？"

**4. 抛弃分数和证书**："我们不太关心学生在考试里表现如何，更关心他们能不能掌握内容、展示能力、证明能力。学生展示他们能做什么，不只是通过考试。"

**5. 真实学习（现实教学法）**："学生想改变这个世界……学生想做出贡献，那是释放激情和目标的东西。这很适合项目式学习——项目可以围绕激情和目标来设计。"

**6. 公平：给地球上每个人学习的机会**："从特权到公平，我们必须给地球上每个人学习的机会。这意味着他们得有设备、有电脑、有技术接入……光教育地球的一部分是不够的——我们是在教育整个星球。"

**7. 全球教育**："我们作为地球有多紧密。光欣赏其他文化是不够的，得有深深的欣赏感、谦卑、互相学习。"

**8. 善良和贡献**："我们怎么到处推广善良和贡献？……因为我们需要一个更善良、更投入的世界，在那里我们为彼此的健康、福祉和幸福做贡献。贡献和善良很重要。"

> 八个转变之后，汤姆再次把话筒交给学习者："随着课程推进，我要问你们：你们打算怎么创新？你会贡献什么？你怎么让这发生？这得靠我们所有人。现在没有专家，你就是专家。"

### 四、从旧生态到新生态：一切都不一样了

**旧生态系统**（我们非常熟悉）："学生们来到校园，排队进入教室……通常有课桌排成排，老师通常站在教室前面。有书本，有国旗，有教室里所有熟悉的装饰。"

**新生态系统**："我们让学生坐在家里，环境五花八门，有的好，有的差。他们看着老师，但隔着屏幕；老师看着他们，但也隔着屏幕。每个人都有能力静音或消失——学生们要么消失，要么在自己面前放个纸板剪影。老师无法理解这一点，所以老师们在想：我怎么保持学生的参与度呢？然后他们让学生异步离线做作业，有时候作业完成了，有时候没有。"

**关键认知**："当这种转变发生时，不仅仅是环境，你的大脑、感受和情绪都在转变。这里有一个非常深层的转变。"

**我们怎么应对？——为远程学习重新组织**："老师们正在想出各种好主意来重新组织远程学习。怎么让它运作起来，怎么让它更好，怎么教学，怎么吸引学生，怎么保持学生的灵感，这样他们就不会消失，实际上还愿意继续面对屏幕，继续参与。"

- **最好的方法之一**："提供高质量的项目工作机会，吸引学生，真正让他们展示创造力。获得灵感去做工作。这对他们来说有意义。"
- **核心立场（金句）**："这比所谓的补救方法重要得多……**我的建议是不要补救，要加速。** 让我们开展真实的在线工作，这样学生可以测试自己，真正做出好成绩。通过真实高质量的项目式学习，这是可能的。"
- **重新组织的方向**："四面墙的教室、排成一排的课桌、站在前面的老师，这些都不再那么管用了。新生态系统是关于想象学生正在经历什么，思考老师需要经历什么以及他们怎么教学，然后围绕这些设计系统。"

### 五、为线上开展重新组织：四个实操变化（C_2.1）

"如果你已经参与过远程教学或混合教学，你应该很清楚，游戏规则在很多方面已经变了。有些方面更难了，有些方面更好了。但变化没那么快的是我们调整系统以适应远程学习机会的能力。实际上，大多数情况下我们做的就是把课堂体验直接搬到远程环境里——但这是行不通的。我们必须思考如何真正为虚拟世界重新组织。"

**变化1：从"学科专家"到"引领学习者"**："做远程教学时，仅仅当个学科专家——数学老师、英语老师、社会研究老师——是不够的。你更像是一个引领学习者。学校重新定义教师角色……这样效果确实好得多。"

**变化2：不要单打独斗，以团队形式工作**："另一个阻碍是老师们试图单打独斗，结果就是他们筋疲力尽、身心俱疲。远程教学实际上要求你以团队形式工作。如果你在中学环境，做跨学科项目吧，和一两个老师搭档……如果你是小学老师，找个搭档一起干。关键是重新组织你的学校，作为远程团队，作为虚拟支持系统。"

**变化3：结果导向变了——价值观、品格、贡献**："远程教学改变了结果导向，这可能是我们面临的最大问题之一。不再是考试和练习题，我们现在关注的是价值观、品格、贡献——像马克·普林斯基列出的这些方面：成就、改善世界、积极行动、应用热情、把事情做成，在现实世界中思考和行动。"

**变化4：提前和团队达成一致 + 建立规则**。开课前要和搭档及教学团队对齐：
- 我们要达成什么目标，怎么去做？
- "激情驱动的项目通常由学生设计，目标驱动的项目通常由教师主导；异步和同步教学的比例怎么定？"
- "你会把哪些关键标准纳入项目中？你是用特定学科内容还是用主题来做项目？"
- "内容掌握和社会情感成长哪个更重要，你打算怎么评估？"
- "我们有一个很好的学习设计表格，可以帮助你和学生设计项目。"
- **关于规则**："确保你和他们讨论规则。这是老师们用 Zoom 时的一个大问题，学生不断掉线……确保你建立并讨论规则，让他们同意，当感觉课堂进展不顺利时，回到规则上。"

### 六、给你的行动清单（把四段课变成动作）

1. **接受"没有专家"**：把线上 PBL 当作共创实验，记录"什么对我有效、我面临什么挑战"，成为变革者
2. **检查自己的两个角色转变**：学生是否更自主？我是否真的在当"共同学习者"而不是主导者？
3. **对照八个转变自问**：我的课程在向"个性化、真实性、学生主导、能力展示、真实学习、公平、全球、善良"中的哪一个前进？
4. **为远程重新组织**：不把课堂体验照搬上线；提供高质量项目工作，"不要补救，要加速"
5. **找搭档**：中学做跨学科项目，小学找教学伙伴；以远程团队/虚拟支持系统的形式组织学校
6. **开课前对齐 + 定规则**：用学习设计表格和学生一起设计项目；建立并讨论线上规则，进展不顺时回到规则

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》中文版序——你是否准备好开始项目制学习

苏西·博斯（本书作者之一）2019 年秋季访问上海，会见了许多中国的教育工作者，讨论了同一个问题："在一个以教师为主导的、传统教学有着悠久而成功的历史的国家里，我们是否已准备好开始以学生为中心的学习？"

- **为什么开始 PBL**："为一些重大的考试所做的准备，并不能让学生成为有创造力的思考者或有创新性的设计师……学生并不需要熟记知识内容，而需要能够将他们所学的知识应用在新的环境中。事实上，为大学、职场和履行公民义务所做的最佳准备，就是让学生成为终身学习者。"
- **教师的角色转变**："在按照预期开展的项目制学习中，教师的角色会从课堂上的专家，转变成为知识渊博的学习指导者或推动者。课堂管理、评估策略，甚至对学习空间的布置都会发生相应的变化。"
- **中国教师的真实顾虑**："我记得有一次研讨会上讨论的是如何指导学生提出更好的问题。一位参会者打断场上的讨论，并说道：'我们的学生不会问问题。在中国，提问的是老师。' 在项目制学习中，参与度是由学生的提问建立的……探究从头到尾为项目提供动力。"
- **身边的真实案例**：小学生把 STEM 学科的学习放在中国皮影戏中，把传统的讲故事与学习光和影的知识结合起来；初中生做"给老年人带来更多幸福感"的项目；高中生从本地着手，为实现联合国可持续发展目标助力。
- **给教育者的建议**："教育者可以通过分享项目思路、课堂策略和成功案例来推动这一新兴运动。"

> 这一段和 C_1"变革者邀请"互为呼应：线上 PBL 的底色，正是"教师从专家变成共同学习者"这一全球共识。

## 🛠️ 落地工具：KWL 表格（《50个工具》工具18）+ STW 三步提问法（《50个工具》工具19）

线上项目启动前，学生彼此不见面、教师摸不清底细——这两件工具就是"探路"双件套：KWL 摸底（知道什么/想知道什么），STW 练观察提问（看到/想到/想知道）。

### 工具 18 KWL 表格

```
┌────────────────────────────────────────────────────────┐
│ KWL 表格（唐娜·奥格尔 1986 年提出）                      │
├──────────────────┬──────────────────┬──────────────────┤
│ K 我知道什么？    │ W 我想知道什么？  │ L 我学到了什么？  │
│ What I know      │ What I want to know │ What I have learned │
├──────────────────┼──────────────────┼──────────────────┤
│ （课前填写，可自  │ （课前填写，最好  │ （课后填写）      │
│   主填+小组头脑   │   自主填写：列举→ │  哪些问题符合预   │
│   风暴查缺补漏）  │   归类→筛选出最   │  期？哪些没解决？ │
│                  │   想知道的几类）  │  还可拓展哪些学   │
│                  │                  │  习活动？         │
└──────────────────┴──────────────────┴──────────────────┘
```

**为何使用**：KWL 引导学习者基于已有知识或经验，在主动思考和建构中学习，"培养学生提出预期、检验成果的思维方式，使他们成为一名有方向的学习者、主动建构的学习者和积极的反思者"。它不止用于阅读——"也可以用于对一节课或一段经历的思考"，甚至"在参观博物馆之前、开始一个科学实验之前"都能用。教师可以做**大周期 KWL**：项目一开始请学生梳理已知和想知，作为探究方向；项目结束后回顾学到什么，检验学习效果。

**使用步骤**：
1. 明确研究对象（一个主题、一篇文章、一次博物馆之行）
2. 教学活动开始前：学生填写第一列 K（我知道什么），可以自主填写，也可以通过团队头脑风暴查缺补漏
3. 继续填写第二列 W（我想知道什么）——最好自主填写，先列举问题，再归类筛选出最想知道的几类；教师适当引导，对"过于不切实际的想法"适当提醒
4. 学习活动结束后（或结束前的课上预留时间）：填写第三列 L（我学到了什么）——哪些问题符合预期、哪些还没解决、后续可开展哪些拓展学习
5. 把"没解决"的 W 直接变成下一轮探究的问题清单

> 💡 **研学场景示例**：
> - 线上云端博物馆课：去杭州博物馆数字展厅"看展"前，让学生填 K 列（我知道的杭州博物馆/文物）和 W 列（最想知道的三件文物背后的故事）——带着问题看展，看完填 L 列，把"没找到答案"的问题变成下一次云端课的探究方向
> - 良渚古城遗址公园线上研学：先 KWL 摸底"良渚文化"，再把 L 列中"还没解决"的问题（如"玉琮上的神人兽面纹到底什么意思？"）转成驱动性问题的素材库

### 工具 19 STW 三步提问法

```
┌────────────────────────────────────────────────────────┐
│ STW 三步提问法（源自哈佛大学教育研究生院"零点计划"）      │
├──────────────────┬──────────────────┬──────────────────┤
│ S 我看到了……     │ T 我想到了……      │ W 我想知道……      │
│ I see            │ I think          │ I wonder         │
├──────────────────┼──────────────────┼──────────────────┤
│ 只观察，不做主观  │ 尝试解释：为什么  │ 说出想进一步了解   │
│ 判断，记录线索    │ 会有这些信息？理  │ 的信息，提出问题   │
│                  │ 由？团队讨论换意见 │                  │
└──────────────────┴──────────────────┴──────────────────┘
```

**为何使用**：STW 鼓励学习者"进行仔细的观察和深刻的理解，然后再提出疑问，有助于激发学习者的好奇心，为后续探究做好准备"。"在真实的课堂中，教师经常反映学生提不出好问题。此时我们应该反思的是，我们是否给了学生足够的时间去观察、去思考，又能否接纳他们提出的所有问题？"——"好的创意经常来自好问题。"注意：**"刚刚使用这个工具的教师一定要具备足够的耐心，等待学生做好提问的准备，也准备好迎接学生可能给我们带来惊喜的好问题。"**

**使用步骤**：
1. 明确研究对象——是一张照片、一件艺术品、一段视频、一篇新闻稿，还是一种社会现象？（帮助学生聚焦）
2. 引导学生观察，先不做主观判断，只记录看到的信息或线索 → 填 S 列
3. 请学生尝试解释观察到的信息：为什么会有这些信息？你的理由是什么？你想到了什么？——团队讨论交换意见、拓展思路 → 填 T 列
4. 引导学生说出想进一步了解的信息并提问 → 填 W 列
5. 把 W 列的问题按"探究可行性"筛选排序，作为下一步探究的入口

> 💡 **研学场景示例**：
> - 布达佩斯展线上展：学生先只看三张匈牙利文物高清图（不看说明牌），按 S→T→W 走一遍——"我看到了金色马具上的纹样""我想到了游牧民族""我想知道它们是怎么来到中国的？"——观察和提问先于讲解，线上看展从"被动听"变"主动探"
> - 西湖博物馆"西湖十景"古画线上课：先观察画作细节（S），再讨论古人为什么这样画（T），最后提出自己的问题（W）——"现在的西湖和画里一样吗？"变成下一节课的探究起点
> - 云端看良渚玉器微距影像：用 STW 让学生先观察玉器纹理再提问，把"老师讲、学生记"翻转为"学生问、一起找答案"

## 📖 案例（行动者手册）

### 《PBL 行动者手册》共创故事：12 个人，四周，一本线上共创的书

背景：《PBL 行动者手册》本身就是一次线上 PBL 的完美样本：12 位原本并不熟识的伙伴，靠着同一个愿景和目标的牵引，用完全 PBL 的方式"运营"这个项目——"让共创者经历一次真实的项目"。

过程：
- 共同设立成功标准；以审核组、编辑组、运营组、项目组高度交叉的职能分工来分组
- 用协作文档和项目进度追踪表管理进度；交叉组合，多次讨论、反馈、修改、迭代
- 组织者不断重申"各个职能小组有直接做决定的权利"，努力不让自己成为项目的天花板（过多预设）和限速瓶颈（不够放权）
- 发布前夜，各职能群还在滚动着大量信息；临发布前一天重新设计 Logo 和整体视觉——"难以想象这么大的改动在几个小时内一一实现了。比起'不可能'，大家更愿意说'我来试试吧'"
- 经过一个半星期的磨合，项目小组真的自主运转起来了

结果：一本收录 10 个案例、覆盖"项目概述—实施过程—项目评价—项目工具"四部分的手册在共创中诞生。

启示：这个案例把 C_1/C_2 的理念全部"演"了一遍：**共创者更自主、组织者当"共同学习者"、用协作文档与进度追踪表重新组织远程协作、以真实产品（手册）为导向**。没有专家、一起共创，正是线上 PBL 的常态——"缺乏行动的认可是苍白的"，迈出第一步比追求完美重要。
