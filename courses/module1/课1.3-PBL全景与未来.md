## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、课程全景：五门课程 + 16 个体验的播放列表

汤姆·马卡姆开场自我介绍："我是 PBL Global 的创始人"，欢迎来到实践者课程——"实践者课程是五门课程中的第一门，它将帮助你成为一名高技能的项目式学习教师。"

**为什么有五门课程？** 因为"项目式学习很复杂"：

> "成为一名项目式学习教师需要高水平的技能。仅仅对你说或对任何其他老师说，你需要做一个'旁边的引导者'是不够的。你不能再做'台上的圣人'，或者像人们有时说的，'黑板的主宰'。"

五门课程：**实践者、变革者、引导者、教练、导师**。做出"从台上的圣人到旁边的引导者"的转变是好的，但"真正需要哪些技能才能成功呢？这五门课程会告诉你"。课程组织方式是 16 个体验环节，"我称之为一个播放列表"，每个环节由多种媒体组成（直接讲解、视频、PPT）。

### 二、从你开始：老师也要经历学生经历的那种成长

一个可能让你惊讶的安排："我们开始时**不会从方法入手**。我们不会从策略开始。我们不会从课程开始。**我们要从你开始。**"原因："当你自己也经历我们期望学生经历的那种成长时，项目式学习效果最好。……我们希望学生发展他们现在所谓的软技能——关系技能、韧性技能、好奇心技能。在某种程度上，**你现在也被要求掌握一些同样的技能。**"

### 三、工作坊的故事："我们现在需要当心理治疗师吗？"——是的

汤姆讲了一个真实的工作坊插曲：房间后面有个男人双臂交叉，表情很不高兴。汤姆讲到"在项目式学习过程中建立关怀和关系至关重要"，男人举起手问："**你什么意思？我们现在需要当心理治疗师吗？**"

汤姆的回答："简短的回答是，**是的，你确实需要。**你得有非常好的关系技能，你得有好的指导和教练技能，你得能读懂学生、观察学生、好好倾听学生，并且**不带评判地和他们合作**，以一种开放的态度，让他们把技能发展到最大限度。"

> 这就是 P_1 的核心态度：PBL 教师的"软技能"不是选修，是必修。

### 四、成为 PBL 教师的 5 件事（本课干货核心）

**第 1 件：思维转变——从课程计划者变成设计师**
- "就是从做课程计划的人，变成设计师，像设计师一样思考"；你在设计一个两周、四周或任何时长的学习体验，"从整体上看，从头到尾"
- 用一本好书打比方：读完一本小说时你学到东西、"在某种程度上你变成了一个不同的人"——"这就是项目式学习的最高目标：**让学生对自己的态度有所改变**，我见过很多很多次"

**第 2 件：和同事协作**
- "第二是你必须和同事在项目式学习上协作"。汤姆知道这不总是容易的："很多学校其实没有为协作时间做好准备……但你必须想办法挤出时间"
- 金句："**项目式学习对一个人的大脑来说太大了。**它很复杂。越多的人能看你的项目，越多的人能和你讨论你的项目，就越好。"
- 行动建议：如果现在有一两个同事也想一起上课，"抓住他们，帮他们报名"

**第 3 件：建立你自己的"生态系统"**
- "我无法告诉你关于项目式学习你需要知道的一切。没有人能做到。没有一本书。没有一门课程。没有一个网站能真正让你准备好应对项目式学习的所有复杂性。"
- 所以你需要建立**你的生态系统**：资源、网站、范例。这门课程会提供很多支持（网站、视频、去哪里找的想法），但"你需要自己去探索这些"，"建立你自己的资源库，才能成为一名优秀的项目式学习老师"

**第 4 件：审视自己的信念**
- "开始审视你自己关于学生学什么、怎么学以及项目式学习是否真的能让他们达到目标的信念"
- 真实案例：一位校长告诉汤姆，"项目式学习只适合职业学校的学生"——"这不是真的。项目式学习适合各种类型的学生，对尖子生、非常优秀的学生效果很好，对学习困难的学生也效果很好"。"关键在于设计……你可以克服项目式学习中的任何障碍，让它真正、真正地发挥作用。"
- 这意味着你要开始拒绝常见批评："学生真的不会一起团队合作"（我们有工具克服）、"他们会玩得太疯或者捣乱太多"（你可以通过项目式学习影响行为）、"成绩很差的学生做不到"（同样可以被设计克服）
- 汤姆的结论："人们通常指出的项目式学习的每一个问题，**我发现其实都不是真的**。关键在于设置、设计和你带来的东西。"

**第 5 件：掌握基础知识**
- "最后的目标是，你必须掌握项目式学习的基础知识。这就是这门课程的内容。"实践者课程给你"基础、根基，以及成为高质量项目式学习老师所需的一切，至少从项目设计的角度来看是这样"
- 你会看到"项目式学习不同于老式的传统项目。它真的是一种设计过程"——"不要把项目仅仅看作孩子们离开座位做点有趣的事。它远不止于此。"

### 五、给你的随身工具与最后提醒

汤姆建议下载两份资料随身携带：**①项目式学习设计和辅导指南**（"放在电脑上，放在手机上，查阅它，阅读它，使用它"）；**②个人反思和评估指南（评分标准）**——他说当今教育中一个很大的空白是：过去十年他们一直告诉老师"你是旁观的引导者"，却没说"那是什么意思？需要什么技能？"；这个评分标准列出了所有课程的类别（实践者、引导者、教练、导师、变革者等），"你可以圈出那个评分标准，和同事讨论它，用它来自我评估你的成长，并规划你前进的旅程，成为我所说的**面向未来的老师**。"

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》引言——智能时代如何做好项目制学习

引言以时间坐标开场：2007 年第一版时，Twitter 刚问世 1 年、还没有 EdCamp、谷歌刚收购 Writely、苹果刚推出 iPhone。"科技前沿的变迁日新月异"，但作者强调："**唯一没有改变的是，我们强调以学习目标为先，然后寻找合适的工具来帮助我们实现这些目标。**"

**推动智能时代 PBL 兴起的 5 大趋势**：

| 趋势 | 要点 |
|------|------|
| 深度学习 | 高质量 PBL 在强调学术知识的同时重视技能培养（协作、批判性思维），引发深度学习 |
| 教育平等 | 无论来自哪个区域、家庭背景如何，所有学生都应获得走向成功之路的真实世界学习经验 |
| 参与 | 学生在学校待的时间越长，学习参与度越低；PBL 强调学生话语权、把学术学习和兴趣联系起来，是"一剂妙方" |
| 更新标准 | 死记硬背的知识可瞬间在网上搜到，标准被修订为更强调知识运用；ISTE 标准呼吁学生会分析、有同理心、能综合、会举证、能创造、会沟通 |
| 计算思维和编程 | 为解决问题提供新方法和新表达形式；非技术背景的教师也要认识到"发现问题和提出问题"的重要性——这是 PBL 和计算思维的共同关键特征 |

**"开启项目制学习征程"的 4 个信念**：
1. **今天的学生能够迎接挑战**——数字世界已渗透学生生活方方面面，大部分学生已做好利用数字化工具学习的准备
2. **项目制学习值得我们付出努力**——教师常说："对同样的课，我不再一遍遍地'炒冷饭'了。因为在教学的过程中，我也在学习。"很多教师会说："我再也不会回到以前的教学方式了。"
3. **学生在真实的世界里生活和学习**——"你是愿意看到你的学生把他们的'学习成果'丢进垃圾桶里，还是想看到他们饶有兴趣地谈论一直驱动他们学习的一个真实项目？"（如科学老师把学生当成研究人员，项目尾声发布专题论文或参与社区研讨会）
4. **新环境促进了项目制学习**——教师团队协作、专业学习社群、跨学科教学、一对一数字化、翻转课堂、创客举措，都扩大了学生使用数字工具的渠道

**"把这本书变成你自己的项目"**：作者建议把书当作一个学习项目，在页边做标记、尝试推荐的科技工具——"你要成为一个适应你所在环境的积极学习者。那也是你的学生开始设计和实施有效的项目时会经历的学习过程。"（与 P_1"从你开始"完全一致。）

### 《PBL项目制学习》结语——关于项目制学习未来的 7 大预测

结语先讲了一个趋势信号：肯塔基州丹维尔学区督学卡门·科尔曼带领整个学区向"为学生上大学和就业做好准备"转型，学区被评为"创新学区"，获盖茨基金会"下一代学习挑战"资助金。家长说："我们希望孩子有更好的学习体验。"——"更好"不是记忆测试高分，而是"更深入的学习、运用知识做原创的东西、与他人有效合作、适应未来的变化"。

**预测 1：促进深度学习**。《地平线报告 K-12 版》自 2012 年起每年强调两个趋势——深度学习和真实的学习体验，"从我们的角度来看，这两种趋势等同于项目制学习"；最新报告甚至说真实的学习"不是趋势，而是必要"。创客空间、机器人、编程被纳入课程，学生"转型为问题解决者和创造者"。

**预测 2：实现规模化发展**。最大挑战之一是重新思考教师角色。可持续的教师专业发展和合作机会将越来越大：课堂学习走访、招募早期采用 PBL 的教师担任教师领导、成立项目制学习顾问团、成熟学校中教师互评项目。对孤立状态中做 PBL 的教师，"这些网络可以成为他们获得同行支持和帮助的生命线"。

**预测 3：普及计算思维**。"没有什么比研发一项新科技更以项目为基础的了"——发明者的过程（确定和仔细研究问题、设计并建立雏形、完善解决方案、推向世界）和学生在 PBL 中的经历一模一样。数据背景：美国劳工部估计到 2024 年将有 110 万个计算机数据处理相关岗位，其中 2/3 以上因缺乏合格人员而空缺；2016 谷歌-盖洛普报告显示超 90% 的家长认为学习计算机科学是对学校资源很好的利用。

**预测 4：与全球性的目标相结合**。ISTE 标准概述"全球合作者"素养；PISA 加入学生全球竞争能力评估；#TeachSDGs 教育者网络致力于联合国可持续发展目标。同时"没理由放弃专注于本地的项目"——"**通过全球化的视野和本土化的行动**，促使学生在解决社区问题时思考决策的全球性影响"。

**预测 5：培养项目制学习思维**。人们越来越关注态度和动机：卡罗尔·德韦克的"成长型思维模式"（努力和坚持的价值，把挫折视为学习和提高的机会）、安杰拉·达克沃思的"坚毅"（长期坚持挑战性任务，像马拉松运动员）；建立在科斯塔和卡利克研究的 16 种思维习惯之上（坚持不懈、灵活思考、对不断学习保持开放）。关键提醒："**不能把复盘推迟到项目结束时。复盘需要贯穿于项目制学习的整个过程。**"科斯塔和卡利克的复盘问题："我现在能做的最明智的事情是什么？"

**预测 6：重新思考学生学习的时间和方式**。翻转教室、在线课程、"20% 的时间"或"天才一小时"（借鉴谷歌生产力实践）正促使教育工作者重新思考学习的时间与方式；教师角色必须改变。EDUCAUSE 提醒翻转课堂"是一个让人很容易就误入歧途的模式"，精心准备和周全计划至关重要。这些趋势"应该是对项目制学习实践的补充"。

**预测 7：寻找更多方式共同学习**。教师将更积极地建立社交网络：#pblchat 和 #EdChats 社群、EdCamp 非传统会议、全球教育会议。"这样一来，任何老师都用不着感到孤立，即使你是你们学校里唯一一个准备推进项目制学习的人。"通过成为互联的学习者，为学生树立榜样。

## 🛠️ 落地工具：PBL 准备度自测（从《PBL项目制学习》引言提炼）

引言末尾提供了"一个简便的方法来衡量你对项目制学习的熟悉程度"，把学习者分为四个阶段——这就是本课的工具：

```
┌─────────────────────────────────────────────────┐
│  PBL 准备度自测（依据《PBL项目制学习》引言）       │
├─────────────────────────────────────────────────┤
│ 读下面的四段描述，选出最像你的一段：              │
│                                                 │
│  A. 神游旅行者：觉得好奇，但还没有做好跟学生     │
│     一起进行项目制学习的准备。                   │
│  B. 新手：刚开始进行第一个项目。                 │
│  C. 探险家：已经在项目式学习上有所成功，         │
│     并渴望进一步拓展。                          │
│  D. 侦查员：资深的项目式学习教师，既能自己       │
│     开展教学，也能对他人进行指导。               │
│                                                 │
│  你现在是：______  半年后希望是：______           │
│  差距在哪（知识/技能/同伴/资源）：____________    │
└─────────────────────────────────────────────────┘
```

**使用步骤**：
1. 诚实地选一个阶段（A/B/C/D）
2. 对照 P_1"5 件事"逐项自评：思维转变（设计师视角？）、同事协作（有人讨论项目吗？）、生态系统（有资源库吗？）、信念（还相信"PBL 只适合好学生"吗？）、基础知识（学过设计方法吗？）
3. 写下从当前阶段到下一阶段最缺的一样东西（例：缺同伴→找共学同事；缺方法→补模块 2 设计课）
4. 每季度重测一次，追踪自己的"成长模式"——这正是 P_1 建议用"个人反思和评估指南"做的事

> 💡 **研学场景示例**（把 PBL 方法落到你的业务）：
> - **课程研发团队**：刚启动研学产品线的团队大多是"神游旅行者"——用自测定位后，先集体学完模块 1-2 再立项，而不是急着上架"伪 PBL"产品。
> - **西湖研学讲师**：已带过几次"西湖诗词研学"（探险家），下一步按预测 4 把项目升级为"全球视野+本地行动"——如让学生为外国游客设计中英双语西湖导览。
> - **良渚/布达佩斯展课程设计者**：达到"侦查员"后，按预测 7 加入线上 PBL 教师社群，把单个课程的迭代经验变成可分享的项目库。

## 📖 案例（《PBL项目制学习》结语）

### 挪威《联合学习者》：师生合著一本书，每个声音都很重要

**背景**：安·迈克尔森是挪威奥斯陆郊区山特维卡高中的行政管理人员兼英语教师，学校约 900 名学生，1:1 笔记本电脑计划让科技无处不在。作为"联合学习者"，她想为教育工作者写一本书，但发现书架上的书"没有哪本是从学习者的角度来看待这些问题的"——于是她邀请 9 年级学生与她共同合著。

**过程**：最终《联合学习者：创建全球课堂的分步指南》诞生——一本 219 页的电子书，序言对"27 名学生和他们的老师"给予同等赞誉。团队花了不到 6 个月完成研究、编写、修改和出版准备。她的做法：项目开始时联系自己的专业学习网络，邀请世界各地的人在谷歌文档上回答问题；用协作工具让学习透明（"每个人都能看到其他人正在研究和写作的内容……而不是将作品交给我，由我统一放在一起"）；让 4 名学生担任项目负责人；章节编辑角色让梦想当编辑的女生实现了愿望（"在这样的项目中，你会对学生有新的了解"）。28 名学生中只有 1 名不参加，选择独立研究项目。

**结果**：书发行时，师生在 Twitter 上开讨论会庆祝，让学生在学校通宵露营参与深夜讨论，来自世界各地的教育工作者参与其中。她通过博文复盘，最受欢迎的讨论主题是"动机"——"具有讽刺意味的是，动机和创新几乎是我们在教育的每一个层面上都会讨论的话题……**我们只是错过了最重要的环节——我们没有花足够的时间和学生讨论这个问题。**"

**启示**：这个案例是 7 大预测的"活的证明"——师生平等合著（预测 7）、真实产品与真实受众（预测 1）、用协作工具透明化学习（预测 3）。对研学从业者最直接的启示：**把"真实世界的产出"交给学生，学生会还你超出预期的作品**——"给予他们信任，让他们担任领导的角色，使他们获得了更努力工作所需的信心和动力"。

**题 3（判断/纠错）**：一位老师听完 7 大预测后说："预测 5 说的项目制学习思维，就是让学生多做反思日记，放在项目结尾写一篇总结就行。" 请找出这句话的问题（提示：对照预测 5 的原文）。

<details><summary>答案</summary>

两层问题：(1) **把"思维模式"窄化成"写日记"**——预测 5 的"项目制学习思维"指成长型思维模式（努力和坚持的价值、把挫折当学习机会）、坚毅（长期坚持挑战性任务）、以及 16 种思维习惯（坚持不懈、灵活思考、开放心态），是一整套"态度与动机"的培养目标，不是一种写作形式。(2) **时间点错了**——原文明确："如果我们想鼓励学生关注自己的思维过程，那就**不能把复盘推迟到项目结束时。复盘需要贯穿于项目制学习的整个过程。**"科斯塔和卡利克的建议是让学生随时停下来问"我现在能做的最明智的事情是什么？"——形成性反思而非终结性总结。
</details>
