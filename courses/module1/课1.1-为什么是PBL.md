> **模块**：模块 1 PBL 是什么 ｜ **课程编号**：PBL-101

## 📌 本课导读

为什么全世界都在做 PBL？本课回答这个"第一性问题"。视频课 P_2.1 的主讲人是一位长期研究"青少年发展"的教育者，他用一张"保护因素"幻灯片讲清了 PBL 有效的底层机制：**PBL 不是教学花样，而是恰好踩中了人类成长的全部关键因素**。本课整合三套资料：**视频课 P_2.1** 讲机制（保护因素模型 + PBL 如何一一对应）、**《PBL项目制学习》第 1 章**给证据（高质量 PBL 框架 + 新科技学校网络案例）、**《PBL行动者手册》序言**给在地案例（12 位中国老师 4 周共创一本手册）。学完本课，你将拥有向任何人解释"为什么是 PBL"的完整话术。

## 📖 主线正文（内容源自 PBL Global 大师课）

### 一、世界在寻找什么：学术发展 × 人的发展

主讲人开场就亮明立场："我长久以来一直觉得，**世界在寻找一种方式，把学术发展和人的发展结合起来**。"

- 随着世界越来越注重"优势（strengths）"，这一点变得更加真切
- 如今，一个人要在生活中取得成功，**学历证书仍然重要，但你个人的能力正变得对成功至关重要**——无论在工作中还是生活中
- 所以主讲人喜欢 PBL 的原因很朴素：**它完美契合了人的优势发展和人的发展**

> 一句话：PBL 之所以是"对的教育"，因为它同时做两件事——教知识（学术发展）+ 养人（人的发展）。只做前者的是传统课堂，只做后者的是活动课，PBL 把两者焊在一起。

### 二、保护因素模型：一张幻灯片讲清"青少年如何成长为成功的成年人"

主讲人展示了一张"很复杂"的幻灯片，但他强调：**过去二三十年甚至四十年的所有研究都表明，同一组因素，很可能造就成功的成年人和情感成熟的个体**。这组因素就是"保护因素（protective factors）"，从左到右分四层：

```
第1层  一段关怀的关系（根本）
        └─ 父母、两位父母、牧师、教练，常常是老师
第2层  三个基本的人类驱动力
        ├─ 自主性：自由探索、学习你想学的东西、探索生活的感觉（自由感很重要）
        ├─ 精通：真正做好某件事，感受到成就感、满足感
        └─ 目标：对我来说生活中什么是有意义的？什么值得去做？
             我想学什么来帮助自己或帮助世界？
第3层  个性和安全感的其他方面
        └─ 安全感、爱、归属感、尊重
第4层  积极行为出现的机会
        └─ 合作、同理心、解决问题、自我效能感
结果   更好的结果
        └─ 健康、文化、社交……也包括考试成绩
```

主讲人特别强调：**一段关怀的关系是根本（fundamental）**——"生活中与一个成年人的关怀关系，确实是支撑人们走下去所必需的，并帮助他们变得成熟。" 关系建立起来之后，另外三个因素（自主、精通、目标）才开始发挥作用，它们"基本上是基本的人类驱动力"。

### 三、PBL 如何与保护因素"完美契合"

这是本课的核心段落。主讲人逐层对照：

| 保护因素 | PBL 中的对应 | 原文依据 |
|---------|-------------|---------|
| 关怀关系 | 师生之间强大的关怀关系 | "项目式学习很大程度上基于师生之间强大的关怀关系" |
| 自主性 | 发言权（voice）、选择（choice）、自主权 | "学生有发言权。选择、自主权，那就是自主性" |
| 精通 | 表现和掌握技能的机会 | "他们有机会表现和掌握技能，展示他们能做什么，那就是精通" |
| 目标 | 项目对学生有意义、有目标 | "项目对学生有意义和有目标，学生有学习的理由" |
| 参与和动力 | 前三者齐备的产物 | "那就是你获得参与感和动力的地方" |

**关键逻辑**：PBL 的日常（选课题、做作品、解决问题）不是"活动设计"，而是**在真实地激活人类成长的三大驱动力**。这不是巧合，是 PBL 结构本身的特性。

### 四、从驱动力到好结果：完整因果链

一旦这些因素发挥作用，链条继续向下走：

1. 自主 + 精通 + 目标 → **参与感和动力**
2. 动力 → 个性与安全感的其他方面出现：**安全感、爱、归属感、尊重**
3. 安全感 → 为积极行为创造机会：**合作、同理心、解决问题、自我效能感**
4. 积极行为 → 更好的结果：**健康、文化、社交……"我包括考试成绩"**

主讲人的结论掷地有声："**你获得项目式学习好结果的原因之一是，你也开始运用一些导致成功、投入的成年人的相同因素。而投入会带来成就。所以这就是为什么项目式学习有效。**"

> 记忆钩子：**关系 → 自主/精通/目标 → 安全感 → 积极行为 → 好结果**。这条链上每一个环节，PBL 都有明确的"接口"。

### 五、PBL 就是社会情感学习（SEL）

主讲人把话挑明："**当你做项目式学习时，你就是在做社会情感学习，你在培养年轻人的幸福感。这很关键。**"

- PBL 不是"先学知识、再培养品格"的两段论——两者在项目过程中同时发生
- 学生在项目中经历真实的成功与挫折、合作与冲突，这些体验本身就是 SEL 的素材
- 对教育工作者而言，PBL 是"以教学的形式做育人"

### 六、给老师的资源建议

接近课程尾声，主讲人希望"尽可能多地给你们留下资源"：

- 看看他推荐的一些**博客**、一些**网站**
- 主题聚焦：**社会情感学习（SEL）和幸福感**
- 他认为："这确实是成为熟练的项目式学习老师的一部分"——即 SEL 不是额外负担，而是 PBL 教师的专业基本功

## 📚 深度阅读（书籍精华）

### 《PBL项目制学习》第 1 章——项目制学习到底是什么

**开篇故事：达勒姆的自我拷问**。斯科特·达勒姆在密歇根州的一所学校任教，这所学校也是他曾经就读的母校。新年到来前，他漫步穿过学校大厅，经过曾经上课的教室时想起往事，然后问了自己一个重要的问题："**我在那些教室里到底做过些什么？**"他记得自己在各项考试和作业上取得过好成绩，却想不起任何一个曾让自己对学习感到兴奋的项目。他当即便向自己和未来的学生承诺：追寻一种"与众不同的教学方式"。

**项目制学习如何颠覆传统课堂**（三大改变）：

| 维度 | 传统课堂 | 项目制学习 |
|------|---------|-----------|
| 教师角色 | 内容专家，把知识一点点教给学生 | 不再是内容专家；设计学习框架，把自主权交给学生 |
| 学生行为 | 被老师牵着鼻子走 | 提出自己的问题，并为之创造意义 |
| 教室界限 | 教室四面墙 | 利用科技获取和分析来自世界各地的信息；学生与专家实时联系；新型学习社群聚集讨论 |

作者引巴克教育学院资深研究员约翰·默根多拉尔（John Mergendoller）的话点题：PBL 贵在"能让学生**掌握学术技能和知识内容，培养未来成功所必需的技能，养成学习自主性**并能够解决生活中所面临的挑战，以及应对世界所面临的挑战"——这与视频课 P_2.1 的"学术发展 × 人的发展"完全同频。

**高质量 PBL 的衡量框架（2018《高质量项目制学习框架》）**：该项目借鉴数百名实践者与倡导组织的见解，确定 6 项准则：

| 准则 | 含义 |
|------|------|
| 智力挑战与成就 | 学生深入学习，批判性思考，追求卓越 |
| 真实性 | 学生开展有意义的、与他们的文化、生活和未来相关的项目 |
| 公开产品 | 学生的作品被公开展示、讨论和评论 |
| 协作 | 学生面对面或通过网络协作，或接受导师和专家指导 |
| 项目管理 | 学生使用项目管理流程，有效开展项目 |
| 复盘 | 学生在整个项目中对工作和学习进行复盘 |

巴克"项目制学习黄金标准"进一步给出 **7 个基本项目设计元素**：挑战性难题或问题；持续性探究；真实性；学生的话语权和选择；复盘；评论和修正；公开产品。

**研究证据**：高中阶段以 PBL 为主要学习方式的学生，不仅升入高等院校的比率超过美国平均水平，而且在大学里学习的时间更长；全面开展 PBL 的学校（如深度学习学校网络成员），学生学业水平和个人技能发展（协作、学术参与、学习积极性、自我发展）均高于平均水准。

**"让 PBL 重新焕发活力的关键"清单**：
- 项目是课程的核心，**不是附加的或额外的教学单元**
- 学生参与真实世界活动，实践演练学科中使用的策略方法
- 学生可以合作，有时甚至进行全球性合作，解决对他们和现实受众重要的问题
- 科技是探索、合作、创造和沟通的工具
- 教师相互合作，共同设计实施跨越地域甚至时区的项目
- 好项目产生的能量带来"螺旋式效应"，甚至吸引媒体关注，让社区理解 PBL 的价值

**达勒姆的落地与回报**：他与学校媒体专家合作设计项目——学生利用美国国会图书馆在线藏书调查原始资料，"就像真正的历史学家所做的那样"分析事件和历史文物。达勒姆的投资回报巨大："我已经获得了作为一名教师的自由，因为我知道，我的学生如今可以**无拘无束地为自己去寻找意义**了。"

**全球图景**：新加坡从 2000 年开始推行"课题研究"，策略是"少一点讲述、多一些主动学习"；韩国教育工作者从高度测试导向的课程转向，着重培养协作能力与批判性思维；项目制学习"从印度带到了欧洲和南美洲"。

**"老师重新变成学习者"**：
- 迈克尔·麦克道尔（《设计严谨的项目制学习》作者）自白："我在高中生物课上唯一记得的事情，就是解剖了一只青蛙。"他让学生记住的不只是有丝分裂的定义："几年后，我想让学生记住，教室不仅是他们学习生物学的地方，也是他们学习如何进行团队合作、如何解决问题、如何应对变化的地方。"
- 保罗·柯蒂斯的转型：在传统高中单打独斗推行 PBL 受阻（"除非全校都相信这就是我们要走的路，否则你就是独自在打一场硬仗"），后加入 1996 年成立的纳帕新科技高中，"整个课程体系都是由项目制学习来推动的"。新科技学校网络如今覆盖全美近 200 所学校，坚持 4 项核心设计原则：①激励学生也激励成年人的文化；②以 PBL 为教学手段；③科技融入整个学习体验；④学习成果具有现实意义。

## 🛠️ 落地工具：PBL × 青少年发展对照卡（从 P_2.1 提炼）

把保护因素模型变成可检查的工具——设计或评估任何项目时，对照这张卡看"人的发展"是否到位：

```
┌─────────────────────────────────────────────────┐
│  PBL × 青少年发展对照卡（依据 P_2.1 保护因素模型） │
├─────────────────────────────────────────────────┤
│ 项目名称：____________________ 日期：__________ │
│                                                 │
│ ① 关怀关系：项目中师生/同伴之间是否有真实、持续   │
│    的关怀关系？（谁是这个孩子的"那个人"？）       │
│    □ 教师与学生有深度对话机会   □ 有导师/专家陪伴  │
│                                                 │
│ ② 自主性：学生有发言权和选择权吗？               │
│    □ 学生参与选题/问题设计   □ 学生自己选择角色、  │
│      路径、作品形式   □ 学生能自主安排部分进度     │
│                                                 │
│ ③ 精通：学生有机会真正"做好一件事"并感到成就感吗？ │
│    □ 有反复打磨作品的机会（不止做一遍）           │
│    □ 有展示技能/能力的场合   □ 有专业反馈帮助精进  │
│                                                 │
│ ④ 目标：学生知道"为什么做"吗？项目对他有意义吗？  │
│    □ 学生能说出项目对谁有价值、解决什么问题       │
│    □ 项目与学生的生活/兴趣有连接                 │
│                                                 │
│ ⑤ 结果预期：以上 ①②③④ 若齐备，按模型将自然产生  │
│    参与感→安全感/归属感→合作/同理心/自我效能→      │
│    更好结果（含成绩）。缺哪一项，就补哪一项。      │
└─────────────────────────────────────────────────┘
```

**使用步骤**：
1. 写下一个正在设计（或正在实施）的项目名称
2. 逐条对照 ①②③④，在方框里打勾或留空
3. 留空的项目 → 回到主线正文对应段落，找"保护因素"的原理解释
4. 四条全勾 → 检查第 ⑤ 步：是否已设计"参与感→归属感→积极行为"的路径（如团队仪式、成果公开展示）
5. 每学期末再用一次，对比项目迭代前后的覆盖度

> 💡 **研学场景示例**（把 PBL 方法落到你的业务）：
> - **杭州博物馆研学营**：学生自主选一件展品做"讲解员"（自主性），先跟着讲解员学、再自己查资料写讲解词、反复试讲（精通），最终面向真实观众讲解并收集反馈（目标+关怀关系+成就感）——四个保护因素全覆盖。
> - **西湖水质探究**：学生小组自主提出"西湖水质到底好不好"的假设并设计验证方案（自主性），用采样、检测、绘图等真实技能做出水质报告（精通），报告提交给景区管理部门并获回复（目标+真实受众），带队导师每周一次一对一复盘（关怀关系）。
> - **良渚文化布展项目**：为良渚博物院设计"给 10 岁孩子的导览方案"，学生自己分工策展、制作展板（自主性），作品在博物院公共空间展出（精通+成就感），讲解给外地游客听（目标）——从"听讲者"变成"创造者"。

## 📖 案例（行动者手册）

### "PBL 行动者计划"：12 位陌生老师 4 周共创一本手册

**背景**：《PBL行动者手册》序言讲述了一个"用 PBL 的方式做 PBL"的故事。2020 年 2 月 22 日 20 点 20 分，手册的各个职能群还在滚动着大量信息，为发布做最后准备——临发布前一天，团队重新设计 Logo、重新设计整体视觉。"难以想象这么大的改动在几个小时内一一实现了。比起'不可能'，似乎，大家更愿意说'我来试试吧'。这就是项目式学习（PBL）拥抱真实的魅力。"

**过程**：发起人发现一个痛点——"尽管参与 PBL 教师培训的人数不断攀升，但最终落地实施的项目却并没有如预期般增长，日常的工作和教学，仍旧是老样子"；从国外引进的 PBL 概念"过于繁复抽象，项目周期也长"，面对课堂时间有限、统考压力、班额人数大等困境，"想要迈出第一步并非易事"。于是"PBL 行动者计划"诞生："那就完全用 PBL 的方式来'运营'这个项目吧，让共创者经历一次真实的项目"——12 位原本并不熟识的伙伴共同设立成功的标准；以审核组、编辑组、运营组、项目组高度交叉的职能分工分组；用协作文档和项目进度追踪表管理进度；交叉组合、多次讨论、反馈、修改、迭代。发起人刻意扮演 PBL 中教师的角色："不断去重申各个职能小组有直接做决定的权利，努力不让自己成为项目的天花板（过多预设）和限速瓶颈（不够放权）。"

**结果**：一个半星期的磨合后，项目小组自主运转起来，最终手册收录 10 个案例，每个案例包含项目概述、项目实施过程、项目评价、项目工具四部分；出版后读者被邀请发起"手册共读小组"、申请加入行动者社群，甚至成为下一期手册的共创者——"这会是一本'生长中'的手册"。

**启示**：序言引用 2019 年 PBL 年度冠军罗恩·伯杰（Ron Berger）的话收束全篇："我是项目式学习的忠实簇拥者，并不是因为它很新潮或因为它是当下的热点，而是因为，**项目式学习就是生活应有的样子**。"PBL 的"为什么"不在理论里，而在"一群普通人靠同一个愿景完成一件骄傲作品"的真实过程里——这正是保护因素模型（关系+自主+精通+目标）在成人世界的复现。

## ✅ 自测（自我检查，做完即看答案）

**题 1（改写）**：你被要求向一位校长解释"为什么要在研学营里引入 PBL"。请用"一句话 + 保护因素模型四层结构"写出你的解释（要求：必须出现"关怀关系、自主、精通、目标"四个词）。

<details><summary>参考示例（先自己写再看）</summary>

示例："PBL 之所以值得做，是因为它恰好激活了青少年成长的四个关键因素——先建立师生之间的**关怀关系**，再让学生在项目中拥有**自主**（自己选题、自己决策）、追求**精通**（把作品反复打磨到专业水准）、找到**目标**（知道为谁解决什么问题），这四个因素齐了，参与感和动力自然出现，进而带来归属感、合作能力、解决问题能力，最后连考试成绩都会受益——这就是为什么 PBL 不是花架子，而是踩中了人的成长规律。"

判断标准：四层结构完整（关系→三驱动力→安全感/积极行为→好结果）；有"投入带来成就"的因果表述；能让没听过 PBL 的人听懂。
</details>

**题 2（判断）**：以下哪个项目更符合"保护因素模型"？为什么？
A. 研学营每天上午听讲解员讲文物知识，下午做文物知识填空卷，结营时按分数排名
B. 研学营学生自己选一件文物，向讲解员学方法后自己查资料、写讲解词、反复试讲，最后在展厅向真实观众讲解

<details><summary>答案</summary>

B。A 只有"知识输入+回忆测试"，四个保护因素全部缺席：没有自主（内容固定）、没有精通（无打磨机会）、没有目标（为分数而非为真实受众）、也难有深度关怀关系。B 四个因素齐备：自己选文物（自主）、向专家学+反复试讲（精通、关怀关系）、面向真实观众讲解（目标+成就感）。按 P_2.1 的模型，B 才会产生参与感、归属感和后续的积极行为。
</details>

**题 3（判断/纠错）**：一位老师说："我们的研学活动就是 PBL——我们带学生去西湖边捡垃圾、做环保手抄报，学生可开心了，这就是在做社会情感学习。" 请找出这句话里的问题（提示：对照保护因素模型与"积极行为"的定义）。

<details><summary>答案</summary>

两层问题：(1) **有活动无目标**：捡垃圾+手抄报是"动手操作"，但学生没有"目标"——不知道为谁解决什么问题、解决到什么程度算好；按模型，缺"目标"这一驱动力，参与感不会持续。(2) **把"开心"当成"社会情感学习"**：P_2.1 里的 SEL 是"合作、同理心、解决问题、自我效能感"等积极行为的出现，需要安全感、归属感打底，而安全感和归属感来自关怀关系与真实挑战（比如真实检测西湖水质、向管理部门提交报告并得到反馈），不是一次性的环保活动。真正的 PBL 是"课程本身"（见深度阅读），活动只是它的载体。
</details>

**题 4（自查·本课产出）**：拿出你正在设计（或已开过）的一个研学课程，用"PBL × 青少年发展对照卡"自查：
1. 四个保护因素各打勾/留空
2. 留空的项，用一句话写出改进方案（例：缺"精通"→ 给作品增加一次"专家反馈+修改迭代"环节）
3. 最后用保护因素模型，向一位家长说清楚：你的课程为什么值得孩子参加？

<details><summary>自查指引</summary>

这是本课的核心产出——把"为什么是 PBL"变成你课程的具体卖点。自查要点：
- 如果四因素只覆盖一两个：你的课程还停留在"活动"层面，不是 PBL；回到主线第三、四节补齐
- 如果说不清"学生为什么做"（目标项）：回到"目标=对我有意义/对世界有价值"的原定义，重写项目的意义陈述
- 对家长的表述要落到结果：关系→投入→归属→积极行为→成长（含学业），用保护因素模型当"证据链"，而不是只说"培养综合素质"这种空话
</details>
