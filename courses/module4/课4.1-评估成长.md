## 📖 主线正文（整理自视频课 P_14 / P_14.1）

### 一、"为成长而评估"：期望先行

这个体验的标题是"为成长而评估"。关键认知：**评估从项目一开始就启动**——当你让学生清楚知道你对他们的期望、他们应该怎么表现、你会怎么评价他们时，他们达到那个水平的可能性会大得多。所以：

> "你要把评分标准当作一个**表现工具**，而不仅仅是一个评估工具。"

### 二、PBL 里用什么评估？

你在 PBL 中用的很多工具都会很熟悉：测试、小测验、作业、论文、报告、实验——所有这些类型的评价都可以包含在 PBL 里。**但额外的是你还需要用评分标准，因为你在衡量表现，而不用评分标准就没法衡量表现。**

### 三、评分标准 ≠ 打分指南（关键区分）

"它们得是**好的评分标准，不是打分指南**。很多人把这两者搞混了。打分指南只是列出你要做的事情，然后给个总分。比如，报告封面需要一张照片，有照片就给 5 分——但完全没说照片质量怎么样。"

- **打分指南**：核对清单式，有/没有，给分/不给分——评价不了质量
- **评分标准（rubric）**：描述不同水平的表现长什么样——能衡量表现质量

工具箱里已有现成的评分标准（经过实践检验），"语言都给你准备好了，所以你不需要从零开始重新发明评分标准"——可以扩展、修改、合并、整合。

### 四、"为成长而评估"是引导和辅导技能

"用评分标准来'为成长而评估'，其实是一个很深的**引导和辅导技能**……它清楚显示了你期望看到的行为是什么，它提醒学生他们能做什么，所以评分标准可以用作**成长工具**。"——评分标准不是期末宣判，而是过程中的导航仪。

### 五、你需要一个整体的评估计划（P_14.1）

下一步是给自己建一个**评估计划**，决定你想给评分标准多少权重、给传统测试或论文多少权重——"这真的会影响你的评分方案，以及你怎么给项目打分"。

P_14.1 的评估计划要素：**总结性评估、形成性评估、职业道德、个人表现与团队表现、学术内容与技能**——"要从整体评分角度来考虑，你要看项目表现的许多不同方面，并制定一个计划。计划确实是制定有效评估的第一步。"

**用评分标准时**：当作成长工具而非总结性工具——"把它放在口袋里，和团队一起工作时随身带着，不断指出他们在哪里进步了，在哪里还需要成长。"

**单点评分标准（single-point rubric）**：只在"达标"一档写详细描述，两侧留白供写"超出/不足"的具体证据——"让学生在整个项目中自我评估表现的好方法，让他们能对自己工作质量做出很好的判断"。

**确保给技能打分**："在项目式学习中打分很难。我要说的第一件事，也是最重要的，确保你给技能打分。你不能让技能不打分，否则学生不会像他们应该的那样认真对待。"

## 📚 深度阅读（书籍精华）

### 巴克《项目学习教师指南》第 3 章——规划项目评价

**核心理念**：项目学习采用更真实的评价方法——"评价项目中的学生表现，比传统的学习评价更具有多样性……要求评价手段不仅关注学习结果，还要把握学习过程。"评价内容包括：学生的高级思维和必要技能、高品质项目作品、规范的探究方法。

**步骤 1：使项目作品与学习目标相匹配（倒推法）**——从学习目标倒推，采用与学习目标相符合的项目作品。三层作品结构：
- **最终作品**：项目结束时完成，是所学知识与技能的综合体现，往往在重要场合展示（研究论文、报告、多媒体演示、学校范围内的演讲、学校以外的展览）。**展览的益处**：学生参与策划和制定评价标准；展品多样性体现不同阶段进展；训练元认知（制订计划、设定目标、自我激励、控制进度）；"每个学生都会被视为知识丰富的实践者"；可引入同伴评价、专家评价、自我评价、家长评价
- **阶段性作品**：出现在项目初始、中间、最后阶段（作品初稿或完成品）——与里程碑结合，"给学生创造出更多不断改进的机会"；给教师提供控制过程的机会，及早发现学生能否达成目标；为具体教学内容提供检查点
- **项目过程文件（artifacts）**：学生计划、提问、解决问题的过程证据（笔记、日志、电子邮件、决策记录、访谈记录、进展小结）——用于评价技能和思维习惯，需事先设定期望和标准

**步骤 2：明确评价内容**——把知识和技能分解成一组学习目标的明确描述。例如"口头陈述"至少包含三项子技能：目光接触、肢体语言、语音语调；还可包括吸引人的开场、连贯的表达、重要事实。

**步骤 3：使用评价表**——"评价表是一种打分评价指南，能够区分学生不同程度的表现。"关键点：**评价表是公开的，从项目一开始学生就知道，他们也可以参与制定**；配以示例效果更好——"在项目开始之前，让学生用评价表评价一下以前学生的作品案例，这会很有帮助"。

**有效评价表的特征**：基于对学生项目工作的分析；利用表现的核心特征区分（而非"最容易看到、数得清、容易评分的部分"）；区分度合适（不要分级太多）；使用丰富的质性评语；用词无歧义、提供示例。

**设计评价表三要素**：
| 要素 | 说明 | 示例 |
|------|------|------|
| 要素 | 表现/作品可分解的部分 | 陈述五要素：影响力、工作质量和技能、方法和行为的合理性、内容的有效性、所用知识的完善性 |
| 等级 | 表现的分级 | "基础/达标/高级"，多数用 3-6 级；偶数等级避免"找平均分" |
| 评价标准 | 确定成功程度的具体表述 | "有效的口头陈述：80% 的时间里保持与听众的目光交流" |

**两种类型**：分析性评价表（把任务分解成子项分别评价，推荐课堂使用）；整体性评价表（综合各项得一个总分，但缺少细节）。

**编写技巧**：利用布卢姆教育目标分类学动词（知识→理解→应用→分析→综合→评价）；把评价标准与课程标准联系；控制评价表数量与区分度；**使用学生的语言**（让学生用自己的话重述标准）；保持范例高水准；"对能被感知的项目作品进行判断，而不是对无形过程进行猜测"（不用"表现出洞察力"这类模糊词）。

## 🛠️ 落地工具：评价矩阵（工具9）+ 学生评价全套（工具35/39/40）

### 工具卡 1：评价矩阵（工具9）

```
┌────────────────────────────────────────────────┐
│ 主产品/表现 │ 学习目标 │ 评价证据 │ 评价方式 │ 评价时机 │ 分值比例 │
├────────────────────────────────────────────────┤
│ （示例）平面图 │ 探索几何图形 │ 平面图数据、│ 教师反馈、│ 里程碑2 │ 30% │
│            │ 面积体积计算  │ 比例的准确性│ 评价量规  │ （形成性）│      │
└────────────────────────────────────────────────┘
```

**评价核心三要素**：谁来评价（教师/学生）？为什么评价（检测目标体系达成，不是为评价而评价——"过多的评价会大大增加教师和学生的负担"）？评价什么（**能体现学习目标的产品或表现才能作为评价对象**，与学习目标无关的不能成为评价对象）？

**四大结合**：形成性 + 终结性；教师评价 + 学生评价；自评 + 他评（对比两者能帮助学生更快进步）；内部评价 + 外部评价（专家点评、用户反馈、听众反馈）。

**使用步骤**（6 步）：① 完成"驱动问题分解表"（工具7）和"问题-任务-产品对应表"（工具8），参考其最后一列设计矩阵第一列；② 参考 PBL 目标体系（工具2），把每个关键产品或表现涉及的学习目标迁移过来；③ 从产品/表现中找证明目标达成的依据，作为量规维度；④ 选评价方式：打分量规/教师同伴反馈/不含分值的主观性评语；⑤ 写清评价时机，区分形成性与终结性；⑥ 设定评分比例（主观评语不设百分比）。

### 工具卡 2：学生评价全套（工具35 BESMART + 工具39 自我评价 + 工具40 互相评价）

**BESMART 素养评价表（工具35）**：在 BESMART 能力模型（PBL 核心素养）中选择与项目相关的 2-3 个维度，把二级指标"能力表现"细化到三级指标"行为表现"，通过观察具体行为打分（5=非常符合 → 1=没有体现）。例："有效沟通与合作"的行为表现——"运用礼貌用语（没有指责、埋怨或攻击性语言）交流""善于倾听，从他人表达中获取关键信息""有责任感，将团队的事当作自己的事"。也可用于整体性评价：对未参与 PBL 的学生前测，开展一段时间后后测，验证素养提升效果。

**自我评价表（工具39）**：开放式问题——"我通过哪些方式为团队做出了贡献？""我遇到的三个问题是什么？我是如何解决的？""如果再来一次，我会怎样做？""我对自己有哪些新发现？"**三原则**：不用定量指标，用开放式问题和描述；不评判结果，引导对过程反思复盘；避免消极句式（"……做得不好"），用积极句式（"我的收获/成长是……"）。自评提升**元认知**能力（弗拉维尔），学生通过分析自评与他评的差异更全面认识自己。**操作要点**：解读问题 → 给提问澄清机会 → 安排安静完整的时间独立填写 → 学生可选择提交或留存（隐私被尊重，自评才有意义）。

**互相评价表（工具40）**：五问——"在你的小组中，你希望给谁反馈？为什么选择他/她？你觉得他/她对团队最大的贡献是？他/她做了什么事让你印象深刻？你最想给他/她什么建议？"**三点意义**：提供平等的视角（教师视角有主观成分、自评受元认知能力限制）；在评价中进步（学生可以讨论评价结果，而非被动接受）；在评价中反思（"评价他人就像照一面镜子"）。**机制设计**：团队内部评价（两两组队、编号循环、或自由选择）；团队之间评价（评作品不评个人）。**注意事项**：评价用语要礼貌、合理、建设性；避免"匿名评价""背对背打分"；学生一开始只说好话——"这说明当下的文化对学生来说还不够安全"，多开展几次氛围会越来越好。

> 💡 **研学场景示例**：
> - **良渚博物院研学**：评价矩阵主产品 = 玉器讲解词 + 现场讲解 + 团队协作——讲解评价用分析性量规（内容准确性 40%、表达感染力 30%、与观众互动 30%），团队协作用 BESMART"有效沟通与合作"维度；里程碑 2（讲解词初稿）做形成性评价，最终展示做终结性评价
> - **西湖水质项目**：给"报告撰写人"发单点评分标准（达标档描述"数据完整、来源可查、结论与数据对应"，两侧留白写具体证据）；项目结束时人人填自我评价表（"我遇到的三个问题"）+ 互相评价表（"他/她对团队最大的贡献是"）
> - **布达佩斯展导览**：外部评价——邀请博物馆讲解员用评价表给学生的模拟导览打分（"内部评价 + 外部评价"结合）；"成果汇报"用 BESMART"审美创造"维度（"将自己对美的认知融入自己的作品中"）

## 📖 案例（行动者手册）

### "有爱的包装盒"：一套完整的评价矩阵长什么样

《50个工具》工具 9 展示的北京市良乡中心小学"有爱的包装盒"项目，是评估方案从设计到落地的完整示范。

- **背景**：驱动问题是"我要给谁，送什么礼物？"——学生为选定的对象设计并制作礼物包装盒。项目分四个阶段：选礼物、设计包装盒平面图、制作包装盒、展示推广成果。
- **过程**：教师先完成问题-任务-产品对应表（选礼物 → 平面图 → 包装盒成品 → 成果展示 PPT 和当众演讲），再按六步设计评价矩阵：把"有效沟通与合作""成果汇报"等学习目标迁移进来，为每个主产品选评价证据（平面图数据准确性、包装完整性与美观性、日常沟通与合作、演讲与设计理念），定评价方式（教师反馈/量规/主观性评语/自评互评），标评价时机（里程碑 2 形成性、成果展示终结性），最后设分值比例（平面图 30%、包装盒 30%、沟通合作 30%、成果汇报 40%——比例可叠加，因为汇报同时评沟通与审美）。
- **结果**：每个里程碑节点都有对应的评价动作，学生从项目一开始就知道"平面图要准、包装要美、合作要真、汇报要清"，评价不再是期末的意外。
- **启示**：① 评价方案必须**前置**——"项目评价可能发生在项目实施的各个环节，但是项目评价方案是前置的，要在项目开始实施之前制定"；② 评价矩阵是"框架"，落实还要靠一个个量规和评价表（BESMART、自评、互评）；③ 与学习目标无关的产品不评价——"最终产品一定是用来解决核心驱动问题的，无关产品可以舍弃"。

A. "报告封面有照片，有就给 5 分"
B. "报告的证据部分：达标=至少使用 3 个可查证的资料来源，并说明每个来源与结论的关系；高级=资料来源多样且能批判性比较不同来源"

<details><summary>答案</summary>

B。P_14 明确区分：A 是"打分指南"——只列要做的事然后给总分，"完全没说照片质量怎么样"；B 是"评分标准"——描述了不同水平的表现（达标/高级），能区分质量，且具体可观察。巴克第 3 章补充：好的评价标准要"易于观察和测量"（如"80% 的时间里保持与听众的目光交流"），用丰富质性评语而非"极好的作品"这类比较词。

**题 3（判断）**：一位老师只在项目结束时用一张"综合表现打分表"给学生打分（覆盖知识、技能、合作、作品各给一个总分）。请找出这个问题的问题（两层以上）。

<details><summary>答案</summary>

第一层（时机）：违背"为成长而评估"——评估应从项目一开始启动，让学生清楚知道期望；只做终结性评价，学生全程不知道标准、没有改进机会（研究显示：清楚展示期望，学生达成的可能性会大得多）。第二层（工具）："综合打分表"是整体性评价表——巴克第 3 章指出它"缺少对学生有用的细节内容"，应改用分析性评价表把任务分解成子项（内容/结构/研究深度/资料使用/写作）才能给出明确反馈。第三层（主体）：评价只有教师一个主体——工具 9 要求师评 + 自评 + 互评 + 外部评价结合，学生没参与制定评价表就失去内化标准的机会。补救：评估计划前置、用分析性量规、加入自评互评与外部评价。
</details>

**题 4（自查·本课产出）**：为你的项目完成评估方案：
1. 用评价矩阵 6 步法画出你的矩阵（至少 3 行）
2. 为其中一个能力目标（如沟通合作）写一份 BESMART 行为表现清单（至少 4 条）
3. 设计自我评价表 + 互相评价表各 3 问，并确定互评机制

<details><summary>自查指引</summary>

- 矩阵的"评价证据"必须是可观察的（不要写"表现出洞察力"这类模糊词）
- BESMART 只选 2-3 个相关维度，行为表现具体到动作
- 自评问题用积极句式、开放式（"我的收获是……"而不是"我做得不好的地方"）
- 互评机制：两两组队/编号循环/自由选择？避免匿名打分；学生只会说好话说明安全感还不够——多开展几次会好转
- 最后自查：评估方案是不是项目开始前就定好了？学生知道标准吗？有没有给技能打分？
</details>
