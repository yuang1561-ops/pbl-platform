# PBL 课件生成规范 v1（批量用）

> 每课课件必须达到以下详细度标准。参考样例：`courses/module2/课2.3-驱动性问题.md`（17KB，内容详细版的标杆）。

## 课件固定结构（8 部分，顺序不可变）

1. **标题区**：`# 课 X.Y 标题` + 引用块（模块/课程编号/学习目标/预计学习时间）
2. **📌 本课导读**：3-5 句为什么重要 + 本课整合了哪些来源
3. **📖 主线正文**（整理自视频课）：**6 个左右小节，把视频课原文的干货全部挖出来**：
   - 核心概念讲解（展开讲透）
   - 完整案例（保留故事细节：人物、对话、前后对比）
   - "X 个不要/原则/技巧"逐条展开（每条：坏例子 ❌ + 好例子 ✅ + 原因）
   - 实用公式/步骤（如果有）
   - 每节要有小标题
4. **📚 深度阅读**（书籍精华）：每个来源书一个二级块
   - 提炼 2-3 页精华：定义/原则表格/关键案例/检验标准
   - 每个来源末尾：`> 🔗 延伸阅读：<书名> <章节> → 知识库检索"关键词"`
5. **🛠️ 落地工具**（50工具 对应工具）：
   - 工具卡片（ASCII 框线或 Markdown 表格）
   - **使用步骤**（4-6 步编号流程）
   - `> 💡 研学场景示例`：2-3 个，落到博物馆/西湖/良渚/布达佩斯展等真实研学场景
6. **📖 案例**（行动者手册或其他书）：完整案例（背景/过程/结果/启示 4 段），结尾 `> 🔗 案例全文 → 知识库检索"关键词"`
7. **✅ 自测**：**4 题**，模式固定：
   - 题 1（改写）：给研学主题，要求改写成驱动性问题/方案 → 参考示例
   - 题 2（判断）：A/B 对比哪个好 → 答案 + 依据
   - 题 3（判断/纠错）：找出问题的问题 → 答案 + 两层以上分析
   - 题 4（自查·本课产出）：结合学习者自己的课程实操 → 自查指引
   - 每题用 `<details><summary>...</summary>...</details>` 折叠答案
8. **🔗 关联资源**：下一课 + 工具 + 工坊联动 + 知识库检索关键词

## 内容质量铁律

1. **干货全挖**：视频课原文提到的每个案例、每个技巧、每句话都要结构化呈现，不遗漏
2. **来源真实**：深度阅读内容必须从实际 OCR 文本/epub 中提取，禁止编造章节内容；提取用 `grep -n "关键词" 文件` 定位
3. **研学落地**：示例/案例必须落到博物馆、西湖、良渚、布达佩斯展、杭州研学等真实场景
4. **详细度对标**：每课 12KB-20KB，主线正文占比最大
5. **自测可执行**：题 4 必须是"学习者能带走产出"的任务型题目
